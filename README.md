# K-LOL.GG V2

V1 코드를 복사하지 않고 기능 계약부터 다시 구현하는 독립 Greenfield 프로젝트입니다.

## 현재 범위

- S00 기반·디자인 시스템
- 합성 fixture를 사용하는 첫 플레이어 검색 슬라이스
- 운영 DB·Blob·외부 연동 없음
- 구현 경로: `/`, `/players`

## 로컬 실행

```bash
npm install
npm run dev
```

## 검증

```bash
npm run check
```

진행 상태와 V1 기준점은 `docs/STATUS.md`와 `docs/cutover/V1_BLUEBLACK_BASELINE.md`를 확인합니다.
