[K-LOL.GG 카카오봇 V4 분류기 개발 안내]

V4 서버 명령 분류기의 1차 구현과 자동 검증을 완료했습니다.

- 기존 V1 명령 표본 101개를 40개 canonical 명령으로 정리했습니다.
- `/명령어`와 `명령어`는 같게 처리하고, `//`, URL, 문장 중간 `/`는 명령으로 처리하지 않습니다.
- 파티·스크림은 RECRUIT, 내전·전적·최근·랭킹·운영 기능은 FEATURES 프로필로 분리했습니다.
- 잘못된 봇 프로필에 들어온 명령은 `WRONG_PROFILE`로 명확히 판정합니다.
- 파티·내전·스크림 전체 양식은 일반 명령보다 먼저 SNAPSHOT으로 판정하며, 0명 양식과 A→B→A 재수정을 허용합니다.
- V2/V4 진단과 raw JSON 명령은 일반 사용자 명령과 분리했습니다.

집중 테스트 17개와 타입 검사, ESLint를 통과했습니다.

이번 변경은 서버 분류기와 테스트만 추가했으며 DB·운영 서버·실제 카카오봇에는 반영하지 않았습니다.
