# V2 비공식 AI 팬아트 자산 팩 QA

## 판정

- 상태: **로컬 자산 제작·최적화·시각 검수 통과 / 사용자 화면 미연결 / 운영 미반영**
- 생성 도구: built-in `image_gen`
- 최적화 도구: 저장소에 이미 설치된 Sharp 0.35.4
- 운영 API·외부 DB·배포·push는 사용하지 않았다.

## 범위와 변경

1. 럭스·잔나·세라핀·룰루·그웬 정사각형 카드 팬아트 5종을 새로 생성했다.
2. 각 생성 원본은 저장소 밖 `E:/k-LOL.GG/output/v2-visual-assets-20260901/`에
   보존하고, Git에는 768×768 WebP·AVIF 파생본만 넣었다.
3. 기존 아리 히어로 원본에서 1600×900 WebP·AVIF 성능 대안을 만들었다.
4. 원본과 동일했던 1,817,384B `public/og.png`를 1200×630, 303,652B PNG로
   교체하고 OpenGraph dimensions·alt를 실제 자산에 맞췄다.
5. 픽셀 크기·바이트·SHA-256·한국어 alt·AI 생성·비공식 여부·성능 예산을
   `public/images/champions/asset-manifest.json`에 기록했다.

공식 Riot 이미지나 로고를 내려받거나 복제하지 않았다. 각 생성 프롬프트에는 새 포즈,
새 배경, 공식 스플래시 재현 금지, 공식 로고·텍스트·워터마크 금지를 명시했다. 실제 사용한
프롬프트 전문은 `PROMPTS.md`에 있다.

## 기존 홈 런타임 측정과 해석

- 기존 390px 홈에서 Next Image URL `w=640&q=75`를 브라우저형 `Accept`로 요청하면
  `image/webp` 18,324B였다.
- 같은 변환 URL을 `Accept` 없이 요청하면 PNG 111,466B였다.
- 즉, 기존 홈 히어로는 Next Image 변환 경로에서 이미 작은 브라우저 전달본을 제공한다.
  1,817,384B 원본 PNG는 품질 기준·원본 보존용으로 유지했고, 직접 정적 전달이 필요한
  화면을 위해 81,952B WebP와 53,799B AVIF를 추가했다.
- 반대로 `/og.png`는 변환 없이 원본 1,817,384B가 전달되므로 확실한 병목이었다. 이를
  303,652B로 줄여 83.29% 절감했다.

## 시각 검수

`contact-sheet.jpg`를 원본 크기로 확인했다.

- 다섯 카드 모두 밝은 하늘색·라일락·피치 계열과 기존 홈의 부드러운 판타지 질감이
  일관된다.
- 럭스의 빛 지팡이, 잔나의 바람 지팡이, 세라핀의 수정 마이크, 룰루의 보랏빛 모자와
  요정 마법, 그웬의 장식 가위가 카드 크기에서도 구분된다.
- 공식 로고·문자·워터마크·서명은 보이지 않는다.
- 정사각형 안전 여백, 인물 중심, 주요 소품이 프레임 안에 들어와 카드 크롭에 적합하다.
- OG 1200×630은 인물과 넓은 하늘 여백이 모두 유지되고 눈에 띄는 팔레트 밴딩이나
  파손이 보이지 않는다.

## 남은 위험

1. 생성형 팬아트는 공식 설정·의상 세부와 다를 수 있으므로 공개 전 최종 인물·브랜드
   검수가 필요하다.
2. Riot Games 정책과 팬 프로젝트 고지를 공개 직전에 최신 기준으로 다시 확인해야 한다.
3. 자산을 실제 화면에 연결할 때 의미 이미지에는 manifest의 alt를, 반복 장식에는 빈 alt를
   적용하는 접근성 판단이 필요하다.
4. AVIF는 최신 목표 브라우저 실기기 smoke가 남아 있다. WebP 폴백은 함께 제공한다.
