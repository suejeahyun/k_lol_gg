# 홈 히어로 성능 자산 연결

- 홈의 `next/image` 입력 원본을 1,817,384B PNG에서 81,952B WebP로 변경했다.
- 표시 비율은 기존과 같은 16:9이며 `fill`, 반응형 `sizes`, LCP `priority` 계약은 유지했다.
- 원본 입력 바이트는 95.49% 감소한다. 최종 브라우저 전달본은 Next 이미지 최적화가 뷰포트와 `Accept`에 맞춰 다시 생성한다.
- 320px 실제 프로덕션 화면은 `w=384&q=75`, `image/webp` 8,208B로 응답했고 디코딩 크기 320×180, 원래 alt, 브라우저 오류 0건을 확인했다.
- 같은 화면에서 고전형 세로 스크롤바를 포함한 root/body `clientWidth`와 `scrollWidth`가 305px로 일치해 가로 스크롤이 없음을 확인했다.
- 시각 증거: `home-hero-webp-source-320x800.png`
- 카드용 여성 챔피언 5종은 실제 기능 카드의 의미와 alt 판단이 확정될 때 연결한다.
- 운영 배포는 수행하지 않았다.
