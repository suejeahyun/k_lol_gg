# 카카오 방 기능 분리 사전 패치

카카오 봇 방을 `구인구직`과 `사이트 기능`으로 안전하게 분리할 수 있는 기반을 준비했습니다.

- 기존 구인구직 운영방은 자동으로 `RECRUIT` 프로필을 유지합니다.
- 새 사이트 기능 방은 관리자 화면에서 `FEATURES` 프로필로 연결할 수 있습니다.
- 봇 설치본 하나는 기존과 동일하게 방 하나에만 연결됩니다.
- 다른 프로필의 명령은 서버에서 차단할 수 있는 전용 검증 계약을 추가했습니다.
- 기존 모집·스크림·양식 데이터는 변경하지 않습니다.

현재는 소스와 테스트만 완료된 상태이며 운영 DB와 사이트에는 아직 반영하지 않았습니다.
