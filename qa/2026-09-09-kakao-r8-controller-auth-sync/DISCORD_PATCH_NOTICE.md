## K-LOL.GG 카카오봇 R8 보안·내전 양식 패치 안내

카카오 모집의 생성자/팀장 권한을 서버에서 구분하도록 보강했습니다.

- 모집 생성·조회·스크림 참가는 기존처럼 허용된 방에서 사용할 수 있습니다.
- 모집 동기화·종료·취소·재개·확정·완료는 생성자, 참가한 상대 팀장 또는 운영자만 가능합니다.
- 다른 방의 모집은 보이지 않으며, 같은 방이라도 권한 없는 사용자의 상태 변경은 거부됩니다.
- 개발용 `/V2모집 JSON`은 운영자만 사용할 수 있습니다.
- 내전 전체 양식에서 빠진 카카오 신청은 삭제하지 않고 취소 상태로 안전하게 전환됩니다.
- 이름이 모두 빠진 완전한 1~10번 양식도 0명 동기화로 처리됩니다.
- 전체 양식 맨 앞의 `/` 또는 전각 `／`도 지원하며, `//`·URL·중간 slash는 명령으로 처리하지 않습니다.
- SITE 신청, 관리자 확정 기록, 다른 방·다른 회차 신청은 취소하지 않습니다.
- 응답에 `신청 n · 수정 n · 취소 n · 확인 필요 n`이 표시됩니다.
- 외출 양식은 간편 공지, `2. 양식작성`, `<외출>`, `&lt;외출&gt;` 형태를 모두 동일하게 접수합니다.
- 외출 기간·사유·범위가 비어 있으면 누락 항목을 바로 안내하며 잘못된 신청은 서버로 보내지 않습니다.
- 허용된 카카오방의 일반 멤버도 외출 등 운영 양식을 제출할 수 있습니다. 검토·삭제는 계속 관리자만 가능합니다.
- 미연동 방에서는 `/V2연동확인` 결과를 관리자에게 전달하라는 안내가 표시됩니다.

버전: `KLOL_KAKAO_BOT_V41_V2_2026_09_09_R8_CONTROLLER_AUTH_SYNC`

9월 9일 외출 접수 실패는 운영 로그상 room allowlist 불일치로 확인됐고, 서명이나 개인 발신자 권한 문제는 아니었습니다. 해당 방 allowlist hotfix와 운영 health 확인은 완료됐으며, 같은 방에서 외출 양식을 한 번 다시 보내 실제 접수 결과를 확인해 주세요.
