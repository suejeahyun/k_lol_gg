# 사이트·카카오톡 기능 안내 공지 복붙용

```text
[K-LOL.GG 사이트·카카오톡 기능 안내]

안내 내용
• 사이트 공개·관리자 화면의 기능
• 카카오톡 명령어와 접수번호
• 경고 접수, 승인·반려, 차감 인증
• 종료된 내전 2·3세트 결과 수기 등록
• 카카오 구인·스크림·내전 운영
• 운영 신청, 자동화 설정과 처리 로그

필수 구분
• 경고 부여 근거사진: 0~3장
• 일반 경고 차감 인증: 10장
• 내전 경고 차감 인증: 15장
• 종료 내전 결과: 2세트 2장 / 3세트 3장

핵심 연결 방식
• 카카오톡에서 양식과 사진을 접수합니다.
• 발급된 DS·WR·MR 번호로 상태를 조회합니다.
• 사이트에서 접수를 확인하고 최종 처리합니다.
```
