# 카카오봇 R12 방 식별 수정 안내

동일한 방에서 사용자마다 방 ID가 달라지던 원인을 확인했습니다. 구형 MessengerBot R 알림 파서가 방 이름 대신 발신자명을 전달한 것이 원인이었습니다.

- R12는 방 이름 대신 MessengerBot R의 고유 `channelId`를 우선 사용합니다.
- 같은 방에서는 닉네임이나 방 제목이 달라져도 동일한 방 fingerprint를 사용합니다.
- 손상된 구형 callback은 잘못된 방으로 등록하지 않고 앱 업데이트를 안내합니다.
- 환경변수나 사용자별 예외 목록은 추가하지 않았습니다.

MessengerBot R 앱을 0.7.34a 이상 최신 안정 버전으로 업데이트한 뒤 R12 설치본을 적용해 주세요.

버전: `KLOL_KAKAO_BOT_V41_V2_2026_09_09_R12_CHANNEL_ID_ROOM`

현재 상태: 소스·자동 테스트·설치본 생성까지 확인했습니다. 운영 배포와 휴대폰 설치는 아직 하지 않았습니다.
