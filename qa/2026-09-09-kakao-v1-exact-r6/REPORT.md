# 카카오톡 봇 V1 정확 호환 R6 검수

## 제보와 판정

- 증상: `5인파티`, `2인파티`, `구인현황`은 서명·발신 설정 오류가 나고 `내전구인`은 V1과 다른 양식을 반환했다.
- 기대 동작: 사용자가 보던 V1 명령어·응답·양식 수정 흐름은 그대로 유지하고, 내부 저장만 V2 서명 API를 사용한다.
- 영향: 기존 오픈채팅 운영 흐름 중단, 두 봇의 중복 응답, 내전·스크림 양식 호환 실패.
- 범위: MessengerBot R 설치본, V1 파티·내전·스크림·도움말·조회 호환, V2 모집 저장 경계.

**확인됨:** 이전 V41 라우터에는 V2 전용 내전 양식과 확인 단계가 섞여 있었으며 V1 응답과 달랐다.

**확인됨:** 비공개 설치본의 예전 키 이름과 현재 전송 계층이 읽는 키 이름이 달랐다. R6 비공개 설치본은 `KLOL_V2_KAKAO_WEBHOOK_SECRET_CURRENT`와 `KLOL_V2_KAKAO_IDENTITY_SECRET`을 사용한다.

**확인됨:** V1 스크림 양식에는 멸망전 번호가 없지만 V2 생성 계약은 대회 식별자를 요구했다. signed BOT 요청에 한해 활성 멸망전이 정확히 하나일 때 서버가 트랜잭션 안에서 자동 연결하도록 보완했다. 없거나 여러 개면 저장하지 않고 409 오류를 반환한다.

**확인됨:** 실제 R6 휴대폰 봇은 `/봇버전`과 `/V2연동확인`에 정상 응답했다. `내전구인 협곡`처럼 서버 통신이 없는 V1 양식도 정상 출력됐다.

**확인됨:** 오전 10:00의 `5인파티`, `구인현황`, `스크림 구인` 요청은 Vercel Production의 `/api/integrations/kakao/openchat`에서 모두 HTTP 401 `SIGNING_KEY_UNAVAILABLE`로 거부됐다. 현재 Production 배포는 21시간 전 생성됐고 `KAKAO_WEBHOOK_SECRET_CURRENT` 등 카카오 환경변수는 약 1시간 전에 추가·갱신됐다. 따라서 현재 배포가 새 환경변수를 읽지 못하는 것이 직접 원인이다.

**미확인:** 운영 Vercel을 재배포하지 않았으므로 Production에서 R6 서명 통신이 정상화되는지는 아직 확인하지 않았다.
