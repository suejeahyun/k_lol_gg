# 카카오봇 R14.2 설치본 연동 패치 안내

카카오 알림에서 방 이름이 사용자명처럼 잘못 전달돼 일부 사용자 명령이 실패하던 구조를 제거했습니다.

- 이제 방 이름·channelId를 읽지 않고 **봇 설치본 ID**를 기준으로 연동합니다.
- 같은 설치본을 쓰는 방의 모든 사용자가 `5인파티`, `2인파티`, `구인현황`, 내전·스크림·운영 양식을 사용할 수 있습니다.
- `/`를 붙이거나 빼는 기존 명령 문법은 그대로 유지됩니다.
- `/V2연동확인`에는 설치본·키 ID·개인 opaque 발신자 ID가 표시됩니다.
- 처음 설치하면 관리자가 발급한 코드로 `/V2방연동 코드`를 한 번 실행해야 합니다.

중요: 봇 설치본 하나는 카카오톡 방 하나에서만 사용해 주세요. 다른 방에는 별도 설치본을 사용해야 합니다.

업데이트 직전 진행 중인 모집 수정·내전 미리보기·사진 세션은 마치거나 취소해 주세요. 업데이트 뒤 해당 흐름은 새로 시작해야 하며, 사이트에 저장된 기존 데이터는 삭제되지 않습니다.

확인 순서: `/봇버전` → `/V2연동확인` → `/V2진단` → `/V2방연동 코드` → `/V2진단` → `5인파티` → `/구인현황`
