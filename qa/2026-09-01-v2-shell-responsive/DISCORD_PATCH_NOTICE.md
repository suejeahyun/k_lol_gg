## K-LOL.GG V2 모바일 공통 화면 개선

- 홈 인디케이터가 있는 휴대폰에서도 하단 메뉴가 본문과 푸터를 덮지 않도록 안전 영역 여백을 보강했습니다.
- 전체 기능 창을 열었을 때 뒤쪽 페이지가 함께 움직이지 않도록 스크롤을 분리했습니다.
- 검색 창을 열면 검색 입력칸으로 바로 초점이 이동해 키보드로 곧바로 입력할 수 있습니다.
- 스크롤바가 화면 폭을 차지하는 320px 브라우저에서도 가로 스크롤이 생기지 않게 수정했습니다.
- 390×844 실제 브라우저 화면에서 플레이어 목록 최하단과 전체 기능 창을 다시 캡처해 확인했습니다.

V2는 아직 기능 동등성 구축 중이며 운영 사이트에는 반영하지 않았습니다.
