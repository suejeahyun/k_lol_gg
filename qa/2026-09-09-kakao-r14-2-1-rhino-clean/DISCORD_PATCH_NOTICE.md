# 카카오봇 R14.2.1 설치 안내

MessengerBot R 컴파일 화면에 표시되던 `CODE HAS NO SIDE EFFECTS` 경고를 제거한 설치본입니다.

- 기존 명령과 사이트 연동 기능은 그대로 유지됩니다.
- 방 이름을 읽지 않는 설치본 기준 연동도 그대로입니다.
- `/`를 붙이거나 빼는 명령을 모두 지원합니다.
- 서버와 DB는 R14.2에서 변경되지 않아 이미 R14.2가 적용됐다면 재배포할 필요가 없습니다.

기존 봇을 중지하고 새 파일로 전체 교체한 뒤 컴파일해 주세요. 확인 순서는 `/봇버전` → `/V2연동확인` → `/V2진단` → `5인파티` → `/구인현황`입니다.
