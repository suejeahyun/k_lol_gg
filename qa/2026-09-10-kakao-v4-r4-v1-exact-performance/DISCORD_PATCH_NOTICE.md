# 디스코드 복붙용 패치 공지

📢 K-LOL.GG 카카오봇 V1 사용 방식 복구·속도 개선 안내

• 기존처럼 명령어 앞에 `/`를 붙이거나 붙이지 않아도 사용할 수 있습니다.
• 파티 양식, 구인현황, 상세, 명단 반영, 마감 문구를 기존 V1 형식으로 복구했습니다.
• 파티 양식을 불러오기만 해서는 구인현황에 등록되지 않으며, 이름을 작성한 전체 양식을 전송해야 등록됩니다.
• 전적·최근 경기·랭킹에서 티어, 승률, 참여 수, 세트 수, KDA가 기존 형식으로 표시됩니다.
• 내부 서버 처리와 휴대폰 설정 읽기를 줄여 응답 경로를 가볍게 개선했습니다.
