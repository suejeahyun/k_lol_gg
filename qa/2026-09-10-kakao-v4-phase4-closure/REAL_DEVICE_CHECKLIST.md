# 실기기 검증 체크리스트

현재 상태: 미확인. 이번 작업에서는 배포 및 실제 MessengerBot-R 기기 조작을 수행하지 않았다.

- [ ] RECRUIT R2 생성본을 구인방 기기에 설치하고 컴파일 경고 0건을 확인한다.
- [ ] FEATURES R2 생성본을 기능방 기기에 설치하고 컴파일 경고 0건을 확인한다.
- [ ] 두 profile에서 `도움말`, `명령어`, `봇버전`이 서버 로그 없이 즉시 응답하는지 확인한다.
- [ ] RECRUIT에서 `구인도움말`, `구인도우미`가 정확한 문구와 링크로 로컬 응답하는지 확인한다.
- [ ] FEATURES에서 `사진상태`가 사이트 제출 안내만 보여주고 사진 세션을 생성하지 않는지 확인한다.
- [ ] FEATURES에서 `내전확인 ABCDEF`, `내전미리보기취소`가 명단을 변경하지 않는지 로그와 DB로 확인한다.
- [ ] V2 내부 명령과 임의 문장이 서버 callback을 만들지 않는지 확인한다.
- [ ] 공개 PARTY/INHOUSE/SCRIM/PLAYER/OPERATIONS 대표 명령이 callback 1회와 2xx 또는 명확한 4xx를 반환하는지 확인한다.
- [ ] slash 없음/하나가 같고 double slash·slash-space·URL·중간 slash가 무응답인지 확인한다.
- [ ] 운영 로그와 사용자 화면에 501 또는 `ROUTER_NOT_ENABLED`가 나타나지 않는지 확인한다.
