# 디스코드 복붙용 패치 안내

**K-LOL.GG V2 관리자 인증 보안 보강 안내**

- 관리자 인증 앱 코드 활성화/해제 요청에 영속 시도 제한을 추가했습니다.
- 반복 시도는 계정 세션·IP·전체 범위에서 제한되며, 제한 시간은 응답으로 안내됩니다.
- 로컬 합성 로그인은 전용 검증 실행에서만 잠깐 사용할 수 있도록 만료 proof와 실행 프로세스 확인을 추가했습니다.
- 인증 앱 활성화 성공 즉시 화면에 표시된 등록 키를 제거합니다.
- PostgreSQL 18 실제 HTTP 수명주기, 9번째 반복 시도 차단, production fixture 잠금, 빌드, 비밀정보 검사를 통과했습니다.

현재 작업은 V2 로컬 개발 브랜치에만 있으며 운영 Vercel에는 반영하지 않았습니다. 계정 복구·최초 최고 관리자 생성·운영 백업/복구는 후속 검증 대상입니다.
