# K-LOL.GG V40 사이트 우선·번호 없는 등록 개편 보고서

작성일: 2026-08-31 (KST)

## 결론

사이트 소스, DB 마이그레이션 파일, 카카오봇 V40 전체 코드, 회귀 검사와 프로덕션 빌드까지 준비했다. Production 배포, 운영 DB 마이그레이션 적용, 카카오 단말 코드 교체는 수행하지 않았다.

## 사용자 동선

- `/start`: 내전 결과, 경고 차감 사진, 관리자 경고 등록 중 목적을 고르는 공통 시작 화면
- `/account#discipline`: 로그인 사용자의 활성 주의·경고·벤과 사진 제출 진행률
- `/discipline/evidence`: 로그인한 본인의 유효한 과제만 카드로 선택하고 사진을 부분 제출
- `/matches/submit`: 접수번호 입력 없이 미완료 내전 결과를 자동 조회하고 3단계로 등록
- `/admin/discipline/new`: 대상 선택 → 조치 내용 → 확인·발급의 관리자 등록 도우미

## 구현 내역

1. 경고 차감
   - PC·모바일 내정보의 `전체 징계 통계` 버튼을 `경고 차감 사진 제출`로 교체
   - 사용자 화면과 업로드 API 모두 현재 로그인 계정 소유권 적용
   - 여러 과제가 있을 때 자동 선택하지 않아 오등록 방지
   - 만료 과제 제외, 기존 본인 소유 `?code=` 링크는 선택 후 주소에서 제거
   - WR 번호는 사용자 화면과 대상자 안내에서 숨기고 내부 호환 식별자로만 유지
2. 내전 결과
   - MR 번호 입력·표시·복사 제거
   - 로그인 계정의 미완료 WEB 제출 자동 조회
   - 기본 정보 → 사진 → 확인·완료 3단계와 실패 사진부터 재시도
   - `submittedByUserAccountId` 정규 FK·복합 인덱스 및 기존 JSON 소유자 보정 마이그레이션 추가
3. 관리자 경고 등록
   - 대상 검색·직접 입력, 일반/내전 경고 프리셋, 빠른 사유, 최종 요약 제공
   - 완료 안내는 번호가 아닌 고정 사이트 제출 경로 사용
4. 카카오봇
   - 버전: `KLOL_KAKAO_BOT_V40_SITE_FIRST_NO_CODES_R2_2026_08_31`
   - `/등록`, `/내전등록`, `/경고등록`, `/인증`, 현황 명령을 사이트 링크로 전환
   - 코드가 붙은 구형 명령과 과거 양식 붙여넣기도 신규 접수를 만들지 않고 사이트로 안내
   - 구인, 스크림, 전적 등 이번 범위 밖 명령은 유지
5. 고정 양식
   - `/admin/kakao/forms` 페이지·메뉴·CRUD API 삭제
   - 경고·내전 런타임 템플릿을 코드 상수로 고정
   - 과거 접수의 템플릿 스냅샷과 DB 테이블은 감사·호환을 위해 보존
6. 모바일
   - 핵심 등록·제출·관리자 경로가 모바일 홈으로 접히지 않도록 라우팅 보강
   - 관리자 로그인·2차 인증 뒤 최초 목적지 복귀
   - PWA 바로가기에 등록 시작·경고 사진·내전 결과 추가

## 남은 위험·운영 확인

- 실제 운영 계정의 본인 경고 2건 이상 선택과 사진 업로드는 아직 실검증하지 않았다.
- 운영 Blob 업로드, 운영 DB 보정 행 수, 실제 카카오 단말 이미지 세션은 미확인이다.
- 미가입자 직접 경고는 계정 연결 전 본인 제출 화면에 자동 표시되지 않는다.
- 기존 관리 API와 과거 사진 세션은 호환을 위해 남아 있다. V40 텍스트 명령은 해당 쓰기 API를 호출하지 않는다.
- 고정 템플릿을 다음에 수정할 때는 `version` 증가를 검사로 강제하는 후속 패치가 필요하다.
