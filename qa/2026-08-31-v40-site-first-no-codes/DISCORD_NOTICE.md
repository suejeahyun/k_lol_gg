# 디스코드 공지 복붙본

```text
🛠 K-LOL.GG V40 등록·사진 제출 개편 준비 안내

이번 패치는 카카오에서 복잡한 양식과 접수번호를 입력하던 흐름을 사이트 중심으로 바꿉니다.

✅ 새 등록 시작 화면 추가
- 내전 결과 제출
- 경고 차감 사진 제출
- 관리자 주의·경고·벤 등록

✅ 경고 차감 사진
- 내정보에서 바로 이동
- 로그인한 본인의 경고만 표시
- 여러 장을 한 번에 또는 나누어 제출 가능
- 남은 사진 수와 반려 사유를 바로 확인

✅ 내전 결과
- 접수번호 입력 없이 작성 중인 결과 자동 찾기
- 기본 정보 → 사진 → 최종 확인 3단계
- 날짜와 진행자 자동 입력
- 업로드 실패 시 남은 사진부터 재시도

✅ 카카오봇
- /등록 : 쉬운 등록 센터
- /내전등록 : 사이트 내전 결과 제출
- /경고등록 : 관리자 경고 등록
- /인증 : 본인 경고 사진 제출
- 구형 번호 명령과 과거 양식도 새 사이트 화면으로 안내

✅ 모바일
- 휴대폰 한 화면에 맞춘 카드와 큰 버튼
- 관리자 로그인·2차 인증 뒤 원래 화면으로 자동 복귀

현재 소스·테스트·빌드 준비가 끝난 상태이며, 운영 배포와 카카오봇 교체 전입니다. 실제 반영 시 별도 공지하겠습니다.
```
