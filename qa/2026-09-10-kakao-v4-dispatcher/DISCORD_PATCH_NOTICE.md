# 디스코드 복붙용 공지

```text
[K-LOL.GG 카카오봇 V4 디스패처 개발 안내]

카카오봇 V4의 파티·스크림·내전 명령을 기존 서버 데이터와 연결하는 디스패처를 개발 소스에 추가했습니다.

- 파티: 생성, 현황, 상세, 최신 양식 반영, 마감
- 스크림: 생성, 현황, 상세, 최신 양식 반영
- 내전: 현황, 상세, 신청 명단 전체 동기화(0명과 삭제 반영 포함)
- 같은 방에서는 작성자가 아니어도 최신 양식 반영과 파티 마감 가능
- 같은 event ID 재전송은 기존 응답 재사용, 다른 내용 재사용은 충돌로 차단
- 시작 시간·게임 정보 미입력 시 서버에서 기본값 저장
- 더 이상 쓰지 않는 스크림 참가·확정·취소·수동 종료 명령은 안내만 제공

자동 테스트 58건과 TypeScript/ESLint 검사를 통과했습니다.
현재는 개발 소스 반영 단계이며 운영 DB·운영 서버·실제 카카오봇에는 아직 적용되지 않았습니다. 텍스트 명령 분류기와 최종 연결 후 별도 운영 적용·검증을 진행합니다.
```
