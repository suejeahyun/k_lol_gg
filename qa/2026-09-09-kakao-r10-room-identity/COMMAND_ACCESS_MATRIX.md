# Kakao 단일 명령 권한표

| 권한 | 명령 범위 |
| --- | --- |
| MEMBER | 플레이어 조회, 파티/스크림 생성·현황, 스크림 참가, 내전 동기화·현황, 운영 양식 제출 |
| OWNER 또는 MANAGER | 파티/스크림 전체 양식 동기화, 파티 종료, 스크림 확정·완료 |
| ADMIN | 파티/스크림/내전 강제 취소, 스크림 재개, 운영 양식 검토·삭제 |
| SUPER | 방 등록·상태, 멤버 역할, 설치본·설정·로그 관리 |
| INSTALLATION_INTERNAL | 서명된 raw V2 진단/전송. 사람 역할을 부여하지 않음 |

`/` 유무와 V1 호환 명령 여부는 권한을 바꾸지 않는다. 모든 실제 모집 aggregate는 canonical room UUID에 귀속된다.
