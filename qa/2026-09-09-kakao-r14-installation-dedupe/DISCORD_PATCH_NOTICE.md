## 카카오봇 R14 설치본 인증·중복 응답 개선 안내

카카오 명령 한 번에 연동 오류가 여러 번 표시되는 현상을 조사했습니다. 운영 로그에서는 같은 요청의 서버 내부 중복이 아니라 3~13초 간격의 별도 요청 5건이 확인됐고, 모두 휴대폰과 서버의 서명 키 불일치로 차단됐습니다.

R14에서는 아래를 보강했습니다.

- `/봇버전`, `/V2연동확인`에 설치본 ID와 키 ID를 함께 표시
- 설치본별 키·버전·최근 접속·ACTIVE/REVOKED 상태 기록
- 서명 키 교체 시 previous → current 단방향 승격
- 같은 카카오 메시지가 여러 설치본에서 와도 상태 변경과 응답을 한 번만 처리
- 인증 오류·회수된 설치본·미연결 방의 조치 안내 분리
- 관리자 방 화면에 설치본 상태와 마지막 버전 표시
- `/V2진단`으로 휴대폰 설정·HTTPS·서버 응답 단계를 비밀 노출 없이 구분

서버와 DB의 R14 반영은 완료됐습니다. 휴대폰에는 전달받은 `KLOL_KAKAO_BOT_V41_R14_1_DIAGNOSTIC_READY_TO_INSTALL_PRIVATE.js` 한 파일만 설치해야 하며, 같은 방을 보는 기존 봇·스크립트·프로필은 모두 중지하고 R14.1 한 개만 활성화해 주세요. 이 파일은 운영 비밀이 포함돼 있으므로 공개 채널·Git에 올리지 마세요.

설치 후 `/봇버전` → `/V2연동확인` → `/V2진단`을 실행하고 결과를 관리자에게 전달해 주세요. 이어 pairing과 `5인파티` 한 건으로 실제 signed 연동과 중복 방지를 최종 확인합니다.
