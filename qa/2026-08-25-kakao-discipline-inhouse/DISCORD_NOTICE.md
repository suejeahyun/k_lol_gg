📢 K-LOL.GG 경고·내전 결과 접수 패치 안내

• 카카오 `/경고` 양식과 관리자 검토 기능 추가
• 경고 사유는 카카오 양식에 표시하지 않고 관리자 사이트에서만 비공개 입력
• 일반 경고: 부여일부터 30일 내 10판 인증
• 내전 경고: 부여일부터 30일 내 15판 인증
• 주의 3회 누적 시 실제 경고 1회로 전환
• 경고 3회 누적 시 관리자 강퇴 검토 생성
• 카카오 채팅과 사진이 따로 전송되어도 30분 접수 세션으로 자동 연결
• `/내전등록` 양식 접수 후 결과 사진 2장 또는 3장 등록 가능
• 관리자가 사이트에서 사진을 확인한 뒤 기존 내전 등록 화면으로 수기 확정
• 경고·내전 양식은 관리자 페이지에서 버전별 초안/게시 가능
• 사진은 Google Drive가 아닌 비공개 Vercel Blob에 저장

※ 기능은 배포 직후 기본 비활성화 상태이며 DB/Blob/봇 설정 확인 후 순차 활성화됩니다.
