# 카카오봇 R14.3 설치 안내

카카오봇을 두 방 용도로 분리합니다.

- 구인방: 파티·스크림·구인 생성, 현황, 양식 수정, 마감을 모든 이용자가 사용할 수 있습니다.
- 기능방: 내전 신청, 외출 양식, 기록·랭킹 등 일반 기능을 사용합니다.
- 명령 앞의 `/`는 있어도 없어도 동일하게 동작합니다.
- 파티 최초 양식에서 빈 시작시간·게임정보 줄을 없앴습니다. 직접 적으면 반영되고, 비워 두면 현재 시각과 `미입력`으로 저장됩니다.
- 생성·수정·마감 요청 단계를 줄여 응답 대기 시간을 단축했습니다.

각 방은 서로 다른 봇 설치본을 사용합니다. 설치본 하나를 두 방에서 동시에 켜면 안 됩니다. 작업 시간에는 진행 중인 양식 제출을 잠시 멈춰 주세요.

운영 반영 뒤 확인 명령: `봇버전`, `V2연동확인`, `V2진단`, `5인파티`, `구인현황`, `내전구인 협곡`.
