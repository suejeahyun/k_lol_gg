# Riot 플레이어 상세 기능 대응표

확인일: 2026-09-25. 상태: 소스 구현 대응표와 검증 기준. 아래 소스 상태는 배포·운영 데이터 수집 완료를 의미하지 않는다.

## 요청 범위와 관찰 근거

사용자는 플레이어 상세에 모스트 챔피언, 날짜별 변화, 라인별 비율·승률·게임 수, 최근 경기 정보를 요청한 뒤 **참고 사이트 소환사 상세의 기능 전체**를 원한다고 명확히 했다. 참고는 [lol.ps 소환사 상세](https://lol.ps/summoner)의 종합·챔피언·솔로랭크 리포트와 이 화면에 연결된 경기 상세·빌드 기능이다. 참고 사이트 전체의 다른 독립 서비스로 범위를 임의 확대하지 않는다.

2026-09-25 총괄 작업자가 실제 브라우저에서 확인한 공개 화면과 리포트 견본을 아래에 기록했다. 조사 담당자의 검색 도구로는 해당 소환사 URL 본문에 접근하지 못했으므로, 로그인·유료 영역의 내부 동작이나 계산식까지 확인했다고 간주하지 않는다. 원본 디자인·코드·브랜딩이나 독자 평가 공식을 가져오는 작업이 아니라 K-LOL.GG 실제 데이터로 같은 이용 목적을 제공하는 작업이다.

기능 상태를 기록할 때 `구현`, `검증`, `운영 반영`을 구분한다. 일부 최근 경기 기능만 추가한 상태를 이 목록 전체 완료로 표시하지 않는다. 범위 축소, 대체 기능, 외부 의존으로 남는 항목은 릴리스 설명에서 구체적으로 밝힌다.

## 공식 API로 확인한 데이터 경계

2026-09-25 [Riot 공식 API Reference](https://developer.riotgames.com/apis)를 확인했다. API Reference의 공개 상세 문서(`https://developer.riotgames.com/api-details/match-v5`, `league-v4`)는 공식 페이지가 읽는 문서 데이터이며, 운영 API나 인증 우회 경로가 아니다.

- **Account-v1 / League-v4**: 등록 Riot ID를 확인하고 현재 랭크·LP·승패를 가져온다. 과거 날짜별 LP 반환 기능은 이 계약에 없다.
- **Match-v5**: 경기 ID 목록은 기간, 큐, 시작 위치와 개수 필터를 제공한다. 한 번의 목록 요청은 최대 100개다. 경기 상세는 챔피언·참가자·결과·라인·장비·룬·주문·성과를, timeline은 시점별 프레임과 사건을 제공한다. 이 정보에서 계산하는 지표와 API가 직접 주는 필드를 구분한다.
- **정확성**: `teamPosition`을 기준으로 하고, `gameDuration` 단위는 과거 패치와 다를 수 있다. `gameVersion`으로 패치를 정한다. 미지의 선택 필드와 깨진 필드를 같은 상태로 처리하지 않는다.
- **Data Dragon**: 챔피언·아이템·룬·주문 이미지와 한글 이름을 공식 정적 데이터로 연결한다. 클라이언트 패치와 정적 파일 업데이트 시점은 항상 같지 않다. [공식 LoL 데이터 문서](https://developer.riotgames.com/docs/lol#data-dragon)
- **정책·호출량**: 사용자 지정 경기 공개는 별도 opt-in 경계를 지키고, 현재 RSO 미승인 상태에서 이를 우회하지 않는다. 지역·앱·메서드 제한과 `Retry-After`를 준수한다. [LoL 정책](https://developer.riotgames.com/docs/lol#game-policy), [공식 호출 제한 문서](https://developer.riotgames.com/docs/portal#rate-limiting)

공식 API 문서에는 lol.ps의 인분·팀운·리포트 생성 알고리즘이나 완성된 지역 메타 표본이 없다. 이를 같은 숫자로 재현하는 것은 현재 소스 확인만으로 성립하지 않는다. 데이터를 얻지 못한 항목은 실패/부재로 표시하고, 제품의 동등 기능은 검증 가능한 자체 산식과 실제 표본으로 제공한다. 공식 랭크를 대신하는 숨겨진 MMR 추정치는 만들지 않는다.
