# K-LOL.GG 사이트·카카오톡 기능 안내

기준일: 2026-08-26

이 문서는 K-LOL.GG 사이트와 카카오톡봇에서 제공하는 기능, 사용하는 명령어, 두 시스템이 연결되는 방식을 설명한다.

## 1. 전체 연결 구조

K-LOL.GG 기능은 카카오톡에서 양식이나 사진을 접수하고, 사이트에서 상태를 확인하거나 최종 처리하는 방식으로 연결된다.

| 기능 | 카카오톡에서 하는 일 | 사이트에서 하는 일 |
|---|---|---|
| 파티·내전·스크림 구인 | 모집 생성, 명단 수정, 현황 조회, 마감 | 현재 모집과 참가자 확인·관리 |
| 경고 | 경고 양식 접수, 근거사진 전송, 상태 조회, 차감 인증 | 접수 검토, 사유 입력, 승인·반려, 통계 확인 |
| 종료 내전 결과 | `/내전등록` 양식 작성, 2~3장의 결과사진 전송 | 사진 검토 후 기존 내전 등록 화면에서 수기 확정 |
| 운영 신청 | 지인·건의·모임·외출 양식 접수 | 유형별 신청 확인과 상태 처리 |
| 전적·랭킹 | 카카오 명령으로 간단 조회 | 상세 전적, 랭킹, 플레이어, MMR 확인 |

![관리자 홈: 사이트 기능 메뉴와 현재 현황을 확인하는 화면](docs/assets/admin-training/01-admin-dashboard.jpg)

## 3. 카카오톡 공통 기능

| 입력 | 기능 |
|---|---|
| `/봇버전` | 현재 카카오톡봇 코드 버전 확인 |
| `/도움말` | 사용할 수 있는 기능 안내 확인 |
| `구인도우미` | 구인 관련 명령과 사용법 확인 |
| `/경고` | 경고 접수 양식 받기 |
| `/내전등록` | 종료된 내전 결과 접수 양식 받기 |

카카오톡 접수에는 기능별 번호가 발급된다.

| 번호 | 의미 | 예시 용도 |
|---|---|---|
| `#번호` | 파티·내전·스크림 모집번호 | 같은 모집 수정·조회·마감 |
| `DS...` | 경고 접수번호 | `/경고현황 DS접수번호` |
| `WR...` | 경고 차감 인증번호 | `/경고인증 WR인증번호` |
| `MR...` | 종료 내전 결과 접수번호 | `/내전등록현황 MR접수번호` |

## 4. 파티 구인 기능

### 카카오톡

1. `5인파티`, `자랭구인` 등 지원되는 구인 명령을 보낸다.
2. 봇이 모집번호가 포함된 양식을 보내면 내용을 작성해 양식 전체를 전송한다.
3. 참가자를 수정할 때는 헤더의 `#번호`를 유지하고 명단을 수정한 뒤 양식 전체를 다시 보낸다.
4. `구인현황`, `구인상세 번호`로 모집 상태를 확인한다.
5. `12ㅉ`, `#12ㅉ`처럼 봇이 안내한 형식으로 모집을 마감한다.

`#번호`가 사라지면 기존 모집 수정이 아니라 새 모집으로 인식되거나 다른 구인 기능과 충돌할 수 있다.

![카카오톡 파티 구인: 모집 생성과 모집번호 유지 방법](docs/assets/admin-training/08-kakao-party-guide.jpg)

### 사이트

사이트의 구인 화면에서는 진행 중인 모집, 참가자 수, 모집 종류와 상태를 확인한다. 관리자 구인 화면에서는 잘못 생성된 모집이나 완료·취소 상태를 관리한다.

## 5. 내전 구인 기능

### 카카오톡

- `/내전구인 협곡`, `/내전구인 칼바람`, `/내전구인 증바람`으로 내전 종류를 선택한다.
- 명령 뒤에 날짜와 시간을 넣을 수 있다.
- 기존 모집을 수정할 때는 `#번호`가 포함된 원본 헤더를 유지한다.
- `/내전현황`으로 전체 모집을 확인한다.
- `/내전상세 번호`로 특정 모집의 일정과 명단을 확인한다.
- 내전 모집은 설정된 자동 종료 시각에 마감된다.

### 사이트

내전 구인 화면에서는 모집번호, 종류, 일정, 참가자와 현재 상태를 확인한다. 종료된 내전의 실제 경기 결과 등록은 별도의 내전 결과 접수 기능을 사용한다.

## 6. 스크림 기능

### 카카오톡

1. `/스크림구인`으로 양식을 받는다.
2. 우리 팀이 모집번호가 포함된 양식을 먼저 등록한다.
3. 상대 팀은 같은 번호 양식에 팀 정보를 추가한다.
4. `/스크림현황`과 `/스크림상세 번호`로 양쪽 정보를 확인한다.
5. 완료·취소 명령은 봇이 안내한 모집번호를 기준으로 사용한다.

### 사이트

스크림 관리 화면에서는 우리 팀과 상대 팀 정보, 일정, 진행 상태를 확인하고 필요한 상태 변경을 처리한다.

## 7. 경고 기능

### 사진 수 구분

| 사진 종류 | 수량 | 기능 |
|---|---:|---|
| 경고 부여 근거사진 | 0~3장 | 경고 접수 당시 위반 근거 첨부 |
| 일반 경고 차감 인증 | 10장 | 일반 경고 승인 후 30일 안에 한 판당 한 장 제출 |
| 내전 경고 차감 인증 | 15장 | 내전 경고 승인 후 30일 안에 한 판당 한 장 제출 |

근거사진 0~3장과 차감 인증사진 10·15장은 서로 다른 기능이다. 경고 사유는 카카오 양식에 표시하지 않고 사이트에서 비공개로 입력한다.

![카카오톡 경고 기능: 경고 접수와 차감 인증 명령](docs/assets/admin-training/06-kakao-warning-guide.jpg)

### 카카오톡 경고 접수

1. `/경고`를 보내 양식을 받는다.
2. 대상 이름, 닉네임#태그, 일반·내전 구분, 부여일과 근거사진 수를 작성한다.
3. 양식을 보내면 `DS...` 접수번호가 발급된다.
4. 근거사진이 있으면 양식 접수 뒤 사진을 순서대로 보낸다.
5. `/경고현황 DS접수번호`로 접수 상태를 확인한다.

### 사이트 경고 처리

1. 경고 접수 화면에서 `DS...` 접수의 대상, 구분, 날짜와 사진을 확인한다.
2. 승인할 때 경고 사유를 비공개 입력란에 기록한다.
3. 승인되면 일반 10장 또는 내전 15장을 목표로 하는 `WR...` 인증번호가 생성된다.
4. 반려되면 해당 접수 상태와 반려 결과가 저장된다.

![사이트 경고 화면: 주의·경고·벤 정보 입력 화면](docs/assets/admin-training/02-admin-discipline-new.jpg)

### 카카오톡 차감 인증

1. `/경고인증 WR인증번호`를 보낸다.
2. 봇 안내에 따라 한 판당 사진 한 장을 전송한다.
3. `/경고현황 WR인증번호`로 현재 사진 수와 목표 수를 확인한다.
4. 사이트에서 인증이 승인되면 연결된 경고 1건이 차감 처리된다.

사이트 통계에는 주의·경고 수와 벤 상태가 표시되며, 주의 3회는 경고 1회로 전환되고 경고 3회 누적은 강퇴 검토 상태와 연결된다.

## 8. 종료 내전 결과 등록 기능

### 카카오톡

1. `/내전등록`을 보내 양식을 받는다.
2. 진행일, 진행자, 세트 수, 내전 회차와 팀 밸런스 번호를 작성한다.
3. 양식을 보내면 `MR...` 접수번호가 발급된다.
4. 2세트는 결과사진 2장, 3세트는 결과사진 3장을 1세트부터 순서대로 보낸다.
5. `/내전등록현황 MR접수번호`로 사진 수와 접수 상태를 확인한다.

![카카오톡 내전 결과: 2세트·3세트 사진 접수 방법](docs/assets/admin-training/07-kakao-inhouse-guide.jpg)

### 사이트

1. 내전 접수 화면에서 `MR...` 접수의 진행일, 진행자, 세트 수와 사진 순서를 확인한다.
2. `수기 등록 시작`을 누르면 기존 내전 등록 화면으로 이동한다.
3. 사진을 기준으로 각 세트의 선수, 챔피언, KDA와 승리팀을 입력한다.
4. 저장하면 내전 목록과 플레이어 통계에 결과가 반영된다.

카카오톡으로 받은 사진만으로 경기 결과가 자동 확정되지는 않는다. 사이트의 내전 등록 화면에서 최종 저장해야 한다.

![사이트 내전 등록: 사진을 확인한 뒤 세트 결과를 입력하는 화면](docs/assets/admin-training/03-admin-match-new.jpg)

## 9. 운영 신청 기능

카카오톡에서 지인·건의·모임·외출 양식을 작성하면 사이트의 운영 신청 화면에 유형별로 저장된다.

| 유형 | 주요 입력 내용 | 사이트에서 확인되는 내용 |
|---|---|---|
| 지인·디스코드 | 지인 이름, 닉네임, 이용기간, 디스코드 정보 | 신청자와 대상, 기간, 처리 상태 |
| 건의 | 이름, 닉네임, 건의 사유와 내용 | 건의 본문, 접수 시각, 처리 상태 |
| 모임 | 주최자, 일자, 장소, 참여자 | 모임 정보와 참여자 명단 |
| 외출 | 이름, 닉네임, 기간, 사유와 범위 | 외출 기간과 복귀 예정 정보 |

사이트의 `/admin/kakao/operation-forms`에서 접수 유형, 작성 내용과 처리 상태를 확인한다.

## 10. 카카오 자동화 설정 기능

### 기능 켜기·끄기

`/admin/kakao/settings`에서 경고 양식, 경고 현황, 경고 사진, 내전 결과, 구인, 스크림, 전적·랭킹 기능을 각각 켜거나 끌 수 있다.

![카카오 자동화 설정: 경고·사진·내전 결과 기능 스위치](docs/assets/admin-training/04-admin-kakao-settings.jpg)

### 고정 양식 운영

경고와 내전 결과 양식은 코드에 고정되어 있어 관리자 화면에서 수정하거나 게시하지 않는다. 변경이 필요하면 소스의 템플릿 버전을 올리고 테스트·배포한 뒤 카카오봇 안내와 함께 교체한다. 실제 등록과 사진 제출은 `/start`에서 해당 사이트 화면으로 이동해 처리한다.

### 처리 로그

카카오 처리 로그에서는 명령, 접수번호, 처리 결과와 오류 내용을 확인한다. 접수 처리 오류나 중복 인식이 발생했을 때 입력 시각과 명령을 기준으로 찾는다.

## 11. 오류 메시지와 확인 위치

| 카카오톡 응답 | 확인할 사이트 기능 |
|---|---|
| 현재 해당 기능이 중지되어 있습니다 | 카카오 자동화 설정의 기능 스위치 |
| 접수 처리 중 오류가 발생했습니다 | 카카오 처리 로그와 API 처리 결과 |
| 사진 저장 중 오류가 발생했습니다 | 비공개 이미지 저장소 연결 상태와 사진 처리 로그 |
| 이미 접수된 양식입니다 | 기존 `DS...` 또는 `MR...` 접수번호와 상태 |
| 내전구인으로 보이는 메시지입니다 | 내전 모집번호와 원본 양식 헤더 |
| 인원 또는 명단이 맞지 않습니다 | 모집번호가 포함된 양식 전체와 사이트 참가자 목록 |
