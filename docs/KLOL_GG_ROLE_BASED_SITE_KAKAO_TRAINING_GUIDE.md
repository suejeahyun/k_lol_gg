# K-LOL.GG 역할별 사이트·카카오봇 교육자료

기준일: 2026-08-31 KST
대상: 일반 사용자, 승인 사용자, 관리자, 최고관리자
사이트: https://k-lol-gg.vercel.app
카카오봇 소스 기준 버전: `KLOL_KAKAO_BOT_V39_FAST_REGISTRATION_R1_2026_08_31`

이 문서는 K-LOL.GG 사이트와 카카오톡봇의 기능을 역할별로 구분하고, 교육 진행자가 그대로 설명·실습·평가할 수 있도록 만든 통합 교육자료다.

## 2. 역할과 권한 한눈에 보기

| 역할 | 사이트에서 할 수 있는 일 | 카카오봇에서 주로 하는 일 |
|---|---|---|
| 방문자 | 공개 구인·내전·랭킹·플레이어·MMR·대회·징계·콘텐츠 조회 | 도움말, 전적·최근 경기·랭킹 조회, 구인 현황 확인 |
| 승인 사용자 | 방문자 기능 + 참가 신청, Riot 연결·동기화, 본인 정보, 팀 밸런스·밴픽 추천 | 파티·내전·스크림 구인 참여, 운영 신청, 본인 경고 차감 인증 |
| 관리자 | 내전·구인·대회·계정·징계·운영 신청·카카오 자동화·Riot·MMR·콘텐츠 관리 | 경고 접수, 종료 내전 결과 접수, 접수번호 상태 확인 |
| 최고관리자 | 관리자 기능 + 사이트 설정, AI 요청 로그, 감사 로그, 백업·고위험 초기화/권한 변경 | 운영 정책 결정, 비밀값·허용 방·장애 대응 승인 |

관리자 페이지는 승인된 `ADMIN` 또는 `SUPER_ADMIN`만 접근할 수 있다. 최고관리자 전용 메뉴는 일반 관리자 화면에서 숨겨지고 서버에서도 별도 권한을 검사한다.

> 운영 정책: `/경고`는 서버의 `카카오 운영자 이름`과 허용 방을 모두 검사한다. `/내전등록`은 허용된 진행자가 제출하고 사이트 관리자가 최종 확정한다. 카카오는 불변 계정 ID를 제공하지 않으므로 민감한 WR 사진은 로그인 사이트 제출을 우선 권장한다.

### 일반 사용자 기본 실습

1. 홈에서 구인현황과 최근 내전으로 이동한다.
2. 플레이어 이름을 검색하고 랭킹·MMR 정보를 확인한다.
3. 로그인 후 내 정보와 Riot 계정 상태를 확인한다.
4. 승인 사용자라면 팀 밸런스에서 참가자를 선택해 배정안을 만든다.
5. 진행 중 대회 상세에서 참가 신청 위치와 현재 상태를 확인한다.

### 파티 구인

1. `5인파티`, `10인구인`, `자랭구인`, `칼바람구인`처럼 지원되는 명령을 보낸다.
2. 봇이 모집번호가 포함된 양식을 보내면 이름을 추가하고 양식 전체를 다시 보낸다.
3. 수정할 때는 반드시 `모집번호: #번호`를 유지한다.
4. `구인현황`, `구인상세 12`로 진행 상태를 확인한다.
5. `12ㅉ`, `#12ㅉ`, `12번 파티 마감`처럼 번호를 넣어 종료한다.

![카카오톡 파티 구인: 모집 생성과 모집번호 유지 방법](docs/assets/admin-training/08-kakao-party-guide.jpg)

### 내전·스크림 구인

- 내전 구인은 먼저 `/내전구인`을 보내 종목 선택 안내를 확인한다.
- `/내전현황`, `/내전상세 번호`로 모집과 명단을 확인한다.
- `/스크림구인`으로 양식을 받고, `/스크림현황`, `/스크림상세 번호`로 상태를 확인한다.
- 양식 수정 때 모집번호가 포함된 원본 헤더를 유지한다.
- 내전·스크림 모집은 운영 설정에 따라 매일 오전 6시 자동 종료된다.

> 현재 소스 주의: 서버 파서는 `/내전구인 협곡 2026-08-27 21:00 #3 10명` 같은 상세 명령을 지원하지만, 카카오봇 최상위 라우터는 `/내전구인`과 선택적 번호만 명시적으로 인식한다. 운영 단말에서 상세 명령이 응답하지 않으면 `/내전구인`부터 호출하고 카카오 처리 로그에 기록한다.

### 운영 신청

| 신청 유형 | 양식에 유지할 핵심 항목 | 관리자 확인 위치 |
|---|---|---|
| 지인·디스코드 | 지인 이름, 지인 닉네임, 이용기간, 디스코드 닉네임 변경 | 운영 신청 > 지인·디스코드 |
| 건의 | 본인 이름 및 닉네임, 건의 사유, 건의 내용 | 운영 신청 > 건의 |
| 모임 | 주최자 이름 및 닉네임, 일자, 장소, 참여자 명단 | 운영 신청 > 모임 |
| 외출 | 이름 및 닉네임, 외출기간, 외출사유, 외출범위 | 운영 신청 > 외출 |

양식은 항목명을 지우지 않고 전체를 보내야 봇이 유형을 정확히 판별한다.

### 경고 대상자의 차감 인증

1. 관리자 승인 후 받은 `WR...` 인증번호를 확인한다.
2. `/인증 WR인증번호`로 30분 사진 세션을 시작하거나 재개한다. 기존 `/경고인증`도 지원한다.
3. 한 판당 사진 한 장씩 보낸다.
4. 일반 경고는 10장, 내전 경고는 15장을 제출한다.
5. `/경고현황 WR인증번호`로 현재 수량과 기한을 확인한다.

## 6. 관리자 카카오봇 업무 절차

### 경고 등록과 사이트 승인

1. 운영진이 허용된 방에서 `/경고`를 보낸다.
2. 대상 이름, 닉네임#태그, 일반·내전 구분, 부여일, 근거 사진 수 0~3을 작성한다.
3. 양식 전체를 보내 `DS...` 접수번호를 받는다.
4. 근거 사진이 있으면 같은 방·같은 표시 이름으로 30분 안에 한 장씩 보낸다.
5. `/경고현황 DS접수번호`로 상태를 확인한다.
6. `/admin/discipline`에서 대상·구분·날짜·증빙을 확인하고 비공개 사유를 입력한다.
7. 승인 시 `WR...` 차감 인증번호가 생성된다. 반려 시 근거와 상태를 기록한다.

| 사진 종류 | 수량 | 제출 시점과 목적 |
|---|---:|---|
| 경고 부여 근거 | 0~3장 | 운영진이 접수 직후 위반 사실 검토용으로 제출 |
| 일반 경고 차감 | 10장 | 승인된 대상자가 30일 안에 해제 조건으로 제출 |
| 내전 경고 차감 | 15장 | 승인된 대상자가 30일 안에 해제 조건으로 제출 |

경고 사유는 카카오 공개 양식에 적지 않고 사이트 승인 화면에서만 비공개로 입력한다. 주의 3회는 경고 1회로 전환되고, 경고 3회 누적 시 강퇴 검토 건이 생성되며 최종 결정은 관리자에게 있다.

![사이트 경고 화면: 주의·경고·벤 정보 입력 화면](docs/assets/admin-training/02-admin-discipline-new.jpg)

### 종료된 내전 결과 접수

1. 진행자가 허용된 방에서 `/내전등록`을 보낸다.
2. 진행일, 진행자, 세트 수 2 또는 3, 내전 회차, 팀 밸런스 번호와 특이사항을 작성한다.
3. 양식 전체를 보내 `MR...` 접수번호를 받는다.
4. 1세트부터 결과 사진을 순서대로 2장 또는 3장 보낸다.
5. `/내전등록현황 MR접수번호`로 사진 수량과 상태를 확인한다.
6. `/admin/matches/submissions`에서 사진을 확인하고 `수기 등록 시작`을 누른다.
7. 기존 내전 등록 화면에서 선수, 챔피언, KDA와 승리팀을 입력해 최종 저장한다.

카카오 사진만으로 내전 결과가 자동 확정되지는 않는다. 사이트에서 최종 저장해야 통계에 반영된다.

![사이트 내전 등록: 사진을 확인한 뒤 세트 결과를 입력하는 화면](docs/assets/admin-training/03-admin-match-new.jpg)

## 7. 사진 접수와 오류 대응

텍스트 양식과 사진이 별도 메시지여도 서버는 `접수번호 + 방 이름 + 보낸 사람 + 활성 30분 세션`을 함께 확인한다.

- 양식을 보낸 같은 방과 같은 카카오 표시 이름을 사용한다.
- 사진은 PNG, JPG 또는 WebP를 한 장씩 순서대로 보낸다.
- 같은 세션에서 동일한 사진 해시는 중복으로 저장하지 않는다.
- 30분이 지나면 상태 명령 또는 인증 명령으로 세션을 다시 연다.
- 여러 사람이 동시에 제출하고 표시 이름이 같으면 혼선을 피하도록 순서를 나눈다.

| 응답 또는 상태 | 의미 | 다음 행동 |
|---|---|---|
| `PENDING_REVIEW` | 관리자 검토 대기 | 사이트에서 승인·반려 |
| `AWAITING_UPLOAD` | 사진 업로드 대기 | 같은 방·보낸 사람으로 사진 전송 |
| 이미 접수된 양식 | 중복 차단 정상 동작 | 기존 접수번호 사용 |
| 진행 중인 사진 접수가 없음 | 세션이 없거나 30분 만료 | 상태 확인 후 세션 재개 |
| 기능이 중지됨 | 관리자 기능 스위치 꺼짐 | `/admin/kakao/settings` 확인 |
| 사진 저장 중 오류 | 저장소 인증 또는 서버 오류 | 카카오 로그와 비공개 저장소 연결 확인 |

장애 제보에는 발생 시각, 방 이름, 보낸 사람, 입력 명령, 접수번호, 봇 응답을 포함한다. 비밀값·토큰·인증 헤더 원문은 채팅이나 스크린샷에 남기지 않는다.

## 8. 운영 시작·종료 체크리스트

### 매일 시작 전

- 관리자 홈에서 미처리 접수와 오류를 확인한다.
- 카카오 설정에서 필요한 기능만 켜져 있는지 확인한다.
- 카카오 로그에서 인증·서버·사진 저장 오류를 확인한다.
- 진행 중 구인·스크림·내전의 번호와 상태를 확인한다.
- 사진 저장 성공이 확인되지 않았으면 사진 기능을 정상 운영으로 간주하지 않는다.

### 변경 전후

- 변경 대상, 영향 범위, DB 마이그레이션과 환경변수 필요 여부를 기록한다.
- 삭제·전체 초기화·전체 재계산은 백업과 복구 방법을 먼저 확인한다.
- 변경 후 사이트 핵심 화면, `/api/health`, 카카오 `/봇버전`, `/도움말`을 확인한다.
- 사진 1장 저장, 관리자 열람, 동일 사진 중복 차단은 운영 단말에서 별도로 검증한다.

## 9. 60분 교육 진행안

| 시간 | 대상 | 교육 내용 | 완료 기준 |
|---:|---|---|---|
| 0~10분 | 전원 | 역할, 접수번호와 사이트·카카오 연결 구조 | `#`, `DS`, `WR`, `MR` 용도 설명 |
| 10~25분 | 일반 사용자 | 사이트 조회, 계정·Riot, 구인·전적·랭킹 | 플레이어 검색과 구인 상세 확인 |
| 25~35분 | 승인 사용자 | 팀 밸런스, 참가 신청, 경고 차감 인증 | 승인 필요 기능과 공개 기능 구분 |
| 35~50분 | 관리자 | 경고·내전 결과 접수 후 사이트 처리 | DS·MR 접수에서 최종 처리 위치 설명 |
| 50~57분 | 관리자 | 카카오 설정·로그·오류 대응 | 기능 스위치와 로그 위치 찾기 |
| 57~60분 | 전원 | 퀴즈와 운영 주의 확인 | 아래 평가 문항 4개 이상 정답 |

### 실습 시나리오

1. 일반 사용자: `구인현황`에서 모집번호를 찾고 `구인상세 번호`를 입력한다.
2. 승인 사용자: 팀 밸런스 화면이 승인 사용자에게만 보이는 이유를 설명한다.
3. 관리자: 테스트용 `/경고` 양식에서 근거 사진 수 0과 3의 차이를 설명하되 실제 접수는 운영 승인 후 진행한다.
4. 관리자: `MR...` 접수는 사진 업로드만으로 끝나지 않고 사이트 수기 등록이 필요한 이유를 설명한다.
5. 최고관리자: 카카오 허용 방, 기능 스위치와 감사 로그의 책임 범위를 설명한다.

### 이해도 확인

1. 파티 명단을 수정할 때 반드시 유지해야 하는 값은 무엇인가?
2. 경고 부여 근거 사진과 경고 차감 사진의 수량·목적은 어떻게 다른가?
3. `DS...`, `WR...`, `MR...`는 각각 어떤 상태를 조회하는가?
4. 종료 내전 결과 사진을 모두 보낸 뒤 관리자가 해야 할 마지막 단계는 무엇인가?
5. 경고·내전 운영 명령의 발신자 관리자 역할을 카카오 API가 직접 확인하는가?

정답: 1) 모집번호 `#번호` 2) 근거 0~3장, 일반 차감 10장, 내전 차감 15장 3) 경고 접수, 경고 차감, 내전 결과 접수 4) 사이트에서 수기 결과를 최종 저장 5) 아니오. 서버 비밀값과 허용 방을 검사하므로 운영 정책과 방 관리가 필요하다.

- `src/app/api/kakao/image-receive/route.ts`: 방·보낸 사람 세션, 만료와 중복 이미지 처리
- `src/lib/kakao/inhouse-recruit.ts`: 내전 종목·날짜·번호·정원 파서와 선택 안내
- `KLOL_KAKAO_BOT_V39_FAST_REGISTRATION.js`: 실제 봇 전체 코드와 버전 문자열
- 관련 자동 검사: 메뉴 카탈로그, 관리자 API 가드 72개, 구인 라우팅, 운영 양식, 관리 양식, 징계 정책, 봇 관리 라우팅 통과

## 12. 교육 종료 승인 기준

- 일반 사용자가 공개 기능과 승인 사용자 전용 기능을 구분할 수 있다.
- 참가 신청, 팀 밸런스, Riot 연결의 승인 조건을 설명할 수 있다.
- 관리자가 경고와 내전 결과의 카카오 접수부터 사이트 최종 처리까지 설명할 수 있다.
- `#`, `DS`, `WR`, `MR` 번호를 혼동하지 않는다.
- 사진 세션의 같은 방·같은 보낸 사람·30분 조건을 설명할 수 있다.
- 최고관리자 전용 기능과 삭제·초기화·전체 재계산의 위험을 알고 있다.
- 실제 카카오봇·사진 저장·운영 배포 미확인 항목을 확인됨으로 잘못 보고하지 않는다.
