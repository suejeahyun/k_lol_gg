# 운영 징계 통계 v1 QA·배포 증거

## 범위

- 공개 `/discipline` 페이지에 이름, 닉네임, 주의, 경고, 밴 상태 표 추가
- 활성 기록만 사람별 집계
- 주의 3회당 경고 1회로 조회 시 환산
- 모바일 자동 앱 홈 이동에서 `/discipline` 제외
- 390px 모바일 표를 라벨이 있는 카드형 목록으로 표시

## 환산 규칙

- 표시 주의: `활성 주의 % 3`
- 표시 경고: `활성 WARNING + floor(활성 주의 / 3)`
- 밴 상태: 활성 BAN 기록이 하나 이상이면 `밴`
- DB 원본 징계 기록은 변경하지 않음

## 검증 증거

- `tsx tools/check-discipline-statistics.ts`: 통과
  - 주의 7회 + 직접 경고 1회 = 남은 주의 1회, 경고 3회
  - 활성 밴 상태 및 정렬 우선순위 확인
  - 사이트 미등록 대상 집계 확인
- `npm run typecheck`: 통과
- 변경 파일 ESLint: 오류 없음
- `git diff --check`: 오류 없음
- `npm run build`: 통과
  - Next.js 프로덕션 컴파일 성공
  - `/discipline` 동적 경로 생성 확인
- 실제 로컬 렌더링
  - 데스크톱: 요약 카드 4개와 5열 대상별 표 확인
  - 모바일 390×844: `/app` 리다이렉트 없이 `/discipline` 유지
  - 문서 폭 380px, 가로 페이지 넘침 없음
  - 모바일 카드에 이름·닉네임·주의·경고·밴 상태 라벨 확인

## 운영 반영 상태

- 소스 및 로컬 빌드 반영
- 운영 배포 미실행
- 운영 URL은 배포 후 재검증 필요

## 남은 위험

- 과거에 동일 인물이 사이트 등록 기록과 미등록 직접입력 기록으로 각각 저장됐다면 별도 행으로 보일 수 있음
- 이름·닉네임이 공개 정보가 되는 정책 변경이므로 운영진 공개 범위 합의와 개인정보 안내 문구 점검 필요
