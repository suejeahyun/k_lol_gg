# K-LOL.GG 시각 효과 시스템

## 목표

기존의 밝은 sky·lilac·peach 색상과 짙은 navy 타이포를 유지하면서, 기능 중요도에 맞는 깊이·빛·움직임을 더한다. 효과는 정보를 강조하는 수단이며 기능, 읽기, 입력보다 앞서지 않는다.

## 효과 강도

| 등급 | 적용 대상 | 허용 효과 |
| --- | --- | --- |
| Signature | 홈 히어로, 우승, 랭킹 1위, 팀 결과 | 오로라 글로우, 프리즘 하이라이트, 1회 reveal |
| Feature | 구인 카드, 경기 카드, 대회, 미디어 | 상태 스트라이프, surface depth, fine-pointer hover lift |
| Utility | 검색, 필터, 입력, 일반 버튼 | focus ring, border·shadow 전환, 저장 상태 피드백 |
| Operational | 관리자 표·폼·위험 작업 | 선택·성공·경고·실패의 짧은 상태 피드백만 허용 |

## 모션 계약

- 빠른 상태 전환: 140–180ms
- 일반 reveal: 180–240ms, 이동 6–10px 이내
- 히어로 첫 등장: 최대 700ms
- hover lift: 최대 `translateY(-3px)`
- 무한 파티클, 자동 회전 캐러셀, 숫자 카운트업, 모바일 패럴랙스는 사용하지 않는다.
- 애니메이션은 주로 `transform`과 `opacity`를 사용한다.
- `prefers-reduced-motion: reduce`에서는 정보가 즉시 표시되고 모든 장식 모션을 제거한다.
- hover 효과는 `@media (hover: hover) and (pointer: fine)`에서만 실행한다.

## 전체 화면 공통 계층

- 공개·계정·관리자 화면은 하나의 `VisualEffectsController`를 재사용한다.
- 경로 전환과 동적으로 추가되는 카드·패널도 같은 reveal 계약을 적용한다.
- 공개 기능 카드는 `feature`, 관리자 표·폼은 `operational` surface로 구분한다.
- 페이지 상단의 진행선은 현재 세로 스크롤 위치만 표시하며 콘텐츠 높이를 바꾸지 않는다.
- 개별 화면은 상태 의미가 있을 때만 별도 색조를 추가하고 공통 효과를 복제하지 않는다.

## 1.2 확장 효과 계약

- `IntersectionObserver`가 실제 화면에 진입한 section·article·card만 한 번 공개한다. 모션 감소 환경과 미지원 브라우저는 즉시 표시한다.
- sticky header는 세로 스크롤 뒤 경계와 그림자만 또렷해지며 모바일 높이는 커지지 않는다.
- 홈 챔피언 광원은 정밀 포인터·모션 허용 환경의 히어로 이미지에만 적용하고 이동량은 8px 이하로 제한한다.
- `aria-busy`, `role=status`, `role=alert`, `aria-selected`, `data-status`를 공통 로딩·결과·선택 효과의 의미 원본으로 사용한다.
- 구인 정원, 경기 승자·MVP, 접수 진행률, 팀 밸런스 점수·라인 차이, 랭킹 Top 3, 대회 상태·우승은 도메인 값과 연결된 효과만 표시한다.
- 계정·관리자 화면은 저장·대기·성공·실패·선택·focus 상태만 강조하고 반복 장식 모션을 추가하지 않는다.
- 미디어 이미지는 실제 `onLoad` 이후 blur를 해제하고 오류 fallback을 그대로 유지한다.

## 휠 가로 슬라이드 계약

- 마우스 휠의 세로 입력을 가로 이동으로 바꾸는 대상은 사진 캐러셀처럼 순서가 명확한 콘텐츠만 허용한다.
- 일반 페이지, 표, 입력 폼, 비교 그리드의 세로 스크롤은 가로 이동으로 가로채지 않는다.
- 첫 사진에서 위로, 마지막 사진에서 아래로 이동하면 휠을 가로채지 않아 페이지 세로 스크롤이 계속된다.
- 한 번의 휠 동작은 한 장만 이동하고 220ms 동안 중복 이동을 잠근다.
- 좌우 화살표 키, 이전·다음 버튼, 직접 선택 점을 항상 함께 제공한다.
- 자동 재생과 무한 휠 순환은 사용하지 않으며 `prefers-reduced-motion`에서는 전환 모션을 제거한다.

## 성능·접근성 한도

- LCP 2.5초 이하, CLS 0.1 이하
- 전송량 2MiB 이하, JavaScript 700KiB 이하, 요청 75개 이하
- 새 영상·폰트·캔버스·파티클·애니메이션 라이브러리를 추가하지 않는다.
- 색상만으로 상태를 나타내지 않고 텍스트·아이콘·위치를 함께 사용한다.
- 터치 대상은 최소 44px, 키보드 focus는 hover와 동등하게 보이게 한다.
- 모바일에서는 큰 blur와 backdrop-filter를 줄인다.
- Windows forced-colors와 200% 확대에서도 정보와 작업 순서를 유지한다.

## 적용 순서

1. 전역 surface·shadow·glow·motion 토큰
2. 홈과 공통 내비게이션의 Signature 효과
3. 구인·경기·랭킹·팀 밸런스의 Feature 효과
4. 대회·미디어의 콘텐츠 효과
5. 계정·관리자의 가독성과 Operational 피드백
6. 105페이지·339캡처, 접근성·성능, 기능 회귀 재검증
