# 카카오 경고·내전 결과 접수 운영 가이드

## 확정 구조

- 사진 저장소는 **Vercel Blob 비공개 저장소**만 사용한다. Google Drive 연동은 사용하지 않는다.
- 카카오 텍스트와 사진은 별도 메시지여도 `방 이름 + 보낸 사람 + 30분 세션`으로 연결된다.
- 경고 사유는 카카오 `/경고` 양식에 넣지 않는다. 관리자가 사이트에서 승인할 때 비공개로 입력한다.
- `/내전등록`은 결과 사진 2장 또는 3장을 받은 뒤 관리자 사이트의 기존 내전 등록 폼으로 연결한다. 사진만으로 자동 확정하지 않는다.
- 주의 3회는 실제 경고 1건으로 전환하고 사용된 주의 3건은 비활성 처리한다.
- 경고 3회 누적 시 강퇴 검토 건을 만들고 관리자가 최종 확정한다.

## 카카오 명령어

```text
/경고
/경고현황 접수번호또는인증번호
/경고인증 인증번호
/경고인증완료 인증번호

/내전등록
/내전등록현황 접수번호
```

경고 접수 양식에는 대상 이름, 닉네임#태그, 일반/내전 구분, 부여일, 경고 부여 근거 사진 수(0~3)만 포함된다. 이 사진은 위반 사실을 확인하는 자료이며 차감 인증 사진과 구분한다. 관리자 승인 후 일반 경고는 30일 내 서로 다른 게임 사진 10장, 내전 경고는 15장을 한 판당 한 장씩 제출해야 한다. 30분 수신 세션이 끝나면 `/경고인증 인증번호`를 다시 실행해 남은 수량부터 이어서 제출한다.

## 관리자 흐름

1. 경고·내전 양식은 소스 코드의 고정 템플릿을 사용한다. 별도 양식 관리 화면과 게시 절차는 없다.
2. `/admin/kakao/settings`에서 경고·내전 텍스트 접수 및 이미지 접수를 각각 활성화한다.
3. `/admin/kakao`의 `비공개 사진 저장소`가 `정상`인지 확인한다. `확인 필요`면 안내된 인증 방식과 진단 문구를 먼저 해결한다.
4. `/admin/discipline`에서 경고 접수의 증빙을 확인하고 비공개 사유를 입력해 승인 또는 반려한다.
5. 경고 차감 사진을 확인하고 승인하면 연결된 경고 1건만 비활성화한다.
6. `/admin/matches/submissions`에서 결과 사진을 열고 `수기 등록 시작`을 누른다.
7. 기존 내전 등록 폼에서 각 사진을 보며 선수·챔피언·KDA·승리팀을 입력해 확정한다.

## 배포 전 필수 설정

- DB 마이그레이션: `npm run migrate:deploy`
- Vercel Blob 비공개 저장소를 현재 Vercel 프로젝트에 연결한다. 권장 방식은 프로젝트 연결을 OIDC로 업그레이드하고 해당 저장소의 `BLOB_STORE_ID`를 설정하는 것이다. 정적 인증을 유지한다면 해당 비공개 저장소와 일치하는 `BLOB_READ_WRITE_TOKEN`을 Vercel 환경변수에만 설정한다.
- 기존 `KAKAO_RECRUIT_SECRET` 유지
- 기능은 기본값이 꺼져 있으므로 저장소와 봇 적용을 확인한 뒤 관리자 설정에서 단계적으로 켠다.

## 메신저봇R 인증값

봇 소스에는 인증값을 하드코딩하지 않는다. 메신저봇R의 DataBase에 다음 키를 저장한 뒤 봇을 다시 로드한다.

```text
KLOL_KAKAO_RECRUIT_SECRET
KLOL_KAKAO_OPENCHAT_SECRET
KLOL_KAKAO_SEARCH_PLAYER_SECRET
```

실제 값은 서버 환경변수와 같아야 한다. `.mrpack`처럼 실행 파일이 아닌 파일은 Windows에서 직접 실행하지 말고 해당 앱의 가져오기 기능을 사용한다.

`BLOB_READ_WRITE_TOKEN`은 카카오봇 DataBase에 넣지 않는다. Blob 인증은 Vercel 서버에서만 처리하며 카카오봇에는 위의 K-LOL API 인증 키만 저장한다.

## 보안·운영 제한

- PNG/JPG/WebP만 허용하며 카카오 Base64 전송과 Vercel 요청 한도를 고려해 원본 장당 3MB, 4천만 픽셀 이하로 제한한다.
- 원본 Blob은 공개 URL로 노출하지 않고 관리자 인증 프록시를 통해서만 조회한다.
- 자산 메타데이터에 90일 만료 시각을 기록한다. 실제 Blob 정리 작업은 운영 스케줄러 연결 전까지 수동 점검 대상이다.
- 카카오 API 기능 플래그는 기본 비활성화다. 운영 DB와 Blob 설정 없이 활성화하면 안 된다.
- 동시 등록은 접수 건 행 잠금과 `matchSeriesId` 고유 제약으로 중복 확정을 차단한다.
