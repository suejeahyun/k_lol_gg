# 내전 수동 드래그 교환과 이름 복사

- 결정일: 2026-10-18
- 근거: 사용자가 수동 배치는 드래그로만 교환하고, 교환 시 적용 점수와 밸런스가 다시 계산되며, 닉네임 옆 이름 표시와 `BLUE 이름 5명` / `RED 이름 5명` 두 줄 복사를 명시적으로 요청했다.
- 범위: 인증된 소유자 및 기존 관리자 권한으로 조회하는 팀 초안 화면과 해당 화면의 복사 동작.

## 결정

1. 선수 카드 사이 드래그로 두 사람의 자리를 교환한다. 별도 카드 선택·교체 버튼은 제거한다. 키보드 사용자는 같은 드래그 상태를 시작·이동·놓기·취소할 수 있어야 한다. 단순 클릭으로 두 카드를 선택해 교환하지 않는다.
2. 교환 시 공통 도메인 평가로 배정 역할의 적용 점수, 팀 합계, 대면·바텀 격차와 규칙 경고를 즉시 재계산한다. 점수가 같은 교환에서는 숫자가 같을 수 있다. 서버 평가 전 결과는 미리보기이며, 미평가 변경의 저장·복사·경기 접수는 막는다.
3. 카드에 닉네임 스냅샷과 현재 등록 이름을 함께 표시한다. 이름은 표시 전용 optional DTO로 조회 시 추가하며, 과거 점수·배치·참가자 스냅샷·원본 포지션은 수정하지 않는다. 이름을 구할 수 없으면 누락을 표시하며 닉네임을 등록 이름으로 가장하지 않는다.
4. `member_name`의 일반 공개 DTO 제외 원칙은 유지한다. 이번 사용자 요청에 따라 기존 초안 접근 권한 검사를 통과한 응답에서만 등록 이름을 제공한다. 익명·타인 초안 조회의 거절, 비공개 캐시 정책과 기존 관리자 검사를 유지한다. 이름을 로그·연구 자료·공개 QA에 기록하지 않는다.
5. 복사 결과는 탑·정글·미드·원딜·서폿 순의 등록 이름을 사용한 아래 두 줄뿐이다. 경고, 규칙 판정, 점수, URL, 초안 식별자를 덧붙이지 않는다. 화면의 경고와 검증 상태는 유지한다.

```text
BLUE 이름 이름 이름 이름 이름
RED 이름 이름 이름 이름 이름
```

6. 수동 평가 결과를 최선의 자동 추천으로 표시하지 않는다. 기존 인증·소유권·revision·멱등성·과거 초안 호환성은 유지한다.
7. 조합 규칙 1~6은 사용자의 후속 승인에 따라 재설계할 수 있다. 이 승인은 10명·팀별 역할 구성, 개별 바텀 티어 제한과 최소 완화 순서, 누락 티어의 미검증 표시를 변경하지 않는다. 계산식 채택 여부는 별도의 고정된 실험과 검증으로 결정한다.

## 검증 및 배포

합성 자료와 일회성 PostgreSQL에서 생성 → 드래그 → 즉시 미리보기 → 서버 평가 → 저장 → 재평가, 이름 복사, 모바일 표시와 권한 경계를 검사한다. 운영 DB에는 시험 자료를 쓰지 않는다. 구현·실험·배포 상태는 [이번 QA 근거](../qa-evidence/balance-policy-2026-10-18/README.md)에 기록한다.
