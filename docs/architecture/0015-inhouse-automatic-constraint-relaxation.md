# 내전 편성 불가 시 자동 조정

- 결정일: 2026-10-16
- 사용자 요청: “허용 포지션으로 양 팀의 5개 역할을 채우고 … 참가자나 가능 포지션을 조정해 주세요” 오류로 중단하지 말고 요청한 밸런스 기준을 고려해 자동으로 최선의 팀을 생성한다.
- 적용 범위: 사이트 내전 팀 생성·재평가와 그 결과의 선택·수동 평가·저장. 정기 실행 예약과 관계없다.

## 결정

1. 서로 다른 활성 플레이어 10명, 팀당 5명, 탑·정글·미드·원딜·서폿 각 1명이라는 구조와 인증·소유권·revision·멱등성 검사는 유지한다.
2. 먼저 등록된 포지션과 원딜·서폿 각각의 큰 티어 3단계 제한을 모두 지키는 조합을 탐색한다. 가능하면 기존 추천을 그대로 사용한다.
3. 그런 조합이 없으면 같은 10명의 전체 역할 배치를 자동 탐색한다. 바텀 제한 위반 수와 초과 정도를 최소화하고, 그다음 등록하지 않은 역할 배정 인원을 최소화한다. 이어 기존 전력 기준·포지션 부담·조합 규칙 1→6·점수 차이·고정 순서로 비교한다.
4. 미등록 역할은 기존 AUTO 역할 점수로 평가한다. 등록 포지션, 개인 점수, 관리자 보정, MMR이나 티어를 바꾸어 조건을 통과시키지 않는다.
5. 자동 조정 결과에는 해당 선수·역할 또는 바텀 티어 차이와 조정 사유를 보관하고 표시한다. 이를 모든 조건을 만족한 균형 편성으로 표시하지 않는다. 추가 확인 버튼이나 참가자 변경을 요구하며 생성을 막지 않는다.
6. 자동 조정을 적용한 서버 추천을 근거로 해당 초안의 후속 평가·선택·저장에도 같은 정책을 사용한다. 클라이언트가 임의의 완화 허용 플래그를 제출하게 하지 않는다. 일반 초안의 수동 배치는 기존 제한을 유지한다.
7. 과거 초안의 원본 JSON은 그대로 둔다. 사용자가 재평가하면 새로운 계산과 추천을 적용한다. 스키마 migration은 추가하지 않는다.

## 이전 기준과의 관계

이 결정은 사용자의 새 요청에 따라 “가능 포지션과 바텀 제한을 충족하지 못하면 생성 불가”라는 이전 동작을 대체한다. 가능한 경우의 포지션 고정과 바텀 제한, 조합 규칙 1→6 순서는 유지한다. 자동 조정이 실제로 필요했던 경우에만 예외를 명시적으로 기록한다.

“최선”은 현재 등록 자료와 정해진 비교 순서에서 선택한 추천을 뜻한다. 실제 경기 승률이나 모든 참가자의 미등록 역할 숙련도를 보장하는 표현으로 사용하지 않는다.

## 검증

기존 조건을 충족하는 입력의 결과 보존, 포지션 부족·바텀 제한 충돌 시 자동 생성, 결정성, 원본 포지션·개인 점수 보존, 자동 계산과 저장 재평가의 일치, 잘못된 인원·역할 및 권한 차단을 검사한다. 실제 검증 결과와 배포 상태는 [QA 기록](../qa-evidence/inhouse-auto-balance-2026-10-16/README.md)에 남긴다.
