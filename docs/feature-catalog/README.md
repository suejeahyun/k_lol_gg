# V1 → V2 기능 카탈로그

기준 V1은 Vercel 블루·블랙 배포 소스 `8d4d2a4`다.

| 항목 | V1 기준 수량 | V2 처리 원칙 |
|---|---:|---|
| UI 경로 | 156 | 유지·통합·리다이렉트·폐기 사유를 모두 기록 |
| API 경로 | 181 | 새 계약으로 대체하고 권한 행렬 검증 |
| Prisma 모델 | 79 | 이관·재계산·통합·폐기 사유를 기록 |
| 최신 추가 UI/API | 각 2 | 비공개 자산 관리 기능도 필수 상향 기준에 포함 |

## 기능 영역

1. 회원가입·로그인·계정·관리자 TOTP
2. 홈·사이트 설정·탐색
3. 플레이어 검색·프로필·Riot 분석
4. 랭킹·MMR·팀 밸런스
5. 내전 목록·상세·결과 접수·등록
6. 시즌 참가
7. 이벤트전
8. 멸망전·경매·대진·MVP·갤러리
9. 구인·Kakao 자동화
10. 징계·증거·비공개 자산
11. 하이라이트·갤러리
12. Riot·RSO 연동
13. 관리자 운영 데이터·설정·로그·백업·Cron
14. PWA·Android 설치 경험

## 기능 계약 양식

각 기능은 구현 전에 아래 항목을 채운다.

```text
기능 ID:
사용자 유형:
시작 URL:
사전 조건:
입력:
정상 결과:
데이터 변경:
권한 조건:
로딩 상태:
빈 상태:
오류 상태:
외부 부작용:
관리자 조작:
감사 로그:
V1 증거:
V2 인수 테스트:
```

완성 기준은 V2 페이지 수가 아니라 미분류 기능·미검증 흐름이 모두 0인 상태다.
