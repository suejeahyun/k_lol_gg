- 독립 Next.js 코드베이스 생성
- TypeScript·ESLint·Tailwind·shadcn 기반 구성
- 밝은 Community Breeze 디자인 토큰
- 데스크톱 상단 내비게이션·모바일 하단 내비게이션
- V2 전용 아리 히어로 자산
- 검색어·목록·빈 상태를 포함한 합성 플레이어 검색
- 중복 검색 파라미터 정규화와 Node 회귀 테스트
- PlayerRepository 포트와 fixture 어댑터 주입 경계
- 공통 로딩·오류·404 화면
- lint·타입 검사·테스트·빌드를 수행하는 GitHub Actions CI
- 821~1080px 태블릿 내비게이션과 모바일 로그인 접근성 보강
- 일반 본문·버튼 텍스트 WCAG AA 대비 토큰
