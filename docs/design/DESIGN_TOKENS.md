# V2 디자인 토큰

## 방향

밝고 아기자기하며 발랄하고, 하늘과 바람처럼 가볍게 느껴지는 커뮤니티 작업 화면을 만든다. 장식보다 사용자의 핵심 행동이 첫 화면에 먼저 보이게 한다.

## 팔레트

- Sky: `#DFF3FF`
- Lilac: `#EEE7FF`
- Peach: `#FFE8E1`
- Mint: `#DFF7ED`
- Cream: `#FFF9EC`
- Primary: `#426FC0`
- Primary hover: `#365FA8`
- Muted text: `#56667F`
- Accent text: `#356E9F`
- Purple accent text: `#67539B`
- Ink: `#273450`
- Strong Ink: `#17223B`

## 규칙

- 일반 본문·버튼·상태 정보는 가장 밝은 배경에서도 WCAG AA 4.5:1 이상을 유지한다.
- 흰색과 Primary의 대비는 4.92:1이며, 흰색과 Muted text의 대비는 5.83:1이다.
- 여성 챔피언 이미지는 장식과 분위기 전달에만 사용한다.
- 이미지가 없어도 정보·기능·포커스 순서는 완전해야 한다.
- 모서리는 12~32px 범위로 계층화한다.
- 모바일 터치 대상은 최소 44px을 지향한다.
- 애니메이션은 160~220ms 이내로 제한하고 `prefers-reduced-motion`을 지원한다.
- 데스크톱 상단 메뉴와 모바일 하단 메뉴는 같은 정보 구조를 공유한다.
