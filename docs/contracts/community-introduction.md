# 사이트별 공개 소개

GG HUB의 커뮤니티 목록은 방문 링크와 소개 상세 페이지를 제공한다. 소개 원본은 해당 커뮤니티의 DB에 저장하며, 그 사이트의 승인된 ADMIN/SUPER_ADMIN이 `/admin/community-introduction`에서 편집한다. 중앙 HUB 계정·역할과 다른 사이트의 관리 권한은 편집 권한을 부여하지 않는다.

## 내용과 공개

- 한 줄 소개, 상세 소개, 주요 활동, 활동 시간대, 가입 안내, 문의 URL, 배너 이미지 URL을 설정한다.
- 기본값은 비공개다. 공개 여부를 포함한 전체 설정을 명시적으로 저장한다. 비공개 전환은 저장된 소개 삭제를 뜻하지 않는다.
- 이 소개는 사이트 개설 당시의 신청 설명·브랜드 이름·테마·기능 설정과 별도다. HUB의 테마 게시가 사이트 관리자의 소개를 덮어쓰지 않는다.
- 미리보기는 저장 전 내용을 표시하며 공개 저장과 구분한다. 최신 revision 충돌 시 덮어쓰지 않고 재확인을 요구한다.
- 본문은 일반 문자와 줄바꿈으로 표시한다. HTML 실행·임의 iframe·Markdown 실행을 제공하지 않는다. URL은 검증된 HTTPS만 허용한다.

## API와 권한

`/api/admin/community-introduction`의 GET/PUT은 해당 사이트의 관리자 세션을 요구한다. 쓰기는 기존 Origin/CSRF·If-Match·Idempotency-Key 및 트랜잭션 내 계정/세션 재검증 규칙을 따른다. 감사 기록에 변경 주체와 revision을 남긴다. 소개 수정이 기존 사이트 설정이나 회원·경기·모집 자료를 변경하지 않는다.

`/api/community-introduction`의 GET은 공개한 소개만 허용 목록 DTO로 반환한다. 비공개는 404이며 관리자 계정 식별자·세션·내부 메모·비밀 환경 변수를 포함하지 않는다. 관리형 사이트가 소유자 공개 확인 대기 중이면 기존 사이트 공개 차단이 우선한다. HUB 자체에서는 이 두 API와 소개 편집 페이지를 열지 않는다.

## HUB 표시와 원본 조회

공개 상세 주소는 `/community-network/<등록 UUID>`다. LISTED 등록 또는 ACTIVE 관리형 사이트만 조회할 수 있다. 초안·보관·미공개 사이트는 상세 주소를 알아도 표시하지 않는다. 사용자 입력 URL을 외부 조회 주소로 받지 않는다.

소개 상세에서 등록된 정확한 origin의 고정 공개 API만 읽는다. 조회에 회원 쿠키·인증키를 전달하지 않으며 원본 DB를 직접 조회하지 않는다. HTTPS·공개 IP·TLS 인증서를 검증하고 선택한 IP에 연결을 고정한다. 리다이렉트를 따르지 않으며 응답 크기와 전체 대기 시간을 제한한다. DTO의 origin이 등록 주소와 다르면 표시하지 않는다.

상세 소개는 저장해 둔 과거 사본으로 대체하지 않는다. 원본이 비공개·구형 API·장애 상태이면 등록된 기본 설명과 상태 안내를 표시하며 실패를 빈 소개 또는 연결 성공으로 숨기지 않는다. 목록 페이지는 모든 사이트를 동시에 조회하지 않고 등록 정보만 사용한다. 따라서 목록의 기본 설명과 사이트 관리자에게서 읽은 상세 소개는 별도 항목이다.

공개 소개 조회는 일반 회원 계정 연결·제휴·운영 기록 공유·휴대폰 봇 연결을 의미하지 않는다.
