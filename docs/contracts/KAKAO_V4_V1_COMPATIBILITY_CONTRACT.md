# 카카오봇 V4 재설계 — V1 호환 계약

계약 버전: `KLOL_KAKAO_V4_V1_COMPAT_2026_09_10_R1`

이 문서는 V4 구현이 지켜야 할 사용자 관찰 가능 동작을 고정한다. 실행 가능한 단일 원본은 `tests/fixtures/kakao-v4-v1-compatibility-contract.json`이며, 이 문서와 충돌할 경우 픽스처의 정확 문구와 자동 테스트를 우선한다.

## 근거와 판정

- 확인됨: 원본 V1 단일 파일 SHA-256은 `c91a56a289a762fe7e08143e8fd4b55c9695c4df68ebfcb6689613dcb73776b7`이다.
- 확인됨: 기존 V40/V41 골든 테스트가 도움말, 파티, 내전, 스크림, 전적·최근·랭킹, 운영 양식, 등록·경고 안내 문구를 고정한다.
- 확인됨: 현재 도메인은 시작 시간이 없으면 서버 접수 시각을 KST `HH:mm`으로 저장하고 게임 정보가 없으면 `미입력`을 저장한다.
- 확인됨: 현재 애플리케이션 권한은 검증된 동일 정규 방 구성원에게 파티·스크림 수정 권한을 주며 다른 방에서는 대상을 숨긴다.
- V4 요구사항으로 확정: 전체 양식은 권위 있는 스냅샷이며 A→B→A 재수정을 모두 새 리비전으로 수용한다.
- 미확인: V4의 실제 라우터·저장소 구현과 운영 JAR 반영 여부. 이 산출물은 계약과 독립 검증 픽스처만 추가하며 운영 배포를 하지 않는다.

## 1. 공통 입력 경계

명령어는 선행 ASCII `/`가 없거나 정확히 하나 있는 두 형태만 같다. 예를 들어 `도움말`과 `/도움말`, `5인파티`와 `/5인파티`는 같은 라우트와 같은 응답을 가져야 한다.

아래 입력은 명령어가 아니다.

- `//도움말`, `//5인파티`: 선행 슬래시가 두 개다.
- `/ 5인파티`: 슬래시와 명령어 사이가 떨어져 있다.
- `https://k-lol-gg.vercel.app/도움말`: URL 안의 슬래시다.
- `오늘 /내전현황`, `구인/현황`: 문장 중간의 슬래시다.

전체 양식 본문은 명령어 라우팅보다 별도 양식 파서에서 판정한다. 봇 자신이 보낸 운영 양식은 재접수하지 않는다.

## 2. 방·사용자 권한

모집 소유권은 발신자 개인이 아니라 정규화된 모집 방에 귀속된다.

- 검증된 동일 방 사용자라면 최초 작성자가 아니어도 이름 추가·삭제, 전체 양식 수정, 파티 마감을 할 수 있다.
- 다른 정규 방에서는 읽기·수정·마감을 할 수 없다.
- 발신자 ID는 감사 추적에는 남기되 권한 소유자 키로 사용하지 않는다.
- 방 이름 문자열이 아니라 V2 연동으로 확인한 canonical `room-*` ID를 사용한다.

첨부 대화의 `room-ad9195e02863363eb38dc06a27c3af9b`에서 서로 다른 세 `sender-*`가 같은 모집을 수정·마감할 수 있어야 하는 시나리오를 픽스처에 고정했다. `room-6deb4cdee4ea09d71d2e171f4cbbb7b3`은 다른 방 거부 예시다.

## 3. 전체 양식 수정 계약

파티·내전·스크림의 복사 가능한 전체 양식은 부분 패치가 아니라 현재 상태 전체를 나타낸다.

1. A 양식을 보내면 리비전 1에 A 전체가 저장된다.
2. B 양식을 보내면 누락된 A의 이름·필드는 삭제되고 리비전 2에 B 전체가 저장된다.
3. 다시 A 양식을 보내면 과거 내용이라는 이유로 버리지 않고 리비전 3에 A 전체가 저장된다.
4. 이름이 0명이면 현재 명단을 비운다. 파티는 빈 모집, 내전 참가자는 동일 방·동일 회차에서 취소/철회로 처리한다.

동일 배달 ID의 즉시 재전송만 중복 콜백으로 억제할 수 있다. 내용 해시를 영구 중복 키로 쓰면 A→B→A가 깨지므로 금지한다.

## 4. 파티 구인

### 명령과 별칭

| 흐름 | 별칭 |
|---|---|
| 숫자 파티 | `N인파티`, `N인구인` |
| 협곡·랭크 | `5인협곡`, `5인협곡파티`, `5인 협곡 파티`, `자랭구인`, `일반구인`, `솔랭구인` |
| 칼바람·기타 | `칼바람구인`, `증바람구인`, `기타게임구인` |
| TFT | `롤체일반구인`, `롤체랭크구인`, `더블업구인` |
| 현황 | `현재구인구직현황`, `현재구인현황`, `구인구직현황`, `구인현황`, `현황` |
| 상세 | `구인상세 #N`, `상세 N` |
| 마감 | `N쫑`, `#Nㅉ`, `N번 파티 마감`, `N인 구인 종료`, `구인마감 #N`, `구인쫑 #N`, `구인종료 #N` |

최초 템플릿에는 `시작시간`과 `게임정보` 항목을 넣지 않는다. 둘이 비어 있으면 서버가 저장 시점의 KST 현재 시각과 `미입력`을 저장하며, 최초 템플릿이 아니라 현황·상세·수정 결과에서만 보여준다.

전체 양식에는 `모집번호: #N`이 반드시 있어야 한다. 없으면 다음 정확 문구를 보낸다.

```text
[K-LOL.GG 양식 확인 필요]
모집번호를 찾지 못했습니다.

봇이 출력한 원본 양식의 ‘모집번호: #번호’를 유지해서 다시 보내주세요.
```

최초 5인 템플릿, 기본값 상세, 구인 도움말의 정확 줄바꿈은 픽스처에 원문 그대로 들어 있다.

## 5. 내전

생성 별칭은 `내전구인구직`, `내전구인`, `내전모집`이며 종목·날짜·시간·`#모집번호`·`N명`을 뒤에 붙일 수 있다. `내전상세`, `내전현황`, `시즌내전현황`, `AI공지`, `내전참가`, `내전신청`, `참가신청`을 유지한다.

| 종목 | 입력 별칭 | 참가자 필드 | 시즌 명단 반영 |
|---|---|---|---|
| 협곡 | `협곡`, `rift` | 이름/현티어/최고티어/주라인/부라인 | 예 |
| 칼바람 | `칼바람`, `aram` | 이름 | 아니오 |
| 증바람 | `증바람`, `증강칼바람`, `augmentaram` | 이름 | 아니오 |

전체 양식 재전송은 확인창 없이 즉시 같은 방·회차의 참가자 스냅샷을 교체한다. 비어 있는 전체 양식도 유효하며 0명 철회로 처리한다. 지원하지 않는 종목에 대한 정확 종목 선택 안내는 픽스처에 고정했다.

## 6. 스크림

생성은 `스크림구인`, `스크림모집`, `멸망전스크림`, `멸망전스크림구인`, `멸망전스크림모집`을 유지한다. 현황·목록·상세는 `스크림`과 `멸망전스크림` 접두형을 모두 유지한다.

- 신규 전체 양식 제출은 한 번 저장하고 `[K-LOL.GG 스크림 등록 완료]`를 응답한다.
- 기존 번호 전체 양식은 별도 확인 없이 수정 가능한 필드를 교체하고 기존 멸망전 연결을 보존한다.
- `스크림참가`, `스크림확정`, `스크림취소`, `스크림마감/종료` 및 멸망전 접두형은 상태를 변경하지 않고 V1의 사용 중단 안내를 정확히 응답한다.
- 수동 취소·마감 대신 매일 오전 6시 KST 자동 종료를 유지한다.

초기 양식, 빈 현황, 등록 완료, 네 가지 사용 중단 응답의 정확 문구는 픽스처에 있다.

## 7. 전적·최근·랭킹

- `전적 닉네임#태그`: 시즌, 현재/최고 티어, 참여, 전적, KDA, MVP, 최근 경기, 플레이어 링크를 표시한다.
- `최근 닉네임#태그`: 최근 경기와 플레이어 링크를 표시한다.
- `랭킹`: 최소 참여 기준과 TOP 5를 표시한다.

선행 `/` 유무로 조회 대상이나 표시 내용이 달라지면 안 된다. 대표 응답은 픽스처의 `exactReplies.record`, `recent`, `ranking`에 정확히 고정한다.

## 8. 운영 양식

| 양식 | 필수 라벨 |
|---|---|
| 지인 | 지인 이름, 지인 닉네임, 이용기간, 디스코드 닉네임 변경 |
| 건의 | 본인 이름 및 닉네임, 건의 사유, 건의 내용 |
| 정모 | 주최자 이름 및 닉네임, 일자, 장소, 참여자 명단 |
| 외출 | 이름 및 닉네임, 외출기간, 외출사유, 외출범위 |

외출 양식은 `💟간편 공지💟`, `2. 양식작성 후 전송`, `<외출>`, `&lt;외출&gt;` 래퍼를 모두 허용한다. 필드 누락 시 누락 라벨을 순서대로 보여준다. `오픈채팅봇` 발신 양식은 echo로 간주해 저장·응답하지 않는다.

## 10. 사용자 도움말과 V2 운영 진단 분리

사용자용 `도움말`/`명령어`와 `구인도움말`에는 아래 항목을 넣지 않는다.

- `V2도움말`, `V2진단`, `V2연동확인`
- `V2모집`, `V2시즌`, `V2양식`, `V2사진세션`
- raw JSON 입력 예시

이 항목들은 운영자 진단 표면에서만 제공한다. 사용자 도움말에는 V1 명령과 사이트 기반 등록 안내만 노출한다.
