# 디스코드 공지 복붙본

```text
[팀 밸런스 추천·결과 복사 업데이트 완료]

팀 밸런스 추천 방식을 기존 V1 기준에 맞추고, 결과를 채팅에 바로 붙여넣을 수 있도록 업데이트했습니다.

변경 내용
- 여러 후보를 비교하는 대신 전체탐색 최고안 한 개를 먼저 보여줍니다.
- 선택하지 않은 포지션은 자동으로 배정합니다.
- 추천 결과에서 BLUE·RED 포지션과 밸런스 판단을 확인할 수 있습니다.
- `팀 결과 복사`를 누르면 3줄 텍스트로 복사됩니다.
- 복사 내용에는 계정 ID, 내부 번호, 공개 링크나 토큰이 포함되지 않습니다.

사용자 영향
- 팀을 만든 뒤 후보를 다시 고르지 않아도 추천 결과를 바로 확인할 수 있습니다.
- 최근 솔랭 상세 데이터와 관리자 보정값은 현재 V2에 이관되지 않아 계산에 포함되지 않습니다. 화면에서도 이 제한을 안내합니다.

현재 상태
- 최종 소스 검사와 DB·인증·보안 검사는 통과했습니다.
- 운영 공개 화면 30개 조건의 자동 품질 검사와 health 확인을 마쳤습니다.
- 운영 DB의 무결성 준비 작업은 적용 후 중복과 연결 오류가 없는지 확인했습니다.
- 팀 밸런스 화면이 포함된 운영 앱 배포를 확인했습니다.

필요한 행동
- 팀 밸런스 화면에서 새 추천을 확인하고 `팀 결과 복사`를 사용할 수 있습니다.
- 화면이 이전 상태로 보이면 한 번 새로고침해 주세요. 계속 문제가 있으면 사용 중인 화면과 발생 시각을 함께 운영진에게 알려 주세요.

확인 범위
- 로그인·관리자 화면을 포함한 전체 103개 페이지 전수 캡처와 실제 휴대폰 Kakao 두 방 확인은 이번 배포에서 진행하지 않았습니다.
- 실제 사용자 Riot 계정 연결과 파일 업로드 전체 흐름은 추가 확인이 필요합니다.
```
