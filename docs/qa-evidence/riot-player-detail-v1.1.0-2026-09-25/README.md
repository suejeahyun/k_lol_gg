# Riot 플레이어 상세 1.1.0 — 배치와 실제 소환사 이름

PC 종합 화면은 왼쪽 모스트·라인·함께한 소환사, 오른쪽 최근 경기로 나눈다. 상단에는 승률·KDA·분당 CS·킬 관여율을 모으고 고급 필터, 수집 범위, 날짜별 변화와 상대 챔피언 분석은 펼쳐 볼 수 있게 한다. 모바일은 요약 토글과 최근 경기 중심으로 배치하며 경기 상세 표의 내부 가로 스크롤은 유지한다.

함께한 소환사와 참가자 스코어보드는 경기 데이터의 실제 Riot ID를 기본 표시한다. 가리기는 사용자가 선택할 수 있고, 제공되지 않은 이름은 이름 정보 없음으로 표시한다. 현재 이름으로 추정해 바꾸거나 PUUID 등 비공개 식별자를 노출하지 않는다. 기록 없는 라인과 다른 분석 탭의 중복 보조 카드는 제거한다.

로컬 SSR 합성 데이터 브라우저에서 PC 좌우 배치, 필터 적용 24→8경기 및 초기화, 이름 표시/가리기, 모바일 요약 펼침을 확인했다. 320px 경기 상세 스코어보드·분석·타임라인 및 챔피언/리포트 직접 진입에서 문서 너비305px=scrollWidth305px, 새 console 오류/경고0. 360px 기본 화면도 직접 시각 검증했다. 전체 check 및 배포 근거는 이 폴더의 파일로 연결한다.

DB·API·Riot 호출량 변경 없음. 전체106명 동기화는 [별도 실행 기록](../riot-all-sync-2026-09-25/README.md)을 따른다.

운영 1차 확인에서 소환사 이름의 한글/영문 동률 정렬이 서버 기본 영어와 브라우저 기본 한국어 사이에서 달라 React hydration 오류418이 발생했다. 공개 데이터의 로컬 개발 SSR로 재현했으며, 합성 회귀 테스트도 수정 전 실패를 확인했다. 이름 동률 비교에 ko-KR을 명시하고 회귀 테스트를 추가하여 수정 후 영어 서버·한국어 브라우저에서 새 오류0을 확인했다. 최종 소스의 전체 검사·배포 결과는 후속 근거 파일을 따른다.
