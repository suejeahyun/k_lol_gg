# 디스코드 복붙용 공지

```text
[카카오 구인·내전 입력 개선 적용 안내]

카카오 구인 양식과 내전 참가 신청에서 줄바꿈, 번호 표기, 일부 입력 누락 때문에 전체 요청이 실패하던 부분을 개선했습니다.

주요 변경
- 구인 운영일은 매일 오전 6시 기준으로 전환됩니다.
- 오전 6시 전환은 기존 데이터를 삭제하는 작업이 아닙니다.
- 구인 참가자 추가·수정·빈칸 삭제·마감 후 최신 전체 구인 현황이 함께 표시됩니다.
- `1.`, `1)`, `1 `, `1\.` 같은 번호 표기와 들여쓰기를 유연하게 인식합니다.
- 내전 신청의 `Mid all`, `TOP, MID`, 대소문자 포지션, 부라인 공란과 이름만 입력을 처리합니다.
- 한 참가자 행에 문제가 있어도 정상 행은 반영하고, 문제가 있는 행만 확인 필요로 분리합니다.
- 중복 번호는 마지막 입력을 기준으로 하며 마지막이 빈칸이면 해당 슬롯을 취소합니다.
- 사이트 신청, 확정 신청, 다른 방의 신청은 빈칸 취소로 변경하지 않습니다.

현재 상태
- 사이트·서버 v1.0.0 운영 배포와 health 확인을 완료했습니다.
- Git tag는 kakao-recruit-input-recovery-v1.0.0입니다.
- DB migration은 없으며 운영 head 0036_flowery_hairball을 유지합니다.
- R15/R6 휴대폰 설치본은 준비됐지만 실제 휴대폰 복사·컴파일과 카카오방 실사용 검증은 아직 하지 않았습니다.

사이트에서 처리하는 입력 복구는 운영에 적용됐습니다. 휴대폰 봇 동작은 설치본 교체와 실제 두 방 확인 후 별도로 최종 안내하겠습니다.
```
