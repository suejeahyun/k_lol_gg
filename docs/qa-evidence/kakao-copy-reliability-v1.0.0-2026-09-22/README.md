- 서버 상태: **NOT_DEPLOYED**. 이번 작업에서 운영 서버·운영 DB를 변경하지 않았다.

## 제보와 이번 범위

2026-09-21 카카오 대화의 파티 시간·게임 수정 거부, 이름 삭제·교체 거부, 마감된 파티에 보낸 양식의 일반 형식 오류, 내전 무변경 안내 혼동을 소스와 대조했다. 제보 원문과 실제 참가자 이름은 이 폴더와 새 fixture에 복제하지 않았다. 검사는 합성 참가자와 격리 DB를 사용한다.

번호형 `N인파티`의 편집과 관련 오류 안내를 반영했다. [ADR 0011](../../architecture/0011-kakao-party-editable-copy-flow.md)의 전체 화면·응답 흐름을 모두 구현한 릴리스는 아니다. 저장 후 전체 구인 목록으로 바꾸는 흐름, 모든 상세 조회·초안 처리 개선까지 완료했다고 주장하지 않는다. 라인형 파티 등 다른 종목에 번호형 편집 권한을 넓히지 않는다.

| 증상·조건 | 변경한 동작 | 주요 검증 근거 |
|---|---|---|
| 코드가 있는 N인파티에서 이름 삭제·교체 또는 시작·게임 수정 | 발급 원본·현재 저장값·제출값을 비교한다. 바뀐 항목만 반영하며 서로 다른 수정은 합치고 같은 항목의 상충은 거부한다. | `tests/party-copy-snapshot.test.ts`, `tests/recruiting-application.test.ts`, `tests/database/recruiting.contract.test.ts` |

| 구형 협곡 양식의 기존 이름 전용 행까지 라인 누락으로 거부 | 유효 코드가 있는 구형 양식에서 발급 원본과 슬롯·이름·예비 여부가 같은 행만 원본 라인을 보완한다. 신규·교체·이동 이름은 라인이 필요하며 해당 번호를 안내한다. | `tests/kakao-inhouse-legacy-copy-regression.test.ts`, `tests/database/kakao-assistant.contract.test.ts` |

내전 최신 양식의 협곡 라인 필수 계약, SITE·운영진 확정 항목 보호, 실제 회원을 임의 생성·연결하지 않는 규칙은 유지한다. 구형 이름만으로 최신 명단의 다른 참가자를 추정하지 않는다. 오래된 빈 초안에 없던 이름은 현재 같은 이름이 있어도 원본 일치로 인정하지 않는다.

내전 예비 정렬·빈 번호와 시작 문구 중복 방지는 이전 미배포 버전에 이미 반영되어 있어 회귀 검사만 추가했다. 이를 이번 새 구현이나 운영 수정으로 중복 계산하지 않는다.

## 운영 상태와 적용 전 확인

마지막으로 확인된 과거 배포 근거는 2026-09-21 17:33 KST의 `0c188785315cd781a0e828ba1acc69f96acdbf28`, Vercel `dpl_FmnnD2FtSWmTm7Ks6zrZ8it78jF7` READY/production이다. [당시 제공자 기록](../kakao-r24-name-first-2026-09-21/deployment-source.json)과 [읽기 확인 기록](../kakao-r24-name-first-2026-09-21/live-production.json)은 과거 시점의 증거다. 이번 작업에서 현재 운영 SHA를 실시간 재조회하지 않았다.

앞선 `kakao-inhouse-copy@1.0.0`도 [NOT_DEPLOYED](../kakao-inhouse-copy-v1.0.0-2026-09-21/README.md)였다. 이번 로컬 수정과 R25 파일 생성만으로 서버 배포·운영 DB migration·휴대폰 설치가 이루어진 것은 아니다.

운영 적용 시에는 기존 백업/PITR 복구 지점을 확보하고 0041 적용 여부를 확인한 뒤, 확정된 소스의 서버 배포 ID·SHA·health·읽기 smoke를 기록해야 한다. R25 설치 여부와 실제 방의 생성→참가→삭제·교체→시간 변경→상세→마감은 별도로 확인한다. 이전 서버는 0041의 내전 CLOSED 상태를 모를 수 있으므로 단순 서버 롤백만으로 복구 가능하다고 단정하지 않는다. 검증한 forward-fix 또는 사전에 확인한 복구 절차를 사용한다.

남은 범위와 위험:

- 이번 편집은 기존 같은 방의 참여자 권한을 따른다. 새 소유자 전용 편집 권한을 추가한 것은 아니다.
- 양식 일부를 지우면 저장되지 않는다. 취소할 때는 이름만 비우고 번호·예비·양식코드와 나머지 구조를 남겨야 한다.
- 새 협곡 참가자·교체 이름의 라인 생략은 계속 거부한다. 기존 원본에 없는 이름을 자동 회원 연결하거나 ALL로 추정하지 않는다.
- 실제 설치폰 버전, 알림 도착, 응답 지연·전송 실패의 원인은 로컬·VM·DB 검사만으로 확정할 수 없다.
- 사이트 마지막 자리 충원에 대한 카카오방 서버발 자동 푸시는 이번 범위에 없다. 앞선 내전 패치의 전달 제약은 유지된다.
