📢 파티·내전 모집 양식 개선 안내 — 적용 예정

카카오 모집 양식을 복사해 수정할 때 생기던 불편을 개선하는 패치를 준비했습니다.

• 양식코드가 있는 N인파티에서 이름 추가·삭제·교체와 시작·게임 수정을 할 수 있도록 변경합니다.
• 취소할 때는 이름만 지우고 번호 행과 양식코드를 남겨 전체 전송해주세요.
• 다른 사람이 먼저 수정한 내용과 충돌하면 최신 양식으로 다시 작성하도록 안내합니다.
• 이미 마감된 파티, 번호가 빠진 양식, 정원이 찬 경우의 안내를 구체적으로 바꿉니다.
• 예비 명단은 빈 번호까지 번호순으로 보여주고 입력한 한글 자모 표기를 유지합니다.
• 구형 협곡 양식의 기존 이름은 저장된 원본을 확인해 유지합니다. 새로 추가하거나 바꾸는 이름에는 라인을 적어주세요. 예: `이름/top,mid`, `이름/all`
• 내전 변경이 없을 때는 새로 접수된 것으로 오해하지 않도록 안내합니다.

저장 상태가 불확실하면 파티는 `상세 번호`, 내전은 `내전상세 번호`로 최신 명단을 먼저 확인해주세요.
