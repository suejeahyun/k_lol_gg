# 멸망전 자동 평가 수집 보완 후보

- 비중 20/40/20/15/5와 절대 점수 구간은 유지한다.
- 일반 칼바람은 90일에서 시작하여 유효 경기 20판 미만이면 180일, 365일 순서로 조회한다. 기준 종료 시각 고정, 중복 경기 제외, 상세 최대 100판, 한 단계 최대 목록 1회·상세 5회다. 재경기를 제외한 실제 표본으로 확대 여부를 판단한다.
- 도전과제 영문 locale 대소문자·공백·하이픈 표기를 정규화한다. 시즌 접미사, 비활성, 누락 임계값, 중복 이름/ID는 인정하지 않는다. 실제 KR API에서 tracking 필드를 생략하는 것을 확인하여 고정 누적 ID 101301/101302/101307과 각각의 정확한 이름을 함께 검증한다. 명시된 SEASON이나 만료 시각은 거부한다. 실패 사유에는 공개 설정 필드만 남긴다.
- 운영 DB 읽기 전용 분포 점검: 저장된 READY 챔피언 평가가 있는 연결 참가자는 중복 제거 1명, 점수 100이다. 일반 분포로 해석하기에 부족하므로 계산식은 변경하지 않았다.
- [전체 검사](check.txt): 계약 445개, 단위 1022개 통과, 1개 skip, 기존 lint warning 58개, 빌드 통과.
- [격리 PostgreSQL 검사](database.txt): ARAM/ARAM_MAYHEM 자동 수집, 3개 조회 기간, 기존 V1/V2 내전 점수, 계정 변경 및 경매 확정 보호 통과.
- UI 변경은 기존 기준 안내 목록의 문구 한 곳이며 구조와 상호작용은 유지했다. 기존 반응형·접근성 근거는 1.4.0의 별도 기록에 보존한다.
- 공식 스키마 확인: https://developer.riotgames.com/apis#lol-challenges-v1 의 config 문서에서 ENABLED 및 LIFETIME 의미 확인. 진단 배포 9de37c0d의 운영 재평가(2026-09-28T13:16Z)에서는 세 개 모두 ENABLED, 목표 150/75/500, tracking 미제공으로 관측했다. 공개 config의 ID·이름을 결합한 고정 목록을 사용하며 tracking이 있다고 꾸며내지 않는다.

이 문서는 소스 후보의 검증 근거다. 운영 배포와 실계정 결과는 별도 production.md에 기록한다. 비밀값·원본 개인정보를 보관하지 않는다.
