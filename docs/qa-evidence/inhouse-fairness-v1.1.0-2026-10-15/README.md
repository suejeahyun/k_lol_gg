## 재현과 검사

`npx tsx --test tests/team-balance-swap.test.ts`로 합성 10명에서 같은 팀 주→부·기타 교환과 상대 팀 같은 역할 교환을 재현한다. 이전 비율은 각각 88.8%, 98.3%, 90.9%이며 실제 경기 승률이 아니다. 원본 참가자·점수 불변, 교환 되돌리기, 팀 색 교환 대칭도 검사한다.

공정성·동시 탐색 검사는 상하위 규칙 충돌, 전력 기준과 허용 역할, 바텀 3등급 필수 제한, 동점 및 팀 색 대칭을 검증한다. 전체 후보를 독립적으로 정렬한 기준과 추천 결과를 비교한다. UI 검사는 교환 후 미리보기와 적용 전 결과 구분, 복사 텍스트의 실제 전력값 및 구형 평가 안내를 확인한다.

`npm run check`를 통과했다. 계약 711/711, 단위 1,145 pass·기존 skip 1, lint 오류 0·기존 경고 58, 전체 타입 검사·ERD·가이드 이미지·production build PASS다. 격리 PostgreSQL의 `V2_DB_CONTRACT_SCOPE=team-tools npm run test:db`는 6/6, 인증 HTTP와 현재 트리 비밀정보 검사도 통과했다. [검증 수치](validation.json).

별도 집중 검사: 공정성·동시 탐색·도메인 47개, 교환 재현 3개, UI 조작·재시도 22개 PASS. 최대 1,814,400개 배치 탐색은 전체 단위 검사에서 약 1.97초였다(로컬 수치이며 운영 지연 보장은 아님). 독립 코드 검토에서 배포 차단 회귀는 발견되지 않았다.

## 검증 범위의 한계

합성 데이터와 실제 도메인 함수로 현상을 재현했으며, 사용자가 경험한 특정 초안이나 교환한 선수는 조회하지 않았다. 따라서 그 경기에서 어떤 교환·보정이 원인이었는지는 단정하지 않는다. 실제 경기 승률의 통계적 보정은 이 변경에 포함되지 않는다. 운영 점수·경기·계정에 시험 데이터를 쓰지 않는다.
