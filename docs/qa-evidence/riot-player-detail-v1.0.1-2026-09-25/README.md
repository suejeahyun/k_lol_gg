# Riot 플레이어 상세 1.0.1 — 모바일 경기 상세

운영1.0.0의 실제 경기31개 표본에서 360px 화면의 타임라인 펼침 시 문서 폭이345→593px로 늘어나는 문제를 발견했다. 중첩 grid의 자동 열이 표의 최소폭540px를 상속한 원인이다.

공유 stack의 열을 minmax(0,1fr)로 한정하고 자식 min-width를0으로 허용하여 표가 자체 scroll container 안에서 넘치도록 수정한다. 데이터·DB·API 동작은 변경하지 않는다. 기존1.0.0 tag를 이동하지 않는다.

최종 전체 check·새 배포·운영360px에서 참가자/분석/타임라인 각각 재검증 결과는 이 문서의 후속 근거에 연결한다. 전체회원 동기화/외부 데이터 한계는 [1.0.0 QA](../riot-player-detail-v1.0.0-2026-09-25/README.md)를 따른다.
