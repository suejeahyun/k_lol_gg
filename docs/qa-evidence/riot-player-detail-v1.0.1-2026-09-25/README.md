# Riot 플레이어 상세 1.0.1 — 모바일 및 첫 렌더링

운영1.0.0의 실제 경기31개 표본에서 360px 화면의 타임라인 펼침 시 문서 폭이345→593px로 늘어나는 문제를 발견했다. 중첩 grid의 자동 열이 표의 최소폭540px를 상속한 원인이다.

공유 stack의 열을 minmax(0,1fr)로 한정하고 자식 min-width를0으로 허용하여 표가 자체 scroll container 안에서 넘치도록 수정한다. 320px 스코어보드의 밴 챔피언은 줄바꿈을 허용한다.

React 초기 렌더링 오류도 재현했다. SVG title의 여러 JSX 자식은 서버에서 빈 태그가 되었고, 경기 시간의 locale 출력은 Node의 PM과 브라우저의 오후가 달랐다. title을 단일 문자열로 만들고 기존 한국 시간 숫자 포맷을 재사용한다. 필터 날짜도 한국 시간의 숫자 부분으로 조립한다. hydration 경고를 숨기지 않는다.

실제 컴포넌트 SSR 회귀 4개와 기존 UI 테스트 17개 통과. 수정 전 두 오류를 개발모드 브라우저에서 확인했고 수정 후 종합·챔피언·분석 리포트에 새 오류가 없다. 최종 전체 check 및 운영 배포 후 검증은 이 폴더의 checks/deployment/browser-production 근거에 기록한다. 데이터·DB·API 동작은 변경하지 않으며 기존1.0.0 tag를 이동하지 않는다.

전체회원 동기화/외부 데이터 한계는 [1.0.0 QA](../riot-player-detail-v1.0.0-2026-09-25/README.md)와 이 폴더의 production-sync.json 시점별 집계를 따른다. 활성142명 중 연결106명, ID 확인 필요36명이며 ALL106 실행은 관리자 재로그인 대기다. 자동 수집의 일부 성공을 전체 수집 완료로 표시하지 않는다.
