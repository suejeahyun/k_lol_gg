## 카카오봇 R17 내전 양식 수정

내전 종목별 입력 방식을 기존 사용 흐름에 맞게 복구했습니다.

- 파티 구인은 현재 방식 그대로 유지
- 협곡: 티어·라인을 포함한 10명 전체 양식
- 칼바람·증바람: 이름만 적는 10명 전체 양식
- 양식을 작성해 전체 전송해야 내전 생성
- 빠른 추가는 이름만 입력하거나 상세 입력 모두 가능
- 이름만 추가: `내전상세 6 추가 재현`
- 상세 추가: `내전상세 6 추가 재현/M/M/MID/TOP`
- 삭제: `내전상세 6 삭제 재현`
- 마감: `내전 6ㅉ`

휴대폰 확인 버전: `KLOL_KAKAO_BOT_V40_R17_2026_09_14`
