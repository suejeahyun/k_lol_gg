## 요구사항과 변경

협곡·칼바람·증바람을 10명 + 예비로 생성한다. 양식 위에 종목·인원·양식코드를 모으고, 저장 뒤에는 접수 결과와 현재 모집 목록을 표시한다. `내전상세 N`으로 최신 양식을 다시 받는다. 이름·라인·시작 시간·선택 안내를 편집하며 종목·정원·양식코드는 유지한다.

협곡은 본 참가와 예비 모두 라인이 필수다. `이름/top/mid`, `이름/탑/미드`, `이름/top,mid`, `이름/top,all`, `이름/all`을 지원한다. `top,all`은 탑을 주라인으로, 나머지 네 라인을 부라인으로 저장한다. 칼바람·증바람은 이름만 받는다. 라인 누락·오타·중복 이름·불완전한 새 양식은 항목 안내와 함께 전체 저장을 거부한다.

이름을 먼저 접수하고 회원 연결은 나중에 처리한다. 후보 없음은 미가입으로 단정하지 않고 사이트 이름 오타 확인 또는 가입 후 운영진 연결을 안내한다. 여러 후보는 `이름(닉네임)` 구분을 안내한다. 단일 후보도 이름만으로 자동 연결하지 않고 연결 확인 대상으로 알린다. 운영진의 기존 회원 선택 연결 기능과 사이트에서 본인 신청을 수정하는 흐름을 유지한다.

본 참가에 SITE·연결된 KAKAO·미연결 접수를 합산한다. 사이트와 카카오는 같은 잠금을 사용해 동시 신청 시 11번째 본 참가를 막는다. 예비는 직접 선택하며 자동 승격하지 않는다. 사이트 신청과 운영진 확정 행은 카카오 복사 편집으로 덮어쓰지 않는다. 오래된 양식에서 변하지 않은 부분은 최신 값을 보존하고, 같은 항목을 다르게 고친 경우 충돌을 안내한다.

카카오 저장으로 본 참가가 10명이 되는 즉시 아래 문장을 응답한다. 동일 명단 재저장에는 충원 안내를 다시 추가하지 않는다.

> 시작 시간 10분 전 내전 디스코드방에 대기해주세요~

`내전 Nㅉ`는 모집을 닫고 경기용 명단을 보존한다. 마감 상세는 읽기 전용이며 양식코드를 발급하지 않는다. 빈 초안 마감은 작성 취소로 남긴다.

전체 Git 이력 비밀정보 검사는 장시간 실행 후 중단했고 현재 파일 검사를 완료했다. 이번 근거는 전체 이력 재검사 PASS를 주장하지 않는다.

## 운영 적용 전 확인과 복구

현재 운영은 이전 배포 상태다. 본 패치를 배포하려면 기존 DB 백업/PITR 지점을 확보한 후 0041 migration, 해당 tag 서버 배포, 운영 health·읽기 smoke, 실제 카카오방 생성→입력→상세→마감을 확인해야 한다. 테이블 삭제나 임의 down migration을 사용하지 않는다. 새 CLOSED 상태를 모르는 이전 서버로 단순 되돌리기보다 검증한 forward-fix를 사용한다.

휴대폰 파일은 변경하지 않았다. 실제 설치폰 버전·실제 채팅방 송수신 및 로그인한 사이트의 모바일·키보드 화면은 이번 로컬 자동 검사와 별개로 미확인이다. R24의 로컬 도움말 일부는 과거 문구를 유지한다.

**제약:** 사이트에서 마지막 자리가 채워지면 사이트 저장 응답에는 대기 안내가 표시되지만 카카오방으로 즉시 푸시하지는 못한다. 현재 R24는 사용자 메시지에 대한 응답 전달 방식이며 서버발 메시지를 읽는 통로가 없다. 별도 봇 전달 기능 없이 카카오 자동 발송까지 완료했다고 취급하지 않는다. 알림은 예약 발송이 아니다.
