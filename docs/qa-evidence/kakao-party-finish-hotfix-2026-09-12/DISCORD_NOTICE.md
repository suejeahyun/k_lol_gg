# 디스코드 복붙용 공지

```text
[카카오 구인 마감 오류 수정 안내]

구인현황에 표시된 번호에 `15ㅉ`, `16ㅉ`처럼 입력했을 때 입력 형식 오류가 표시되던 서버 조회 문제를 수정했습니다.

변경 내용
- 현재 운영일·현재 구인방의 진행 중 파티만 정확히 마감합니다.
- 같은 방의 다른 사용자가 만든 파티도 기존처럼 마감할 수 있습니다.
- 다른 방이나 지난 운영일의 파티는 잘못 마감하지 않습니다.
- 이미 마감됐거나 현재 운영일에 없는 번호는 입력 오류로 표시하지 않고 최신 구인현황을 다시 보여줍니다.
- `번호ㅉ`, `/번호ㅉ`, `번호쫑`, `# 15ㅉ`, `구인마감 # 15` 형식을 지원합니다.
- 마감이 성공하면 결과 아래에 최신 전체 구인현황이 이어서 표시됩니다.

서버 v1.0.1은 운영 배포됐으며 휴대폰 봇 코드는 바뀌지 않아 재설치가 필요 없습니다.
실제 방에서는 먼저 `구인현황`을 새로 불러온 뒤 표시된 번호로 마감해 주세요.
```
