# 디스코드 복붙용 공지

```text
[카카오 구인 주최자 자동 참가 안내]

2인파티·5인파티 양식에 주최자를 작성해 전송하면, 파티가 활성화될 때 주최자가 1번 참가자로 자동 등록됩니다.

예시
》시작시간 : 모바시
》게임정보 : 증칼
》주최자 : 재현

위 양식을 전송하면 5인 파티는 1/5로 시작하고 참여 명단 1번에 재현이 표시됩니다.

기존 사용 방식은 그대로입니다.
- 양식 불러오는 중 안내는 정상입니다.
- 추가: 상세 번호 추가 이름
- 삭제: 상세 번호 삭제 이름
- 전체 수정: 상세 메시지를 복사해 고친 뒤 전체 전송

주최자를 참가 명단에서 삭제할 수 있으며, 삭제해도 주최자 표시 정보는 유지됩니다. 같은 주최자를 다시 추가할 때는 상세 번호 추가 이름을 사용하면 됩니다.
```
