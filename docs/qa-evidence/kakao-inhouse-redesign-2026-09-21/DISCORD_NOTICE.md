# 구현 후 사용할 디스코드 공지 초안

현재는 설계 단계이며 운영 반영 공지가 아니다. 아래 문구는 명단 보존 마감 정책 확정과 실제 구현·운영 검증 후 사용한다. 외부에 게시하지 않았다.

```text
[K-LOL.GG 내전 모집 이용 방법]

협곡·칼바람·증바람은 본 참가 10명과 예비로 모집합니다.

1. '내전구인 협곡'처럼 종목을 입력해 양식을 받습니다.
2. 시작 시간과 참가자 이름을 적고 양식 전체를 전송합니다. 협곡은 라인도 필수입니다.
3. 저장 결과와 현재 내전 목록을 확인합니다.
4. '내전상세 번호'로 최신 양식을 받아 수정·추가할 수 있습니다.
5. '내전 1ㅉ'처럼 입력하면 모집을 마감하고 경기용 명단은 남깁니다.

사이트 회원 연결은 나중에 해도 됩니다.
협곡은 본 참가·예비 모두 이름과 라인을 적어주세요.
예: 가온/top/mid, 가온/탑/미드, 가온/top,mid
가온/top,all = 주라인 탑, 부라인 나머지 네 개
가온/all = 모든 라인 가능
칼바람·증바람은 이름만 적으면 됩니다.
동명이인은 다온(푸른새)처럼 구분해서 적어주세요.
본 참가가 찼다면 예비 칸에 작성해주세요. 자동 승격은 하지 않습니다.

카카오 양식 저장으로 본 참가 10명이 되면 바로 아래 안내가 나옵니다.
시작 시간 10분 전 내전 디스코드방에 대기해주세요~
안내 후에도 예비 접수는 계속 받습니다.

사이트 신청자는 사이트에서, 운영진 확정 항목은 운영진이 수정합니다.
다른 사람이 먼저 바꾼 항목과 충돌하면 최신 양식으로 다시 작성해주세요.
사이트와 카카오에서 같은 내전 명단과 모집 상태를 확인할 수 있습니다.
```
