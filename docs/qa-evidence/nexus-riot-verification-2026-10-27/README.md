# NEXUS.GG Riot 사이트 검증 1.0.2

Riot Developer Portal에 별도 제품 `NEXUS.GG`의 운영 키 신청을 제출했다. 신청 ID는 `898158`이며 `APPLICATION RECEIVED!` 화면에서 소유 확인 절차를 안내받았다.

## 구현

- `public/riot.txt`를 제품 주소의 `/riot.txt`에서 제공한다. 검증값은 포털이 공개 게시하도록 지정한 값이며 API 키가 아니다.
- 설치된 Next.js public 폴더 안내를 확인했다. 이 경로를 위한 새 동적 API나 DB 변경은 없다.
- 실제 Riot 연동 환경·DB 기능 플래그는 비활성 상태를 유지한다.

## 제출한 운영 정보

사용자 확인에 따라 대회 주최 Yes, 참가비 KRW 0, 상금 KRW 0로 제출했다. 대회 방식·최소 경기 수·공지 일정은 미정으로 기록했고 수치나 날짜를 만들지 않았다. 5v5, 내부 경매 포인트, 관리자·승인 회원 권한은 실제 구현에 맞게 설명했다. 커뮤니티 MMR·공개 순위·팀 배치와 Riot 자료 기반 대회 등급을 숨기지 않고 정책 검토를 요청했다.

## 검증·배포

`npm run check` 통과: lint 오류 0·기존 경고 87, 타입·ERD·가이드 이미지·production build PASS. 계약 741개, 단위 1,201개 PASS와 기존 fixture 1개 SKIP. 현재 추적·비추적 소스 비밀정보 검사 PASS. 공개 검증 파일은 UTF-8 36바이트이며 BOM·따옴표·개행 없이 포털의 지정값만 담는다. 독립 코드 검토에서 proxy, rewrite, 보안 헤더에 이 경로의 차단·인증·리디렉션이 없음을 확인했다.

전체 검사 후 source를 고정해 NEXUS 프로젝트에 배포하고 `/riot.txt`가 리디렉션 없이 정확한 평문을 반환하는지 확인한다. 배포 근거와 포털 확인 결과는 별도 JSON에 기록한다. 신청 접수·사이트 소유 인증·운영 키 승인은 서로 별도 상태다.
