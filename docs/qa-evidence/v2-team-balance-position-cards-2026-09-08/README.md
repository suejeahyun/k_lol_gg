# 팀 밸런스 포지션·수동 배치 카드 패치

## 변경

- 포지션 확인에서 참가자 이름 바로 옆에 `탑·정글·미드·원딜·서포터·전체` 버튼 배치
- 버튼 선택 시 주 포지션을 즉시 반영하고 선택 상태를 `aria-pressed`로 제공
- 선호도와 추가 가능 포지션은 행의 `세부 설정`에서 유지
- 수동 배치의 플레이어 드롭다운 삭제
- 드롭다운 자리에는 참가자의 가능 포지션, 주·부·자동 구분, 밸런스 점수, 신뢰도, 표본 수 표시
- 마우스 드래그와 키보드 2단계 교체 유지
