# 내전 점수 계산·관리 자료 1.1.0 검증

2026-10-10 KST. 사용자의 후속 작업 전체 진행 요청으로 계산 정확도, 관리 화면, 변경 추적과 실제 분포를 개선했다. 운영 회원 점수를 시험 변경하지 않았다.

## 구현

- 티어 편집기가 생성하는 로마 숫자 단계와 접미사 없는 마스터 이상 LP를 계산기가 처리한다. 기존 한글·숫자 단계, LP 접미사, 마스터 층 입력을 유지한다. 층 입력을 프로필에서 다시 저장할 때는 동등한 LP로 변환한다.
- 공식 버전 `V1_BLUEBLACK_AI_GLOBAL_2026_10_10`. 이전 `2026_09_11` 초안은 과거 스냅샷으로 보존하며 새 계산·명시적 재평가부터 새 공식을 적용한다. MMR 공식·원장·generation은 변경하지 않는다.
- 고티어 주포지션 이탈, 인원 분포 차이와 상대 라인 차이 경고를 분리한다.
- 기존 계산 커널을 공유하는 선수별 기준 점수와 포지션별 미리보기, 절댓값 또는 변경량 10점 이상 재확인, 변경 이력과 수정자 식별, 보정 설정 목록·검색·페이지, 티어별 평균·중앙값·인원을 제공한다.
- 미리보기는 각 포지션이 MAIN이라는 가정이다. 실제 편성의 선호 포지션 감점과 구분한다. 통계는 활성 등록 선수 전체를 현재 티어로 묶은 **기준 점수** 분포이며 수동 보정·최근 솔로·포지션 보너스는 포함하지 않는다. 최고 티어와 현재 시즌 내전 기록은 기존 기준 점수 공식에 포함된다. 일반적인 LoL 인구 통계가 아니다.
- 추가 ADMIN 읽기 API는 `GET /api/admin/balance-ai/team-scores`. 같은 READ ONLY REPEATABLE READ transaction과 요청 시각으로 조회하고 200명씩 계산한다. 10,000명 초과는 일부를 전체 평균으로 표시하지 않고 실패한다. 기존 override GET/POST, 동시성·멱등성·감사 저장과 최고 관리자 전용 MMR 변경 권한을 유지한다. migration head `0047_usage_analytics` 유지.

- 도메인·등록부·계정·관리자 관련 단위 46/46 통과: 실제 편집 포맷 왕복, 7티어×4단계, LP 경계·상한, 마스터 10개 층, 모든 포지션의 미리보기/실제 계산 일치와 0점 하한.
- 새 조회 HTTP 3/3, 격리 PostgreSQL team-tools 5/5 통과. 201명 배치 경계, 비활성 제외, 통계 평균·중앙값, 0점 해제 이력, 검색 escape·페이지, 수정자 fallback·응답 정보 제한, 조회 중 동시 저장의 스냅샷 일관성을 포함한다.
- `node --import tsx scripts/test-db/verify-team-balance-admin-browser.ts`: 일반 ADMIN의 실제 비밀번호·TOTP 로그인, 키보드 검색·자동 조회, 기준 51.8→보정+25→예상76.8, 변경 확인, DB 저장, 이력·목록·실제 평균47/중앙값46.4, 새로고침, 412 충돌·실패한 재조회에도 입력 유지, 오프라인 동일 요청 재시도, 0점 해제를 통과했다. 1440/390/320px에서 편집·포지션 표·티어 탭 9장 및 가로 넘침을 검증했다. 합성 자료만 사용했다.
