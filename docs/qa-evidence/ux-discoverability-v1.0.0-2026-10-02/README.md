- 첫 recruiting 실행에서 기존 TOTP 필수 가정의 테스트가 실패했다. 현재 운영 `ADMIN_MUTATION_SESSION_POLICY.adminTotp=OPTIONAL`과 2026-09-30 관리자 비밀번호 로그인 릴리스에 맞게 테스트만 수정했다. 관리자 인증 정책은 변경하지 않았으며, 별도 세션 폐기·계정 상태 변경 경합 검사도 통과했다.
- Windows 줄바꿈으로 byte hash/ERD 검사가 달라지는 기존 파일 4개는 내용 변경 없이 `.gitattributes`에 LF를 고정했다.
- 현재 작업 트리 비밀정보 검사 `node scripts/check-secrets.mjs --tree-only`: PASS. 전체 Git 이력 재검사는 실행 시간이 길어 중단했으며 완료로 보고하지 않는다.
- 전체 DB 영역, 실사용자 만족도, 실제 휴대폰 설치, WCAG 인증을 검증했다는 의미는 아니다.

### 재현 가능한 HTTP 검사

```powershell
$env:PG_BIN_DIR='C:\Program Files\PostgreSQL\18\bin'
```

스크립트는 loopback의 격리 PostgreSQL 18과 합성 데이터만 사용한다. 외부 Origin 403, 동의 누락/예상 밖 필드 400, 과대 요청 413, 같은 키 재요청 201 재응답, 변경 본문 409, 비로그인 관리자 API 401, 관리자 조회 200, 감사 원문 미포함, cron 인증, robots/sitemap, 가입·이벤트 로그인 경로를 확인한 후 서버와 임시 DB를 종료한다. `V2_UX_QA_HOLD=true`이면 브라우저 확인용으로 유지하며 `.tmp/ux-qa/stop` 파일로 정상 종료한다. 합성 로그인 자격증명은 해당 일회성 환경에서만 유효하다.

## 운영 인수사항

1. 문의는 `/admin/operation-forms/suggestions`에서 확인한다. `닉네임 / 답변 연락 방법`을 보고 운영자가 직접 답변한다. 자동 이메일·실시간 상담·답변 기한을 약속하지 않는다.
2. 개인정보 요청은 대상·범위를 확인하고 계정 소유를 검증한 뒤 기존 처리 절차로 진행한다. 문의만으로 계정을 자동 삭제하지 않는다.
3. 새 사이트 문의 본문·연락처는 접수 후 180일 경과분부터 정리한다. 매일 작업과 요청 시 정리가 있으나 서버 장애·백로그가 있으면 지연될 수 있다. 기존 카카오 양식 보존 정책은 변경하지 않는다.
4. 약관/개인정보 문서 버전은 2026-10-02.1. 실제 운영 담당자의 연락처를 임의로 만들어 넣지 않았다. 사업자 운영 여부나 책임자 실명 등의 추가 고지 필요성은 운영 형태에 따라 확인한다.
