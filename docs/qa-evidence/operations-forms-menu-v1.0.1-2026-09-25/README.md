# 운영·감사 UI 1.0.1

징계와 모임·외출·건의사항·디스코드 초대의 목록·상세·처리 폼이 서로 다른 스타일을 사용하고 신청 유형 메뉴가 중복 표시되는 문제를 정리했다. 실제 반복되는 관리자 CSS를 기존 admin token을 쓰는 공통 모듈로 통합했다.

상단 위치 표시와 유형 메뉴를 하나의 고정 헤더로 묶었다. 메뉴 순서는 징계·모임·외출·건의사항·디스코드 초대·전체 신청이며 모바일에서는 메뉴 내부만 가로 스크롤되고 현재 메뉴가 보이는 위치로 이동한다. 내부의 중복 유형 메뉴를 제거하고 기존 유형·상태 필터와 건수 안내를 유지했다. 제목, 카드, 상태 배지, 버튼, 입력, 오류·빈 화면, 상세 표를 통일했다.
