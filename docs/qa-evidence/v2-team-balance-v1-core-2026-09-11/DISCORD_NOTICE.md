# 디스코드 공지 복붙본

팀 밸런스 추천 방식을 기존 V1 기준으로 정리했습니다.

- 세 가지 후보 비교 대신 V1 전체탐색 최고안 한 가지를 바로 추천합니다.
- 주/부 포지션과 미선택 포지션의 자동배정 기준, 고티어·라인·팀 총점 위험 판단을 V1 방식으로 계산합니다.
- 추천 결과는 BLUE/RED 포지션 순서와 예상 승률을 포함한 3줄 텍스트로 복사할 수 있습니다.
- 수동 드래그/키보드 교체, 서버 재평가, 저장, 경기 결과 접수·관리자 경기 등록 연결은 그대로 유지됩니다.

현재는 소스·테스트·빌드까지만 확인했으며 운영 서버에는 아직 반영되지 않았습니다.
