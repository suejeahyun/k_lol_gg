# V2 실사이트 검수 후 통합 패치 증거

## 범위

- 팀 밸런스 자동 후보를 `종합 균형`, `라인 균형`, `주 포지션 우선` 기준으로 분리
- 관리자 팀 초안 보관·복구 및 소유자 목록/추천 비노출
- 선택 팀을 관리자 경기 등록 화면에 자동 배치하고 DB 출처를 보존
- 초안 revision·평가 회차·후보 signature·10명 배치를 경기 저장 직전에 재검증
- 진행 중 경기 접수가 연결된 초안의 보관 차단
- 플레이어 프로필 통계의 챔피언 이미지 migration 전후 호환 및 Riot 공개 읽기 분리
- 사이트 시즌 신청과 Kakao 신청의 동일 행 병합 및 봇 입출력 양식 통일
- 징계 기록 수정·취소·증빙 검토를 SUPER_ADMIN으로 제한
- 챔피언·하이라이트·갤러리 관리자 UI를 하이라이트 패턴으로 통일
- 관리자 통계 문구 `참가 행`을 `참가인원 집계`로 변경
