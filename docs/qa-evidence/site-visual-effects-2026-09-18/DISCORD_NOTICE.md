# K-LOL.GG 사이트 시각 효과 업데이트

홈과 주요 기능 화면의 분위기와 정보 가독성을 함께 개선했습니다.

- 홈: 여성 챔피언 안내 이미지와 핵심 메뉴가 더 선명하게 보이도록 깊이·빛·등장 효과를 정리했습니다.
- 구인·경기: 모집 상태, 정원, 주최자, 경기 승패를 카드에서 더 빠르게 구분할 수 있습니다.
- 랭킹·팀 밸런스: 상위 순위, 내 순위, 활성 단계와 팀 결과의 강조를 개선했습니다.
- 이벤트 대회·멸망전: 두 대회의 색감과 진행 상태를 분리했습니다.
- 미디어: 대표 갤러리와 이미지 카드의 비율·포커스·오버레이를 개선했습니다.
- 내 정보·관리자: 입력, 선택, 성공, 경고, 오류 상태와 작은 글자의 가독성을 개선했습니다.

효과는 한 번만 짧게 실행되며 모바일과 모션 감소 설정에서는 부담을 줄였습니다. 새 영상이나 무거운 애니메이션 라이브러리는 추가하지 않았습니다.

검수 결과: 105개 페이지, 339개 화면 캡처, 핵심 브라우저 품질 27건, 프로덕션 빌드와 전체 계약 테스트를 통과했습니다.
