# R24 내전 이름 우선 접수 — 1.1.0

사용자 제보: 실제 카카오 대화에서 내전 복붙 참가·미연결 이름 정정·시작 시간 수정이 거부되고, 미연결 신청이 참가 인원에서 빠지는 문제. 사용자가 **이름으로 우선 접수하고 사이트 회원은 나중에 연결**하는 방식을 선택했다. 첨부 원문과 실제 회원명은 증거 폴더·fixture에 복제하지 않았다.

## 확인된 원인과 범위

| 증상·재현 조건 | 확인 근거·영향 | 조치 |
|---|---|---|
| 미등록 이름이 `(회원 확인 중)`으로만 보이고 인원에서 제외 | DB에는 ACTIVE 신청으로 이미 저장된다. detail/overview가 pending을 제외해 접수와 회원 연결을 혼동한다. | 이름·자리·접수 인원에 포함하고 회원 연결은 별도 관리자 흐름으로 유지 |
| 초기 코드로 시간과 첫 이름을 입력한 뒤 같은 원본에 다음 이름을 추가하면 거부 | 원본 DRAFT의 미정 시간과 현재 활성 시간의 차이를 변경 시도로 거부한다. | 원본·현재·요청 값을 비교해 이미 적용된 시간은 유지하고 추가만 병합 |
| 최신 양식의 21:00을 21:30으로 바꾸면 거부 | 활성 양식의 메타데이터 변경을 일괄 금지한다. | 최신 시간·공지 수정 허용, 상충하는 동시 변경은 거부 |
| 시작 칸에 조건과 시간 문구를 함께 적으면 형식 오류 | modern parser가 HH:mm 또는 미정만 허용한다. | 32자 이내 문구 보존. 명확한 HH:mm만 예약 시각으로 해석하며 `9시`를 임의로 21시로 바꾸지 않음 |
| 확인 중인 자리의 이름을 바꾸면 형식 오류 | 본문과 하단 `확인 N.`을 중복 슬롯으로 읽는다. | 구형 하단 목록보다 본문을 우선하고, 원본과 현재가 같은 미연결 이름만 정정 |
| 회원 연결 뒤 카카오 방에서 신청이 빠질 수 있음 | 기존 관리자 연결 CREATE/REFRESH에 방·종목 값이 빠져 있다. | 연결 시 원래 방·종목 보존, 다른 방 신청 이동 방지 |
| 결과 문장에만 이름을 적으면 명단 변경 없음 | 실제 번호 칸이 비어 있어 참가 변경이 없는 정상 처리다. | 번호 옆 빈칸을 작성하도록 무변경 응답 보완 |
| `1ㅉ`로 내전 종료 시도 | `1ㅉ`는 파티, `내전 1ㅉ`는 내전 명령이다. | 파티번호 미발견 시 내전 명령 안내 추가 |
| 연결 오류 뒤 다음 조회에는 이름 존재 | 대화만으로 저장 시점·전송 실패 원인은 확정할 수 없다. | 원인 미확인. 재전송 전 상세 조회 안내 추가 |

DB migration·휴대폰 R24 코드 변경은 없다. 회원을 자동 생성하거나 유사 이름을 임의로 동일인으로 연결하지 않는다. 기존 SITE 출처·확정 신청·다른 방 데이터와 삭제 방지를 유지한다. 미연결 신청은 기존 관리자 회원 연결 화면에서 처리하며 일반 공개 신청 페이지의 개인정보 노출 범위는 확장하지 않는다.
