# 실제 자료 기반 팀 편성 연구 방법

본 연구는 한 번의 작업 안에서 실행했다. 정기 작업·예약·운영 참가자·팀·경기 생성이나 수정은 하지 않았다. 최종 숫자는 `experiment-report.json`, 데이터 범위는 `data-inventory.json`, 고정 기준은 `scripts/balance-research/PROTOCOL.md`를 따른다.

## 고정한 자료와 원본 보호

운영 대상의 기존 배포 migration fingerprint와 일치하는 연결에서 `REPEATABLE READ READ ONLY` 트랜잭션을 열어, 실제 `PostgresTeamBalanceRatingProvider`를 같은 시각으로 호출했다. 마지막에는 `ROLLBACK`했다. 현재 Vercel 연결값은 마스킹되어 있어 환경 메타데이터와 이전 운영 근거를 별도로 연결하며, URL·비밀번호·토큰은 출력하지 않는다.

선수명·회원명·Riot ID·계정 ID를 조회하거나 저장하지 않는다. JOIN에 필요한 원본 UUID는 메모리에서만 사용하고, UUID의 사전 순서를 보존하는 익명 라벨로 바꾼다. legacy 선수 순서는 별도 익명 정수로 보존한다. 이 두 순서는 추천 동률 처리와 팀 대칭 제거에서 서로 다른 역할을 하므로 섞지 않는다. 개인 단위 스냅샷은 Git에서 제외된 `.private/balance-research/`에만 둔다.

원본 기준은 commit `c679a1849bad2623da1339b87a83ecaa9fff485b`의 세 도메인 파일이며, 계산식은 `V2_INHOUSE_RELAXED_2026_10_16`이다. 소스·스냅샷·프로토콜·참가자 목록의 해시를 남긴다. 입력 자료나 관리자 보정, 개인 MMR, 등록 포지션을 바꾸어 실험 점수를 높이지 않았다.

## 관측 조합과 가상 조합의 구분

활성 선수는 170명이며 실제 신청 또는 초안의 등록 역할 자료가 있는 선수는 138명이다. 신청 원천 111명, 신청 자료가 없어 초안을 사용한 선수 27명이다. 나머지 32명은 미등록 역할을 추정하지 않고 재조합 풀에서 제외했다. 신청과 초안이 모두 있으면 가장 최근의 유효 신청을 우선한다. 더 최근의 초안이 있더라도 기존 신청을 덮어쓰지 않으며, 이는 최신 등록 선호를 완전히 대표하지 못할 수 있다.

포지션 자료의 경과일은 신청 또는 초안 참가자 레코드의 수정 시각으로만 계산한다. 초안 재평가로 점수만 갱신되어도 이 시각이 바뀔 수 있으므로, 실제로 포지션 숙련도나 선호를 다시 확인한 시각으로 해석하지 않는다.

게시된 104경기는 45개의 고유 10명 조합으로 묶인다. 이 중 활성 상태와 등록 역할 자료가 모두 있는 38개 조합(89경기)을 재현하고, 나머지 7개 조합(15경기)은 해당 조건이 부족해 제외한다. 초안·신청 조합까지 합쳐 중복을 제거하면 관측 조합은 103개다. 추가 897개는 실제 선수를 재조합한 가상 편성 입력이며 실제 있었던 경기라고 부르지 않는다. 합성 경계 사례는 별도 보고하고 이 1,000개에 합산하지 않는다.

등록 역할 부족, 같은 주 역할 집중, 적은 경기 수, 현재 티어 누락, 비슷한 티어와 큰 티어 혼합을 층화했다. 한 주 역할 6명 이상, 내전 5경기 미만 6명 이상 등의 생성 조건은 실제 선수 자료로 검사한다. 동일 10명은 역할·순서·팀 색이 달라도 같은 조합으로 처리한다.

## 비교와 채택 기준

500개 조합은 조정용, 250개는 검증용, 250개는 최종용으로 고정했다. 실제 관측 여부와 각 구성 유형을 고려하여 분리했으며 동일 참가자 집합의 중복은 없다. 후보 선정은 조정용 → 검증용 → 최종용 순으로만 진행하고, 다음 단계 시작 시 입력·프로토콜 해시 일치를 검사한다.

다음 세 가지 선택 계산만 비교한다. 선수별 점수 계산식은 모두 동일하다.

| 선택 계산 | 단일 변경 |
|---|---|
| BASELINE | 운영 기준 그대로 |
| SUB_TIE | 기존 우선순위와 수치 비용이 완전히 같을 때만 양 팀 부포지션 수 차이를 동률 선택에 사용 |
| SUB_SOFT_1 | 기존 모든 상위 우선순위 비교 이후, 수치 비용에 부포지션 수 차이 × 1을 더함 |

등록 역할과 바텀 제한을 충족하는 전체 탐색을 먼저 수행하고, 불가능하면 바텀 제한 위반 수 → 초과 정도 → 미등록 역할 인원 → 기존 전력·부담·규칙 순서로 완화 탐색한다. 규칙 1–6은 사전순으로 비교한다. 한 배치의 대면 지표는 한 번만 계산해 세 후보에 재사용하며, 최대 1,814,400개 배치를 직접 비교한다. strict 탐색 뒤 fallback에서 다시 본 배치는 고유 배치 수에 중복 합산하지 않는다.

후보가 선택한 모든 결과를 동결한 기존 평가 함수로 다시 평가한다. 팀 합계, 각 라인·최대 대면 격차, 원딜과 서폿 개별 격차, 바텀 합계, 주·부·기타·미등록 배정, 부담 쏠림, 규칙별 위반, 자료 부족을 함께 기록한다. 평균뿐 아니라 악화 사례와 집단별 평균·최대값도 검사한다. 후보 자체의 새 점수만 좋아진 것을 개선으로 채택하지 않는다.

조정용 500개에서 SUB_TIE는 결과가 모두 같아 추가 효과가 없었다. SUB_SOFT_1은 부포지션 쏠림을 줄인 28개에서 기존 고정 기준의 비용을 악화시켰고, 이 중 총 양보 부담이 오히려 늘어난 사례도 8개 있었다. 사전 기준에 따라 둘 다 기각했다. 이후 500개는 기존 계산식의 범위·최악 사례·시간을 조사하는 감사로만 실행하고, 기각한 후보를 검증·최종 자료로 재선정하지 않는다.

주·부·기타 감점, 역할 MMR 계수, 표본 신뢰도, 과거 기록 감쇠·최근 기록 비중은 변경하지 않는다. 원딜과 서폿을 합쳐 제한을 통과시키지 않고 개별 현재 티어를 사용한다. 현재 티어가 없으면 정보 부족 상태를 유지한다. 기존 티어 환산 항목의 기본값(현재 티어 미제공 시 최고 티어 점수의 80%, 둘 다 미제공 시 30점)은 실측 자료나 검증된 현재 티어로 해석하지 않는다. 두 티어와 내전 성적이 모두 없으면 내전 항목의 기존 기본값 50을 합쳐 최종 개인 기준은 32점이다. 누락 원본 값을 채운 것이 아니며 제한 검증에 사용하지 않는다.

## 시간 누출과 예측 한계

104경기는 2026-04-29부터 2026-09-24까지의 게시 자료다. 경기 전 초안과 연결된 게시 시리즈는 0건이다. 현재 티어의 과거 관측 시각도 완전하게 재구성할 수 없다. 현재 MMR·현재 티어·경기 후 통계를 과거 경기의 예측 입력에 넣지 않았으며, 승패 예측이나 보정 성능을 검증했다고 주장하지 않는다.

관측된 10명 조합을 현재의 동일 시점 자료로 다시 편성하는 평가와, 실제 과거 승패 예측은 별개다. 가상으로 만든 팀의 승패는 알 수 없으며 이번 결과를 실제 승률 개선으로 표현하지 않는다. 자료가 부족해 점수 계수 변경 근거를 얻지 못한 항목은 유지한다.

재현 명령과 단계별 실행 조건은 `scripts/balance-research/README.md`에 있다. 초기 익명화 순서 및 지표 반올림의 구현 오류는 후보 결과를 해석하기 전에 수정하고 중단된 실행은 폐기했다. 최종 집계에는 수정된 스냅샷과 중복 없는 최종 실행만 사용한다.
