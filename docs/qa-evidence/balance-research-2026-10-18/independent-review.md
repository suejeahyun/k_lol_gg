# 실험·사용 흐름 독립 검토

2026-10-18 Asia/Seoul. 실험 작성자와 별도로 코드, 고정 프로토콜, 익명화 회귀, tuning 결과를 검토했다. 운영 자료를 추가 조회하거나 수정하지 않았다. 결과 검토는 익명화된 로컬 자료에서 집계만 출력했다.

## 채택 판정 재계산

최종 tuning JSONL 500건을 직접 읽어 위험 벡터의 사전식 비교, 포지션 부담 판정, 집단별 평균·최댓값 검사를 다시 계산했다. 요약 파일과 다음 값이 모두 일치했다.

| 후보 | 개선 | 유지 | 악화 | 위험 벡터 악화 | 배치 변경 | 집단 검사 탈락 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| SUB_TIE | 0 | 500 | 0 | 0 | 0 | 0 |
| SUB_SOFT_1 | 0 | 472 | 28 | 28 | 28 | 8 |

`SUB_TIE`는 독립 개선이 없고 `SUB_SOFT_1`은 5.6%에서 악화하여 두 후보 모두 채택 조건을 충족하지 못한다. `survivors=[]`, `selected=null`은 기존 계산식 유지라는 사전 규칙에 맞다. 집단별 악화 8건은 서로 겹치는 집단이며 선수나 참가자 조합 8개를 뜻하지 않는다.

- tuning 참가자 조합: 500개 모두 고유하며 manifest의 tuning 집합과 일치.
- tuning 고유 후보 배치: 459,361,632개. JSONL 합계와 요약 일치.
- snapshot SHA-256: `aecb6d6f5767f21ec1225427aea5c32e53a657bd4ede4319b50d0e498cd5e75d`.
- protocol SHA-256: `1a9c6c3339af97365373b714f35c0c7cc4835fcf3f50341921b57e1bac1007d4`.
- protocol lock의 snapshot·protocol·roster manifest 해시가 실제 파일과 일치.

전체 1,000개 조합을 보고할 때는 **후보 비교 500개**와 후보 탈락 후의 **기존 계산식만 검사한 나머지 500개**를 구분해야 한다. 나머지 집합에서 탈락 후보를 재선정하거나 최종 평가를 통한 개선을 주장하지 않는다.

## 익명화와 측정 점검

초기 익명화가 legacy 순서로 ID를 부여하여 UUID 사전순에 따른 동률 선택을 바꾸는 문제를 발견했다. 수정된 `createResearchPlayerIdentity`는 UUID 순서와 legacy 순서를 각각 보존한다. 실제 원본 UUID와 대응표는 파일에 쓰지 않는다.

`tests/team-balance-research-anonymization.test.ts`의 합성 자료 회귀 2/2와 해당 파일 lint가 통과했다. UUID·legacy 순서를 반대로 두고 nullable/tied legacy를 포함한 10명에 대해 원본과 익명 결과의 역매핑 배치·점수가 동일하다. 이전의 잘못된 매핑은 실제 다른 추천을 만든다는 민감도 검사도 통과했다. bigint 문자열과 10,001명에서의 ID 자릿수도 확인했다.

주 포지션 수·신뢰도 증가의 개선 방향과 반올림 후 경계 검사도 수정 확인했다. 참가자 조합의 중복·입력 순서·팀 색을 별도 사례로 합산하지 않는다. 경기 전 자료 연결은 0건이므로 실제 승패 예측 성능은 검증할 수 없다.

## 운영 코드 변경과 실제 사용 흐름

운영 도메인 변경은 `noSampleCount`에서 `sampleSize=0`도 표본 없음으로 집계하는 한 줄이다. 이는 진단 수치 수정이며 추천 순위나 선수 전력 점수의 변경이 아니다. 추천 품질 또는 계산 속도를 개선했다고 주장할 근거로 사용하지 않는다. 기존 계산식 식별자는 `V2_INHOUSE_RELAXED_2026_10_16`을 유지한다.

실제 격리 PostgreSQL 18·`next start`·Chromium 검증 17항목은 [browser.json](browser.json)에 기록했다. 생성 → 교환 미리보기 → 서버 평가 → 저장 → 재평가, 도메인 점수 일치, 원본 포지션과 과거 점수 JSON 보존, 소유권·인증·출처·revision·멱등성, 320/390/1440px 화면을 확인했다. 수동 결과는 자동 최선 추천으로 표시하지 않고 미검증 승률도 표시하지 않는다.

운영 데이터 쓰기는 0건이다. 정상 종료 후 일회성 DB가 제거되었고 검증 runner·Next 서버·격리 브라우저 프로세스가 각각 0개임을 확인했다. 이번 검증 이후 계산식이나 정책이 변경되면 브라우저 검증을 다시 실행해야 한다.

## 최종 읽기 전용 재검토

최종 JSONL의 1,000개 고유 조합과 921,331,808개 고유 배치를 다시 합산해 공개 결과와 일치를 확인했다. heldout 500개는 후보 지표가 없는 baseline audit로 저장되었다. 기준 소스 3파일은 Git 원본과 일치한다. 공개 텍스트 29파일에서 원본 UUID·연결 문자열·JWT·토큰 노출을 발견하지 못했다(HTTP 경계의 명시적 합성 UUID 제외).

검토 중 발견한 malformed DB URL 오류의 입력 노출 경로는 고정 오류 코드로 바꿨다. 자료 원천 수정 시각도 `sourceRecordAgeDays`로 정정하여 티어·포지션 갱신 시각이라고 해석하지 않는다. 최종 검토에서 미해결 조치 사항은 없었다.
