# 실제 입력 재현과 독립 조합 비교

사용자가 제공한 본인 초안의 공식 읽기 전용 API를 로그인한 브라우저에서 열고, 화면에 렌더링된 JSON에서 이름·원본 ID·기존 식별자를 제거한 입력으로 로컬 계산을 수행했다. 운영 초안을 반복 생성하거나 수정하는 방식으로 실험하지 않았다. 아래는 비식별 집계 결과이며 원본 참가자 자료는 보관하지 않는다.

## 원래 입력

저장된 10개 배정 점수, 양 팀 합계와 차이가 실제 도메인 재계산과 모두 일치했다. 전적이 없는 7명도 각자 티어·역할에 따라 점수가 달랐다. 단, 현재·최고 티어가 모두 없는 한 명은 임시 기준 32점에서 원딜 부포지션 감점 5점을 뺀 27점이었다. 프로필에서도 두 티어 미등록 및 Riot 미연결을 확인했다.

원래 입력에서는 허용 배치 352개를 비교했다. 추천의 팀 합계 차이는 6.66점, 최대 라인 격차는 8.08점, 원문 조합 규칙 1→6 위반은 모두 0이었다. 추천에서 가능한 45개 두 사람 교환 중 7개가 허용되고 38개는 역할·바텀 조건으로 차단됐다. 허용된 교환에 더 좋은 목적함수 결과는 없었다. 입력 역순과 팀 색상 반전에서도 일관성을 확인했다.

## 사용자 확인 티어로 비교

사용자가 누락된 현재 티어를 골드 IV, 최고 티어를 골드 II로 확인했다. 이 입력의 기준 점수는 43.4점, 현재 초안의 원딜 부포지션 점수는 38.4점이다.

| 입력·배치 | 팀 합계 차이 | 최대 라인 격차 | 규칙 1→6 위반 |
|---|---:|---:|---|
| 원래 자료·원래 배치 | 6.66 | 8.08 | 모두 0 |
| 확인된 티어 반영·원래 배치 유지 | 4.74 | 8.00 | 모두 0 |
| 확인된 티어 반영·재추천 | 1.90 | 8.00 | 모두 0 |

재추천 합계는 252.18 대 250.28점이다. 확인된 티어를 반영한 원래 배치에서 두 원딜을 교환하면 재추천과 같은 팀 구성이 된다. 팀 색상은 다를 수 있으며 운영 추천은 실제 선수 식별자의 동률 결정 순서에 따라 색상이 달라질 수 있다.

production 탐색 함수와 별개로 좌석을 직접 열거해 허용 배치 256개, 제한 위반 672개를 확인했다. 허용 배치 전체에서 추천보다 좋은 목적함수 결과는 없었고 같은 최적값은 1개였다. 재추천의 45개 교환 역시 허용 7개·차단 38개·개선 0개다. 주/부/자동 배정은 3/5/2이며, 자동 포지션의 부담 때문에 조건부 편성 표시는 남는다. 미확인 티어는 0명이다.

## 여러 조건에서 반복 검사

별도 9개 합성 시나리오, 18회 생성, 두 사람 교환 405개에서 현재 비교 기준의 개선 누락, 입력 변형, 팀 색상 비대칭을 발견하지 못했다. 동일 입력을 반복 호출하면 같은 추천이 정상이다. 현재 알고리즘은 최대 126개 팀 분할 × 양 팀 120개 역할 배치, 즉 1,814,400개 배치를 이미 비교한다.

이는 등록 자료와 현재 비교 기준 안에서의 최적성 검사다. 실제 경기 승률이나 참가자의 미등록 역할 실력을 입증하지 않는다. 실제 결과로 점수 가중치를 조정하려면 이후 경기 결과를 따로 축적해 검증해야 한다. 이번 사례에서는 가중치를 바꾸는 대신 누락 입력 보완과 표시 정정에 근거가 있었다.

추가 검사에서 임의 문자열의 첫 글자만으로 티어 점수를 주는 입력 검증 결함을 발견했다. 예를 들어 `masterpiece`가 마스터 점수로 계산되는 반면 공정성 검사는 미확인으로 판정했다. 실제 초안에는 해당 입력이 없었다. 동일한 엄격 티어 검증을 점수 계산에도 적용하는 회귀 검사를 추가한다.

운영 프로필 저장·초안 재평가·배포 여부는 별도 운영 기록으로 확인한다. 위 수치는 로컬 비교만으로 운영 반영을 주장하지 않는다.
