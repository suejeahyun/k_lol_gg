## 문제와 수정

- **P2 재시도:** 신청·관리자 플레이어·계정 목록 오류에서 새 조회 없이 오류 상태만 지웠다. 설치된 Next 오류 경계를 실행해 재현하고 실제 서버 재조회로 수정했다. 계정 상세는 정상 전체 재로드를 공통 방식으로 통일한 개선이며 결함 수에 넣지 않았다.
- **P2 설치:** 브라우저 설치 실패, 중복 실행, 초기 상태 및 늦은 응답의 완료 상태 덮어쓰기를 처리했다. 요청 수락과 실제 설치 완료를 구분한다. 실제 OS 설치를 완료했다고 주장하지 않는다.
- **P2 선택/접근성:** 멸망전 8개 방식이 4개 같은 이름으로 보여 구분되지 않던 문제를 단판/3판 2선승 label로 수정했다. 신청 오류 화면의 중복 main도 실제 렌더로 재현·수정했다.
- **P3 문구/중복:** 소개·홍보·영문 장식·버튼을 다시 설명하는 문장·내부 구현 코드를 정리했다. 로그인 관리자 링크, 비밀번호 결과 경고, 초기 상태의 반복 안내와 빈 상자를 제거했다. 기본 AI 비활성처럼 실제 현재 상태를 보장하지 못하는 설명도 삭제했다.

필수 입력 이름·제약, 실제 상태·오류·복구·저장 결과, 권한·삭제 영향·정책·집계 기준과 작성된 콘텐츠는 보존했다. 홈 여섯 영역 순서, 한 랭킹 슬라이드의 승률/최다 참여/최다 MVP, 생성 이미지/배경과 직접 조작·모션 감소 계약을 유지했다. API·도메인·DB·예약 설정·외부 연동·의존성은 변경하지 않았다. 이전에 반영한 Next 16.3.8 보안 patch를 유지하며 이번에 새 기술·공급자를 추가할 근거는 발견하지 못했다. 성능 개선 수치를 주장하지 않는다.
