## 이번 수정 범위

1. 경기 신규 접수·수정에서 저장 요청 중 입력을 잠가, 성공 응답 때 추가 입력이 사라지지 않게 한다. 실패하면 기존 입력을 유지한 채 다시 편집할 수 있다.
2. 내전의 명시적 예비삭제는 예비 참가자만 대상으로 한다. 같은 이름의 본 참가자는 취소하지 않는다.
3. 빠른 추가·삭제 명령에서 한글 자모 닉네임이 중복 정규화로 다른 문자열이 되는 문제를 수정한다. 명령의 전각·분해 한글 허용은 유지한다.
4. 팀 초안의 기본 정보·참가자·후보를 같은 DB 스냅샷에서 조회해 재평가 도중 서로 다른 버전이 섞이지 않게 한다.
5. 팀 편성의 최근 신청자 조회를 자정 대신 기존 06시 운영일 기준으로 맞춘다.
6. 팀 초안 수정 충돌에서는 최신 상태를 확인하고 수동 배치를 유지할지 버릴지 선택한 후 다시 작업하도록 한다.
