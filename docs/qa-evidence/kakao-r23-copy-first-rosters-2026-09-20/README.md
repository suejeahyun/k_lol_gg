## 변경 범위

- 파티·내전: 최초 전체 빈 양식 → 복사 → 이름 입력 → 전체 전송 → 최신 전체 양식.
- 파티는 주최자 입력 없이 참가자 이름으로 활성화. 내전은 등록 회원 이름만으로 참가하며 기존 라인 선택 보존.
- 저장기준 검사: 파티 ID/운영일/revision, 내전 운영일/round/신청 행 fingerprint. 최신 DB 잠금 상태에서 검사하여 오래된 양식의 덮어쓰기 차단.
- 저장기준 없는 구형 양식은 기존 참가자와 메타데이터를 보존하는 추가만 허용.
- 파티 편집 양식은 원본 시간·게임정보·이름·예비 슬롯을 유지. 기존 null/불일치 position 데이터도 이름을 누락하지 않고 무수정 재전송 시 그대로 보존.
- 카카오 스크림 명령·양식·도움말 제거. 서버와 휴대폰에서 종료 안내. 과거 DB 기록·웹 조회·관리자 대회 기능 보존.
- 도움말·사이트 안내·내전 참가 안내를 복붙 우선으로 통일.

## 적용·복구 경계와 남은 위험

- 운영 서버 배포, 휴대폰 코드 교체, 운영 DB migration·직접 수정·삭제 없음.
- 실제 카카오톡의 전체 복사·한글/이모지·줄바꿈 전달과 휴대폰 재컴파일은 실기기에서 확인해야 한다.
- 최신 양식을 다른 사람이 먼저 수정하면 재복사를 요구한다. 오래된 양식의 변경 내용을 자동 병합하지 않는다.
- 이름만으로 내전 참가할 때 미등록·동명이인 회원은 기존 식별 규칙에 따라 가입/구분이 필요하다.
- 저장기준은 권한 인증값이 아니다. 기존 서명과 논리적 installation 범위를 유지한다.
- 서버/휴대폰은 함께 승인된 버전으로 맞춰야 한다. 로컬 R23 파일 생성이 운영 적용을 뜻하지 않는다.
- 문제가 생기면 소스 변경을 검토해 이전 릴리스로 재배포하고 휴대폰은 R22 백업으로 복원한다. 기존 모집 데이터를 삭제하거나 DB를 역변경하지 않는다.
