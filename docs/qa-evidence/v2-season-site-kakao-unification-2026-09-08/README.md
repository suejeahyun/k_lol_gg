# V2 사이트·카카오 내전 참가 신청 통합 QA

상태: 소스 반영 및 관련 로컬 계약 검증 완료. 운영 DB 변경, MessengerBot R 설치, 실제 카카오 호출, Vercel 배포는 수행하지 않았다.

## 변경 범위

- 사이트 신청 화면에 연결 플레이어, 신청일, 회차, 현재 출처, 주·부라인을 한 양식으로 표시한다.
- 동일 `시즌 + 플레이어 + 신청일 + 회차`의 카카오 신청을 사이트에서 저장하면 행을 중복 생성하지 않고 SITE로 승격한다.
- SITE 저장 시 봇 전용 슬롯·원본 해시를 제거하며, 이후 카카오 동기화는 SITE 선택과 관리자 완료 판정을 보존한다.
- V41 봇 출력과 입력을 `플레이어 / 신청일 / 회차 / Riot ID / 주라인 / 부라인 / 상태 / 출처` 형식으로 통일하고 기존 슬래시 입력은 호환 경로로 유지한다.
- 확인된 신청의 봇 표시에서 회원명 대신 공개 닉네임·Riot ID만 사용한다. 자동 매칭되지 않은 입력명은 서명된 운영자 경계 안의 검토 데이터로만 유지한다.

## 운영 반영 상태와 남은 위험

- 운영 반영 상태: 미반영.
- V41 완성본은 소스에서 다시 생성해야 하며 실제 봇 교체 전 별도 사본 검증이 필요하다.
- 최근 24시간 안에 저장된 이전 형식 idempotency 응답은 재사용될 수 있으므로, 전환 검증에서는 새 요청 키를 사용한다.
- 자동 매칭 실패·동명이인은 계속 관리자 pending 검토 대상으로 남는다. 임의 자동 병합하지 않는다.
- 전체 DB 묶음은 관련 시즌 계약 23개 통과 뒤 공유 작업 중인 팀 초안 보관 권한 계약에서 중단됐다. 카카오 포함 recruiting DB 계약 7개는 별도 격리 실행으로 모두 통과했다.
- 전체 Git 이력 비밀 패턴 검사는 장시간 무출력으로 종료했으며 이 변경 대상은 응답 allowlist·동적 DB 계약으로 개인정보 비노출을 확인했다.
