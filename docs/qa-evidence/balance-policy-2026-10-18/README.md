## 5. 안정성·시간·독립 검증

고정된 조정용 16개 조합에서 입력 반전과 팀 색 교환을 확인했고, 엔진마다 45개 쌍 교환×16=720개를 검사했다. 각각 390개 교환을 평가하고 330개는 원래 정책 제약으로 거절했다. ±0.1 실제 적용 점수 변화는 엔진마다 32회였다. 추천 변화는 기준 2회, 후보 1회였고, 원점수로 재평가한 최악 팀 격차 악화는 기준 1.12, 후보 0.06이었다. 다른 보호 좌표 악화는 0이었다. 안정성 기준은 통과했지만 조정 단계의 신뢰도 실패를 상쇄하지 않는다.

새 500개 중 15개는 기준의 원래 공개 전체 탐색과 별도의 후보 전체 열거기로 검증했다. 엄격/완화 모드를 모두 포함했다. 선택한 1,000개 배치는 고정 평가기와 현재 서버 도메인으로 다시 계산해 일치했고, 모든 입력 보존을 확인했다. 별도 검토자가 저장된 1,000개 배치의 직접 산술, 집단 통계, 실패 조건과 462,889,392개 배치 수를 다시 검산했다. [독립 검토](independent-review.md), [안정성 상세](stability.json)를 보존한다.

실행시간은 기존 연구의 고정 16개에서 공개 기준 함수와 완전한 두 단계 후보 계산을 비교한다. 양쪽 준비 실행 1회는 통계에서 제외하고, 기준 먼저/후보 먼저 순서를 교대로 배치했다. 독립 열거기는 시간 측정 밖이다. 초기 단독 p95는 기준 2,546.81ms, 후보 4,672.27ms(1.835배)였다. 최종 단독 측정은 기준 중앙값 61.52ms·p95/최대 2,216.39ms, 후보 77.28ms·4,450.44ms로 p95비 2.008배였고 2.5배 한도를 통과했다. 병렬 작업 중 진단용 기준 중앙값/p95/최대는 2,283.57/3,760.35/5,426.04ms, 후보는 4,558.25/7,312.83/8,912.42ms였다. 이 수치는 공개 기준 함수와 다른 스트리밍 1차 탐색 및 동시 CPU 작업의 영향을 받아 채택 시간 기준으로 사용하지 않았다.
