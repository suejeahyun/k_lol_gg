# 전체 완료 판정 후속 · 1.0.11

1.0.10 운영 화면을 실제 재검토하다 완료 대회에서 신규 참가와 MVP 투표 로그인을 유도하는 P2를 발견했다. 서버는 완료 후 이 쓰기를 허용하지 않지만 클라이언트가 인증을 대회 상태보다 먼저 표시한 것이 원인이다. 반면 본인 신청 기록 조회는 종료 후에도 필요하므로 유지한다.

같은 원인을 관련 화면으로 확대해 이벤트전과 내전 신청에서도 마감 상태보다 로그인·연결 안내를 먼저 표시하는 문제를 확인했다. 파티 모집은 현재 OPEN 목록과 정원 상태를 먼저 보여 주어 같은 원인이 확인되지 않았다.

이번 변경은 현재 상태와 다음 행동의 표시를 고친다. 기능·API·DB·권한 정책을 추가하거나 대회 자료를 수정하지 않는다. 홈 순서·단일 랭킹·기존 생성 이미지와 배경 테마를 유지한다. 전체 기능군과 개별 경로는 [전체 원장](../service-completion-final-2026-10-08/README.md), [현재 목록](../service-completion-final-2026-10-08/interface-inventory.json)을 따르며 내전·이벤트전·멸망전의 인증/신청/투표 표시를 후속 결과로 갱신한다.

개별 실제 JSX 회귀·독립 검토, 필수 통합 검사와 운영 검증은 이 폴더에 분리해 기록한다. 변경하지 않은 DB/집계/권한 검사는 직전1.0.9의 새 격리 환경 결과와 서버 계약을 재사용하며 실제 UI 검사로 바꿔 쓰지 않는다. 서버 정책과 실제 표시를 다시 대조해 기능 추가 없이 문제를 해결한다.

최종 소스를 다시 수집한 [개별 경로·조작 목록](interface-inventory.json)은108페이지·212 API·63 호환·3 metadata, 총386경로와1203개 조작 소스 위치다. 기존 기능 목록에서 빠지거나 삭제된 경로는 없다.6개 예약 작업과18개 기능군의 기존 검증을 연결하며, 조작 위치 수를 실제 모든 버튼 클릭으로 해석하지 않는다.

최고관리자 재로그인, native confirm 도구 및 외부 기기/권한 등의 미확인 조건은 실제 확인 전까지 완료로 변경하지 않는다.
