## 보안·무결성 확인

- 회원명은 검색 조건으로만 사용하고 공개 DTO에는 포함하지 않는다.
- 챔피언 이미지는 Riot Data Dragon HTTPS 형식만 허용하고 값이 없거나 잘못되면 안전한 대체 UI를 사용한다.
- 팀 밸런스 초안의 타인 소유·조작 UUID·이전 후보·중복 선수·잘못된 포지션은 서버에서 거부한다.
- 경기 결과 승인 이후에도 연결된 팀 밸런스 초안 ID가 감사·outbox 흐름에 유지된다.
- 징계 증빙 이미지는 기존 비공개 자산 저장 및 소유권 검증 흐름을 재사용한다.
