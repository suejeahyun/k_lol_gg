# K-LOL.GG 전체 화면 효과 업데이트

사이트 전체가 조금 더 또렷하고 자연스럽게 움직이도록 다듬었습니다.

- 홈·구인·경기·신청·대회·미디어 카드에 짧은 등장과 상태 효과를 통일했습니다.
- 입력창과 버튼, 표는 선택 위치와 포커스를 더 쉽게 알아볼 수 있습니다.
- 참가 신청·경기 접수·징계 상태는 색상과 글자를 함께 사용해 구분하기 쉬워졌습니다.
- 홈의 멸망전 우승 사진은 사진 위에서 마우스 휠을 내리면 한 장씩 옆으로 넘어갑니다.
- 마지막 사진에서는 휠이 다시 페이지 아래로 자연스럽게 이어집니다.
- 좌우 화살표 키와 이전·다음 버튼도 그대로 사용할 수 있습니다.
- 모바일과 모션 감소 설정에서는 효과를 줄여 읽기와 조작을 우선합니다.

검수 결과: 105개 페이지·339개 화면 캡처, 핵심 브라우저 품질 27건, 전체 계약 테스트와 운영 health를 통과했습니다.
