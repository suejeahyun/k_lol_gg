## 검증 구분

- 단위/렌더 실행 회귀: 실제 TSX를 렌더해 폼 identity·계정 상태·접수 복귀·파일 상태·MMR 페이지와 포지션 수치를 확인한다. 별도의 mock UI를 제품처럼 검사하지 않는다.
- PostgreSQL: 기존 안전 가드가 적용된 임시 PostgreSQL 18 클러스터와 합성 계정·경기만 사용한다. DB·권한·수식·동시 처리 계약과 HTTP 로그를 남긴다. 운영 데이터로 접수·신청·계정 테스트를 하지 않는다.
- 전체 경로 HTTP: 108개 페이지 및 상세/검색 변형 169개를 합성 일반/관리자 세션으로 확인한다. 이것은 버튼별 업무 E2E를 대체하지 않는다.
- 브라우저: 실제 로그인 복귀, 내전 수정/회차 전환, 접수 생성/이어하기/새 접수, 필터 이동, MMR 페이지/초기화와 주요 화면의 반응형·키보드 상태를 별도 기록한다.
- 운영: 배포 ID·source SHA·alias·health, 공개 핵심 경로/변경 화면, 생성 자산 해시를 재확인한다. 실제 회원 데이터 쓰기는 제외한다.

실행 전 계획과 실행 후 결과를 혼동하지 않도록 원본 로그와 결과 JSON을 함께 보관한다. 후보·운영 배포와 배포 후 확인은 아직 대기 상태이며, 완료 후 최종 source SHA·배포 ID·복구 기준을 `production.md`에 기록한다.

## 변경하지 않는 범위와 이유

모집과 카카오 편집 양식, 대회/내전의 기존 정원·예비 규칙, 회원 승인과 관리자 권한, 경기 통계·MMR 수식, DB 스키마는 기존 계약을 유지한다. 새로운 사이트 내 파티 편집 시스템은 현재 카카오 원본과 경쟁하는 중복 경로이므로 만들지 않는다. Riot/알림의 새 공급자, 검색 소유권 등록, 실기기 앱 설치는 외부 권한·기기가 필요하며 이번 코드 릴리스에 섞지 않는다.

리렌더·캐시·쿼리·이미지 수식에 대한 추측성 성능 최적화도 하지 않는다. 효과 처리 수정은 실제 hydration 충돌의 원인 제거다. HTTP 응답 시간은 측정 환경별 관찰이며 LCP/INP나 실제 이동통신 성능으로 주장하지 않는다.
