# K-LOL.GG 화면 효과 대규모 업데이트

사이트 전반의 움직임과 상태 표시를 더 자연스럽고 알아보기 쉽게 다듬었습니다.

- 홈 챔피언 이미지에 은은한 광원과 깊이감을 추가했습니다.
- 화면을 내릴 때 각 섹션이 짧고 자연스럽게 등장합니다.
- 구인 카드에 참여 인원과 마감 정도가 게이지로 표시됩니다.
- 경기의 승리 팀, MVP, 접수·업로드 상태를 더 쉽게 구분할 수 있습니다.
- 팀 밸런스에서 BLUE·RED 팀, 점수 차이, 라인 차이와 선택 상태가 또렷해졌습니다.
- 랭킹 상위권, MMR 신뢰도, 대회 진행·승자·우승 표시를 강화했습니다.
- 내정보와 관리자 화면은 저장·대기·성공·오류·선택 위치를 쉽게 확인할 수 있습니다.
- 모바일과 모션 감소·고대비 설정에서는 효과를 줄이고 읽기와 조작을 우선합니다.

검수 결과: 105개 페이지·339개 화면, 브라우저 품질 27건, 전체 테스트와 production build를 통과했습니다.
