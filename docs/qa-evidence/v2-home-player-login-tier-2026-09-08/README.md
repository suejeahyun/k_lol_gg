# 홈·플레이어 목록·로그인·티어 개선 QA

## 범위와 상태

| 요구 | 구현 근거 | 상태 |
| --- | --- | --- |
| 회원명·닉네임·Riot ID 검색 | `PostgresPlayerRepository`가 회원명 정확 일치와 공개 닉네임/Riot ID prefix를 조회 | 소스 반영 |
| 검색창 아래 티어 버튼 | 전체 및 10개 티어 필터, 검색·페이지 이동 중 query 유지 | 소스 반영 |
| 테마형 티어 이미지 | 공식 랭크 문양을 복제하지 않은 자체 SVG 엠블럼과 티어별 색상 | 소스 반영 |
| 밝고 친근한 홈 카피 | “우리 같이 롤하자~” 중심의 짧은 이용 문구 | 소스 반영 |
| 오늘의 안내 챔피언 | DB의 모든 활성 챔피언을 pagination해 KST 날짜별 결정 선택 | 소스 반영 |
| 챔피언 이미지 안전성 | DB URL은 Data Dragon HTTPS allowlist 공통 컴포넌트, 없으면 승인된 로컬 팬아트 또는 이름 테마 카드 | 소스 반영 |
| 홈 현재 랭킹 | 현재 공개 시즌 참여 10회 기준 상위 5명 요약표와 전체 랭킹 링크 | 소스 반영 |
| 로그인 후 홈 이동 | 일반 로그인 기본 목적지를 홈으로 변경, 강제 비밀번호 변경과 안전한 `next`는 유지 | 소스 반영 |
| 로그인 메뉴 전환 | 로그인 세션이면 데스크톱·모바일 모두 “내 정보”로 표시 | 소스 반영 |

플레이어 상세 화면은 병렬 작업과 충돌하지 않도록 이 범위에서 수정하지 않았다. 운영 배포와 운영 DB 변경은 수행하지 않았다.

## 개인정보·저작권 경계

- 회원명은 정확 일치 검색 조건에만 사용하고 public projection에는 포함하지 않는다.
- 계정, Discord, 내부 보정 필드는 플레이어 목록 결과에 포함하지 않는다.
- 임의 외부 이미지 URL은 렌더링하지 않는다. 허용된 Riot Data Dragon URL만 공통 검증기를 거친다.
- 로컬 이미지는 비공식 팬아트로 식별하며 Riot 로고 또는 공식 제휴 표시는 사용하지 않는다.
