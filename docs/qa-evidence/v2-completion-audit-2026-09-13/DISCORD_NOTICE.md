# 📢 K-LOL.GG V2 전체 보완 패치 안내

사이트 전 기능을 다시 점검하고, 남아 있던 연결·표시·관리 흐름을 한 번에 보완했습니다.

✅ 팀 밸런스는 V1 평가 기준을 유지하면서 가장 좋은 `AI 최적 팀 추천` 한 가지만 보여줍니다. 수동 배치는 카드의 플레이어 정보를 보며 바로 이동할 수 있습니다.

✅ 경기 상세와 플레이어 프로필에 챔피언 이미지, KDA, 내전 승률, 신청 포지션 유형과 팀 밸런스 정보를 연결했습니다.

✅ 승률·최다 참여·최다 MVP 랭킹과 MMR 랭킹 이동 경로를 확인했습니다.

✅ 챔피언 173종의 공식 이미지 346개와 홈 여성 챔피언 테마 이미지 68개를 전수 검사했습니다.

✅ 콘텐츠 기본 화면을 하이라이트로 통일하고 갤러리·이벤트·멸망전 이미지와 참가자 관리 기능을 보완했습니다.

✅ Kakao 봇은 기존 V1 명령과 양식을 유지합니다. `/` 유무, 줄바꿈·공백, 참가자 수정·삭제, 다른 사용자의 수정·종료를 처리하며 양식을 불렀을 때가 아니라 작성 완료본을 보냈을 때 저장합니다.

✅ 관리자 Kakao 통계에서 이름을 검색해 파티 수와 자주 함께한 사람을 볼 수 있습니다. 민감한 설정·로그·상태 화면은 최고 관리자에게만 표시됩니다.

✅ 사이트 103개 페이지를 데스크톱·태블릿·모바일 335개 조건으로 실제 렌더링해 오류와 가로 넘침 0건을 확인했습니다.

✅ 사이트 패치는 소스·DB 테스트·브라우저 QA 후 K-LOL.GG 운영 사이트에 반영했습니다.
⚠️ 휴대폰 MessengerBot R 교체와 실제 두 방 송수신 검증은 별도 진행 항목입니다.
