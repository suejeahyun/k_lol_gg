# 배포 확인 후 사용할 공지 초안

아래 내용은 소스·로컬 검사 기준 초안입니다. 현재 운영 반영 완료 공지로 사용하지 마세요.

```text
[K-LOL.GG 카카오 파티 이용 안내]

• 구인현황을 번호순 간단 목록으로 볼 수 있습니다. 원하는 파티는 ‘구인상세 3’처럼 번호를 입력해 전체 양식을 받아주세요.
• 양식을 저장하면 결과와 현재 구인 목록이 나옵니다. 다음 참가자는 ‘구인상세 번호’로 최신 양식을 다시 받아 작성해주세요.
• 새 N인파티 양식은 시작 시간·게임 종류가 빈칸입니다. 처음 등록할 때는 참가자 이름이 한 명 이상 있어야 합니다.
• 작성 중인 초안도 ‘구인상세 번호’로 다시 받을 수 있습니다. 만들지 않을 때는 ‘번호ㅉ’로 취소할 수 있습니다.
• 이름 추가·삭제·교체와 시간·게임 수정은 최신 양식 전체를 복사해 전송하세요. 모집번호·정원·양식코드는 그대로 두세요.
• 저장 결과 뒤 목록을 불러오지 못했다면 ‘구인현황’으로 다시 확인해주세요. 연결 오류만 보고 같은 모집을 새로 만들지 않아도 됩니다.
```
