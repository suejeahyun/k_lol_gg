# 핵심 과업의 저장·복구·접근성 보완 — 1.0.5

사용자 요청에 따라 1.0.4의 완료 기록을 그대로 신뢰하지 않고 실제 과업으로 재확인했다. 기준 commit은 `ca242292ef82d9910574925465d898e8e0e79887`, 운영 source는 `583dab4d3793b1bb00de92c2ea2fd4ad21a2e04d`다. 별도 사용자 checkout과 실제 운영 회원·신청·경기는 변경하지 않는다.

## 목적과 범위

참가·모집 → 팀 편성 → 경기 접수·검토 → 기록·공유의 기존 기능을 연결하고 정확하게 완료하는 데 집중한다. 새 프레임워크나 중복 기능을 추가할 근거는 확인되지 않았다. 홈 여섯 영역의 순서, 한 랭킹 슬라이드의 세 기준, 생성 이미지·배경 테마는 유지한다. 버튼을 반복 설명하는 문장은 제거하되 입력 이름·현재 상태·오류·복구·정책·집계 기준은 기능으로 보존한다.

전체 페이지/API/메뉴·조작 인벤토리는 [기존 386경로 원장](../service-completion-v1.0.4-2026-10-06/interface-inventory.json), 기능별 실행 층위와 남은 조건은 [01–18 순서별 재분류](coverage-gaps.md)에 연결한다. 이번 수정은 경로를 추가하거나 삭제하지 않는다.

## 검증과 한계

[실제 브라우저 기록](browser.md), [관리 HTTP](coverage-gaps.md), [실측 성능 판단](performance-review.md)을 구분한다. 컴포넌트 handler, 합성 PostgreSQL, HTTP, 실제 UI, 운영 제공자·실기기는 서로 대체하지 않는다. 성능 표본에서 확인되지 않은 LCP·부하 개선 수치를 주장하지 않는다.

[새 격리 DB](completion-browser-final-database.log), [전체108페이지169조건](release-http.json), [이벤트 저장 HTTP11응답](event-write-http-after.json) 통과. 마지막 랭킹 CSS 이후 새 빌드와 네 폭 실제 렌더를 확인했다. 같은 검사의 재실행 수를 합산하지 않는다. 배포 결과는 후속 production 문서에서 확정한다.

운영 MMR 공식 전환은 실제 최고관리자 로그인 대기다. 기존 읽기 전용 영향 분석과 백업/격리 복원은 [전환 검토](../service-followup-2026-10-06/mmr-transition-review.md)에 있다. Riot RSO 승인·계정 소유자 동의, 카카오 기기·허용된 방 실제 수신, 물리 기기·스크린리더, 실제 OCR 정확도·장시간 부하·외부 경보·PITR/Blob 전체 복원은 필요한 조건과 함께 미확인으로 유지한다.

## 검증 환경 기록

첫 browser hold의 stdout/stdin 환경에서 입력이 닫혀 종료 명령을 전달할 수 없었다. 해당 Next PID와 소유 DB 경로를 확인해 서버를 중지했고 `pg_ctl -m fast -w stop` 성공을 확인했다. 임시 경로의 일괄 정리는 자동 승인 검토에서 차단되어 삭제를 재시도하지 않았다. 경로는 ignored `.tmp`에 보존했다. 다음 hold는 상호작용 가능한 TTY로 실행한다. 이를 제품 오류나 정상 harness 종료로 표시하지 않는다.
