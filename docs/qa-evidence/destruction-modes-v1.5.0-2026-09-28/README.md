# 멸망전 본인 기재 승패 평가 1.5.0

## 변경 계약

신청 PUT은 기존 소유자 인증·행 잠금·revision·멱등성·감사·outbox 경로를 유지하며 `modeRecord: { wins, losses }`를 추가한다. 모드와 제출 시각은 서버가 정한다. 숫자 외 타입, 음수·소수·추가 필드, 합계 1,000,000판 초과는 거부한다. 협곡 신청에는 승패를 허용하지 않는다.

공식 ABSOLUTE_V2: 해당 모드의 본인 기재 누적 승패 20%, 솔랭 40%, 내전 20%, 챔피언 15%, 도전과제 5%. 승패 점수는 clamp(((wins + 10)/(wins + losses + 20) − 0.3)/0.4 × 100, 0, 100), 소수 둘째 자리 반올림이다. 0판·미기재는 NO_DATA이고 가중치를 재배분하지 않는다. 데이터 출처 SELF_REPORTED는 자동 수집이나 운영자 확인과 구분한다.

참가 확정 후 PUT은 RECRUITING/TEAM_BUILDING이며 팀이 없는 동안 승패만 변경할 수 있다. 참가 역할·포지션 변경은 거부한다. 애플리케이션과 참가자 스냅샷을 함께 저장하고 다른 네 항목을 보존하여 점수·최소 입찰가를 재계산한다. 주장·팀 확정 이후에는 입력과 비중을 잠근다.

새 대회/모집 마감부터 V2를 사용한다. 예약 작업은 미확정 TEAM_BUILDING의 이전 정책을 V2로 전환하고 기존 자동 칼바람 대리 점수를 제거한다. 실제 입력이 없으면 미확인으로 유지한다. 기존 확정 경매와 협곡은 변경하지 않는다. DDL은 없다.

## 복구

배포 전 영향 범위는 미확정 대회 1개·참가자 20명이며 원본 스냅샷을 비공개 경로에 백업했다. 이전 서버는 ABSOLUTE_V2를 인식하지 않으므로 데이터 전환 후에는 단순 배포 되돌리기만 실행하지 않는다. forward-fix를 우선하며, 원본 복원은 이후 신규 신청·수정 이력을 확인하고 보존하는 절차와 함께 수행해야 한다. 확정된 경매는 전환 대상이 아니다.
