```text
[K-LOL.GG 파티·내전 참가 방식 개선]

이제 봇이 보낸 최신 명단을 전체 복사하고,

• 파티와 내전의 양식을 짧고 읽기 쉽게 정리했습니다.
• 내전에는 사이트에 등록한 이름을 적어 주세요.
• 사이트 신청과 기존 라인 정보는 그대로 유지됩니다.
• 회원 확인이 필요한 이름은 참가 명단과 따로 안내합니다.
• 동시에 신청해도 다른 사람의 이름을 덮어쓰지 않습니다.
• 취소는 이름을 지우지 말고 별도 삭제 명령을 사용해 주세요.
• 양식코드는 수정하지 않고 함께 보내 주세요.

새로 모집할 때: 5인파티 / 내전구인 협곡
기존 모집에 참가할 때는 새 모집을 만들 필요가 없습니다.
내전 종목은 협곡·칼바람·증바람 중 선택할 수 있어요.

카카오 스크림 기능은 종료합니다. 과거 기록은 보존됩니다.
사용법이 필요하면 구인도움말을 입력해 주세요.
```
