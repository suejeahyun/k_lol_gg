# 디스코드 복붙용 공지

```text
[카카오 구인 명단 빠른 추가·삭제 안내]

파티 전체 양식을 복사하지 않고도 한 사람을 빠르게 추가하거나 삭제할 수 있습니다.

사용 방법
- 추가: 상세 번호 추가 이름
- 삭제: 상세 번호 삭제 이름
- 예시: 상세 12 추가 민서
- 예시: 상세 12 삭제 민서

추가·삭제 결과 아래에는 최신 전체 구인현황이 함께 표시됩니다.
이미 등록된 이름, 명단에 없는 이름, 동명이인, 인원 한도, 현재 수정할 수 없는 모집도 입력 오류로 뭉뚱그리지 않고 이유를 안내합니다.

기존 방식도 그대로 사용할 수 있습니다. `상세 번호`로 받은 전체 양식을 복사해 여러 이름과 정보를 한꺼번에 수정한 뒤 전체 전송하면 됩니다.

사이트 서버 배포는 완료되었습니다. 휴대폰 MessengerBot R에는 새 설치 파일을 붙여넣은 뒤 봇을 다시 켜 주세요.
```
