# 구현 후 사용할 디스코드 공지 초안

현재는 설계만 작성했다. 아래 문구는 실제 구현·운영 검증 후 사용한다.

```text
[K-LOL.GG 파티 모집 이용 방식 변경]

1. '5인파티'처럼 인원을 입력해 양식을 받습니다.
2. 시작·게임·참가자 이름을 적고 전체를 전송합니다.
3. 저장되면 등록 결과와 현재 구인 목록이 나옵니다.
4. '구인상세 번호'로 최신 양식을 받아 다시 편집할 수 있습니다.
5. '3ㅉ'처럼 번호를 붙이면 해당 파티가 마감됩니다.

양식에서 이름 추가·삭제와 시작·게임 수정이 가능합니다.
다른 사람이 같은 내용을 먼저 수정했다면 최신 양식으로 다시 작성해주세요.
사이트에도 같은 명단과 모집 상태가 반영됩니다.
```
