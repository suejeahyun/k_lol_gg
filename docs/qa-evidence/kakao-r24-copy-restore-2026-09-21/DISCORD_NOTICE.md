# 디스코드 공지 — 서버 적용 완료·휴대폰 교체 안내

서버·DB 운영 반영을 확인했다. 휴대폰 봇 파일 교체와 실제 송수신은 아직 미확인이다. 외부 게시하지 않았다.

```text
[K-LOL.GG 카카오톡 참가 방식 안내]

사이트 연동 서버 업데이트를 적용했습니다.

파티·내전은 익숙한 양식 복사·붙여넣기로 참가합니다.

1. 봇이 보낸 최신 양식 전체 복사
2. 빈칸에 내 이름 추가
3. 메시지 전체 전송 후 저장 결과 확인

• 사이트 모집·내전 신청 연동은 유지됩니다.
• 내전에는 사이트에 등록한 이름을 사용해 주세요.
• 다른 참가자 이름과 양식코드는 그대로 두세요.
• 예비 명단 중간에 빈자리가 생기면 해당 빈칸이 다시 표시됩니다.
• 취소: 상세 9 삭제 내이름 / 내전상세 9 삭제 내이름

다음 참가자는 봇이 새로 보낸 최신 명단을 복사해 주세요.
```
