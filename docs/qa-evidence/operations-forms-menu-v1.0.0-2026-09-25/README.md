# 운영·감사 신청 메뉴 1.0.0

네 가지 운영 신청은 기존 `operation-forms` 화면에 존재했으나 운영·감사 작업 공간의 진입점은 징계 화면만 제공했다. 운영 신청 목록·상세에서도 해당 작업 공간이 선택되지 않았다. 사용자 용어와 다른 ‘친구 신청’, ‘탈퇴·휴식’ 표기도 혼동을 만들었다.

기존 관리자 셸에 징계·전체 신청·모임·외출·건의사항·디스코드 초대 메뉴를 추가했다. 기존 통합 query 경로, 타입별 목록, 상세에서 같은 활성 메뉴와 위치 정보를 제공한다. 모바일 작업 링크도 운영 영역을 유지한다. 표시 명칭은 기존 순수 도메인 상수를 서버 목록/상세와 클라이언트 탐색에서 공유한다.

서비스·HTTP API·ADMIN 권한·DB 스키마와 저장 상태는 변경하지 않았다. 읽기 전용 운영 조사에서 삭제되지 않은 기존 신청 113건(디스코드 초대 3, 외출 72, 모임 31, 건의사항 7)을 확인했다. 개인정보와 신청 원문은 QA에 기록하지 않았다.
