# kakao-inhouse-auto-link 1.0.0

현재 단계: 소스·로컬 검사. 운영 배포·태그는 완료 후 별도 근거로 연결한다. migration 변경 없음 (`0044_vengeful_trauma`).

## 범위

- 오래된 빈 양식에서 기존 참가자의 라인을 수정하면 중복 이름으로 오안내하던 응답을 정정했다. 원본 없는 필드 변경은 최신 양식에서 다시 입력하도록 하며 타인의 변경을 추측해 덮어쓰지 않는다.
- 저장 transaction의 최신 양식코드·전체 명단을 성공 안내 바로 아래 반환한다. 추가 목록 조회 없이 최신 편집 기준을 전달한다.
- 정확히 한 명인 활성 회원 이름/닉네임 또는 이름(사이트 닉네임) 결합 일치를 참가 명단에 자동 연결한다. 사용자 후속 요청으로 기존 확인 대기 정책을 변경했다. 발신자 인증·계정 권한·Riot 인증은 변경하지 않는다.
- 기존 미연결 항목도 다음 저장 때 연결한다. 새 연결에서 참가 순서·라인·예비 여부를 보존하며 가능하면 기존 항목 ID를 유지한다. 본 참가·예비 모두 계정별 신청 유일 키를 사용한다.
- SITE/운영진 확정 보호, 동시 수정, 취소 보존, 정원, 중복 계정과 다른 범위 보호 유지. 동명이인과 미가입자는 임의 연결하지 않는다.
- 사이트 도움말과 서버 응답을 수정했다. 기존 R25·사이트 알림 1.0.3 재설치는 필요 없다.

## 검증 근거

- `.tmp/inhouse-auto-link-focused.log`: 집중 단위 검사.
- `.tmp/inhouse-auto-link-db.log`: `V2_DB_CONTRACT_SCOPE=recruiting npm run test:db`, 일회성 PostgreSQL. 기존 명단·SITE 보호·경합 검사 및 신규 본 참가/예비 자동 연결, 동명이인 구분, 같은 계정의 별칭 중복 롤백, 기존 미연결 접수 자동 연결과 이전 항목 ID를 통한 라인 수정 검증.
- `.tmp/inhouse-auto-link-check.log`: 전체 lint·타입·ERD·계약·단위·이미지·빌드 검사.
- 공개 증거에는 실제 참가자의 이름이나 등록 코드·개인 설치 설정을 기록하지 않는다. 운영 명단 변경·실제 카카오 메시지 전송은 검증에 사용하지 않는다.
