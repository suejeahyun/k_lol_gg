# 멸망전 3개 모드 1.0.0 검증

최신 운영 기준 `230e204d5650e4f16c52b665b818fbebe265a3bb`에 멸망전 변경만 병합했다. 기존 작업 폴더의 다른 미배포 변경은 포함하지 않았다. DB migration head는 `0045_simple_reptil`이며 이번 기능에는 스키마 변경·운영 데이터 이관이 없다.

## 기능

- 협곡: 기존 주장 기준 가치, 팀당 5명·포지션별 1명, 상위 4팀 본선·BO3 유지.
- 칼바람: Riot Match-V5 queue 450의 최근 최대 100개 경기 ID를 고정하고 5개씩 수집·재개. 5분 미만·조기 종료 제외. API 장애 시 운영자 확인 입력도 가능하다.
- 증바람: 다른 모드 기록을 섞지 않고 운영자가 증바람 전적을 확인해 입력한다. Riot API 조회인 것처럼 표시하지 않는다.
- 확인 입력은 관리자 TOTP 세션, 해당 대회 모드, 1~100판 정수 승패, 10~500자 근거를 검증한다. 서버가 출처·확인 시각·등급·최소 입찰가를 결정하고 실행자·변경 전후 기록을 감사 로그에 저장한다. 근거는 공개 DTO에서 제외한다.
- 보정 승률 `(승+10)/(판수+20)`: S ≥60%, A ≥52.5%, B ≥47.5%, C ≥40%, D <40%. 20판 미만은 잠정 B, 50판 미만은 표본 부족. S/A/B/C/D 최소 입찰가 300/250/200/150/100P, 주장 예산 2,000P − 본인 최소 입찰가. Riot 공식 티어나 MMR이 아닌 대회 경매 전용 평가다.
- 주장 확정 이후 전적·평가 고정. 입찰 하한·잔여 포지션 충원 예산 보호. 공통 카드 뒤집기·포인트 애니메이션·WAV 3종 효과음, 음소거 및 동작 줄이기 지원.
- 모집 심사·일정·대진 미리보기·경매 중단/재개·결과 정정·선수 교체·MVP·종료·취소 복구 지원. 요청 유실은 같은 멱등성 키로 재확인한다.

## 운영 순서

1. 관리자 → 멸망전 생성에서 협곡/칼바람/증바람 선택 → 모집 시작.
2. 포지션별 참가자 확정 → 모집 마감.
3. 칼바람은 선수 Riot 연결 후 전적 수집, 증바람은 선수별 확인 입력. 확인 근거에 전적 출처와 확인 기간·최신 경기 일시를 기록한다.
4. 모든 평가 완료 후 주장·팀 확정 → 경매 시작. 카드 효과음은 화면에서 켜기를 누른 뒤 재생된다.
5. 추첨·보류·낙찰 → 모든 포지션 충원 후 예선 대진 검토·공개 → 결과 입력·MVP → 본선 → 결승·MVP 확정 → 종료.
