# K-LOL.GG 카카오봇 V39 빠른 등록 안내

기준일: 2026-08-31 KST
소스 버전: `KLOL_KAKAO_BOT_V39_FAST_REGISTRATION_R1_2026_08_31`
전체 코드 파일: `KLOL_KAKAO_BOT_V39_FAST_REGISTRATION.js`
SHA-256: `DB7B366298A35F9804A62E23173426ED4806249C6B8BD8B78EFF0637619DADB3`

> 사이트 V39 R1 배포는 완료됐다. 카카오 명령이 실제로 V39가 되려면 메신저봇R 전체 코드 교체와 `/봇버전` 확인이 별도로 필요하다.

R1은 메신저봇R 편집기에서 오류 위치로 표시된 기존 2020~2022행의 설명 주석을 제거하고, 요청 JSON 조립 구간을 ES5 실행문만 남도록 정리했다. 전체 소스의 들여쓰기 공백과 개행도 일반 공백·CRLF로 통일한 호환성 보정판이다.

## 사용자가 기억할 명령

| 목적 | 가장 짧은 명령 | 다음 행동 |
|---|---|---|
| 경고 빠른 접수(운영자) | `/경고 닉네임#태그 일반 사진0` | 오늘 날짜·대상 이름을 자동 채워 즉시 접수 |
| 경고 차감 사진 | `/인증` | 본인의 업로드 가능 WR이 정확히 1건이면 자동 선택 |
| 경고 진행률 | `/경고현황` | 본인 소유의 진행 건이 정확히 1건이면 자동 조회 |
| 내전 결과 빠른 접수 | `/결과등록 3세트 1회차 밸런스#2 메모:정상 종료` | 오늘 날짜·진행자를 자동 채워 즉시 접수 후 사진 전송 |
| 내전 결과 진행률 | `/결과현황` | 같은 방·같은 작성자의 진행 건이 정확히 1건이면 자동 조회 |
| 사진 세션 취소 | `/사진취소` | 잘못 시작한 현재 사진 접수 종료 |
| 파티 모집 | `5인파티`, `자랭구인` 등 | 모집번호가 있는 양식을 유지해 명단 수정 |
| 파티 마감 | `12ㅉ` | 구인을 만든 같은 방·같은 작성자만 마감 가능 |

여러 건이라 자동 선택할 수 없을 때만 `/인증 WR접수번호`, `/경고현황 DS또는WR접수번호`, `/결과현황 MR접수번호`처럼 번호를 붙인다. 기존 `/경고인증`, `/내전등록`, `/내전등록현황`도 계속 지원한다.

## 빠른 접수 문법

- 일반 경고, 사진 없음: `/경고 닉네임#태그 일반`
- 내전 경고, 근거 사진 2장: `/경고 닉네임#태그 내전 사진2`
- 내전 결과, 밸런스 없음: `/결과등록 2세트 4회차`
- 내전 결과, 밸런스·메모 있음: `/결과등록 3세트 1회차 밸런스#2 메모:정상 종료`
- `/경고` 양식은 부여일과 사진 수 `0`을, `/내전등록` 양식은 진행일·진행자를 자동 입력한다.
- 관리자가 양식에 새 필수 항목을 추가했다면 빠른 접수 대신 전체 양식을 안내한다.

자동 선택은 편의를 위해 소유권 검사를 생략하지 않는다. 후보가 없거나 두 건 이상이면 서버가 임의로 고르지 않고 번호 입력 또는 로그인 후 내정보 확인을 안내한다. 공개 채팅 응답에는 경고 사유를 표시하지 않는다.

## 사이트에서 더 간단히 제출하기

- 경고 차감: `/discipline/evidence?code=WR...`
- 내전 결과: `/matches/submit?code=MR...`
- 로그인 후 모바일에서도 접수번호가 유지된다.
- 여러 사진을 한 번에 선택하고 순서를 바꾼 뒤 제출할 수 있다.
- 일부 사진만 실패하면 성공한 사진을 다시 보내지 않고 실패 지점부터 재시도한다.

## 운영자 설정

관리자 사이트 `/admin/kakao/settings`에서 다음 순서로 설정한다.

1. 전체 활성화와 점검 모드를 확인한다.
2. 전체 허용 방 또는 경고·내전 전용 방을 등록한다.
3. `카카오 운영자 이름`에 실제 카카오 표시 이름을 정확히 등록한다.
4. 파티·내전·경고·사진·운영양식 기능 스위치를 필요한 것만 켠다.

운영자 이름은 서버 설정 한 곳에서 관리한다. 봇 DataBase에 운영자 이름을 중복 등록할 필요는 없다.

## 달라진 안전 규칙

- 기능을 끄거나 점검 모드로 바꾸면 전용 API도 같은 정책을 적용한다.
- 파티 명단 수정·마감은 생성한 방의 작성자만 가능하다.
- 서버에 등록된 운영자는 작성자를 대신해 처리할 수 있다.
- `/경고` 양식 호출과 접수는 등록된 운영자만 가능하다.
- `/인증`과 `/인증 WR...`은 카카오 표시 이름과 징계 대상 정보를 대조한다. 일치하지 않으면 로그인 사이트 제출을 이용한다.
- MR·DS 현황은 같은 방의 작성자 또는 등록 운영자만, WR 현황은 징계 당사자 또는 등록 운영자만 확인할 수 있다.
- 활성 사진 접수가 없으면 일반 사진에 오류 답장을 하지 않는다.
- 사진 세션은 완료·취소·30분 만료 시 정리된다.
- 동일 운영양식이 중복 전달돼도 서버에는 한 번만 저장된다.
- 인증 오류와 서버 내부 원문 JSON은 채팅방에 노출하지 않는다.

## 운영 반영 순서

1. 운영 DB 백업과 롤백 지점을 만든다.
2. 생성된 Prisma 마이그레이션 두 건을 검토하고 적용한다.
3. 사이트를 배포하고 health·로그인·MR/WR 화면을 확인한다.
4. 메신저봇R의 전체 코드를 V39로 교체하고 스크립트를 다시 로드한다.
5. `/봇버전`으로 V39 문자열을 확인한다.
6. 테스트 방에서 일반 사용자와 운영자 계정을 분리해 아래 항목을 검증한다.
   - 다른 사용자의 파티 수정·마감 거부
   - 운영자 대리 마감 성공
   - `/인증` 단일 건 자동 선택, 0건·2건 이상 거부, `/인증 WR...` 지정 선택
   - `/경고현황`, `/결과현황` 단일 건 자동 조회와 다중 건 번호 요구
   - 빠른 `/경고 닉네임#태그 일반|내전 [사진N]` 권한·중복 재시도
   - 빠른 `/결과등록 2세트|3세트 N회차` 사진 제출
   - `/사진취소`, 만료, 동일 사진 재전송
   - 기능 OFF·점검 모드·허용되지 않은 방 거부

실제 비밀값은 문서·채팅·스크린샷에 기록하지 않는다.
