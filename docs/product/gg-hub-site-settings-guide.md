# GG HUB 사이트 개설과 기능 관리

구현 대상: `community-site-studio@0.1.0`. 실제 배포·외부 개설 검증 상태는 [QA 근거](../qa-evidence/community-site-studio-2026-10-29/README.md)에서 확인한다.

## 처음 만드는 운영자

1. GG HUB에 가입하고 로그인한다.
2. **사이트 만들기**에서 이름·주소 식별자·소개를 입력한다.
3. **Arena / Lounge / Club** 중 홈 구성을 고른다. 색상·로고·배너·홈 블록 순서를 바꿀 수 있다.
4. 사용할 기능을 선택하고 미리보기를 확인한 뒤 **개설 신청하기**를 누른다.
5. **내 사이트**에서 심사·보완 요청·개설 상태를 확인한다. 보완 요청을 받으면 초안을 저장하고 다시 심사를 요청한다.
6. 개설 후 소유자가 GG HUB로 로그인해 화면과 운영진 접근을 확인한 다음 **운영 시작**을 요청한다. 공개 처리가 완료된 사이트가 탐색 목록에 나타난다.

새 사이트의 회원·모집·경기 자료는 빈 상태로 시작한다. 신청자의 중앙 계정과 새 사이트 소유자 계정을 안전하게 연결하며, 기존 K-LOL/NEXUS 기록은 복사하지 않는다. 중앙 계정의 일반 권한이 모든 자식 사이트의 관리자 권한으로 바뀌지 않는다.

## 운영 중 바꾸기

**내 사이트 → 설정과 진행 상태**에서 수정한다. **초안 저장 → 저장한 설정 게시 → 완료 확인** 순서로 적용한다. 초안은 저장만 해서는 운영 화면을 바꾸지 않는다. 게시 중 추가 편집은 다음 초안으로 남는다.

개별 사이트의 **운영 설정**은 지원 URL과 비공개 운영 메모만 편집한다. 이름·소개·테마·기능 변경은 그 화면에 있는 GG HUB 연결을 이용한다. 두 화면에서 서로 다른 설정을 저장해 혼동하지 않도록 관리 위치를 한 곳으로 정했다.

| 원하는 작업 | 화면에서 할 일 | 남는 자료 |
|---|---|---|
| 기능을 잠시 중지 | 해당 기능을 끄고 영향 안내를 확인한 뒤 게시 | 기존 기록·참가 취소·운영진 마무리 경로 보존 |
| 기능을 다시 사용 | 같은 기능을 켜고 게시 | 보존된 기록과 홈 배치 재사용 |
| 화면 분위기 변경 | 테마·색상·로고·배너 수정 후 게시 | 회원·경기·모집 원본 유지 |
| 홈을 단순하게 구성 | 불필요한 홈 블록을 숨기거나 순서 이동 | 해당 기능과 자료 유지 |
| 잘못 수정한 초안 취소 | **현재 게시본을 초안으로 복원** 후 저장 | 현재 운영 설정 유지 |
| 심사 전 신청 취소 | **신청 취소** | 신청·처리 이력 보존, 재신청 가능 |

회원 기능은 기본 기능이다. 의존하는 기능을 켜면 필요한 기능도 함께 켜지고, 기반 기능을 끄면 영향을 받는 기능도 함께 중지된다. 새 기능이 추가되어도 기존 사이트에서 자동으로 켜지지 않는다.

**기능 끄기는 자료 삭제가 아니다.** 사이트 폐쇄나 회원·경기 자료의 영구 삭제는 이 설정 화면의 동작에 포함되지 않는다. Riot 연결은 전용 연결 설정을 제공하기 전까지 선택할 수 없다. 카카오 안내 선택만으로 휴대폰 봇이 설치되거나 방이 연결되지는 않는다.

## 운영자가 보는 진행 상태

신청 접수 → 검토 또는 보완 → 승인 → 독립 DB·사이트 개설 → 소유자 점검 → 공개 운영 순서다. 문제가 생기면 기존 작업과 자원 식별자를 유지하며 재시도한다. 중복 클릭과 네트워크 재전송으로 새 DB·사이트가 반복 생성되지 않게 처리한다.

사이트 간 제휴·공동 모집·공동 대회·운영 기록 공유·기존 사이트 계정 연결·휴대폰 동적 방 설정은 [제품 기획](gg-hub-platform-plan-v1.md)의 후속 단계다. 현재 설정에 완료된 기능처럼 표시하지 않는다.
