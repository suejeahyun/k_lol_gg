# 플레이어 Riot 전적 1.0.1

휴대폰에서 경기 타임라인을 펼쳤을 때 화면 전체가 옆으로 밀리는 문제를 수정했습니다. 성장 차트와 버튼은 화면 안에 표시하고, 넓은 표만 표 내부에서 좌우로 이동합니다.

작은 화면의 밴 챔피언 목록이 줄바꿈되도록 수정했습니다. 첫 화면에서 차트 설명과 경기 시간이 서버·브라우저마다 다르게 만들어져 화면을 다시 그리던 오류도 수정했습니다.

전적 데이터·계정 연결·동기화 방식은 그대로 유지됩니다. 검증과 배포 상태는 [QA](../qa-evidence/riot-player-detail-v1.0.1-2026-09-25/README.md)를 참고하세요.
