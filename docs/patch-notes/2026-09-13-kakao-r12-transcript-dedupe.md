# 카카오 V1 strict R12 알림 중복·양식 활성화 보완

정상 `오픈채팅봇`의 `내전구인 양식 불러오는 중…` 안내는 그대로 유지하면서, KLOL 봇이 이 안내를 사용자 명령으로 다시 읽어 중복 응답하던 경로를 차단했다. 동일 MessengerBot `logId`가 재전달될 때에는 같은 런타임에서 이미 성공적으로 표시한 답장만 억제하고, 다른 실제 명령이나 전송 실패 뒤 재시도는 막지 않는다.

`/내전구인` 무인자 명령은 오류 없이 종목 선택 안내만 표시하고, 실제 미지원 인자가 있을 때만 오류를 표시한다. `/내전구인 증바람`, `내전상세 번호 추가/삭제 이름`, 주최자·시작시간·게임정보를 채운 파티 전체 양식 활성화는 V1 사용 방식 그대로 유지한다. 모집 종류가 없는 `번호 추가 이름`은 파티·내전·스크림 오인 방지를 위해 계속 무응답이다.

MessengerBot R의 CRLF 65,535자 제한을 넘지 않도록 private 생성기를 보강했고, 기존 비공개 설정은 값 노출 없이 보존했다. DB 기능이나 운영 데이터는 변경하지 않았다. 전체 자동 테스트와 Vercel 운영 배포를 완료하더라도 실제 휴대폰 파일 교체·컴파일·카카오방 송수신은 사용자가 설치한 뒤 별도로 확인해야 한다.
