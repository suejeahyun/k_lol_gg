# 카카오 R24 — 사이트 연동 복사 참가

2026-09-20. 로컬 패치이며 운영 배포·운영 DB 변경·휴대폰 설치는 미실시.

- 기존 모집 참가: 최신 전체 명단 복사 → 빈칸에 이름 추가 → 전체 전송 → 결과와 최신 명단.
- 새 모집 개설은 별도로 안내하며 최초 파티 양식에서 시간·게임을 설정한다. 미입력 시간은 `미정`.
- 복사 저장은 참가 추가 전용. 기존 이름 삭제·교체·이동·모집 정보 덮어쓰기를 차단한다.
- 짧은 원본 코드로 동시 참가를 병합한다. 일반 번호는 빈자리로 조정하며, 지정 라인·본 참가/예비 구분은 임의 변경하지 않는다.
- 내전은 사이트 회원·시즌 신청과 연동한다. SITE 출처·확정 상태·기존 라인을 보존하며, 미등록·동명이인은 회원 확인 필요로 분리한다.
- 카카오 스크림 종료를 유지한다. 과거 DB·웹·관리자 기록은 삭제하지 않는다.
- migration `0040_kakao_form_snapshot_codes`를 새로 추가했다. 서버 배포 전에 반드시 적용해야 한다.

상세 근거·최종 검증 결과·산출물 해시는 [QA 기록](../qa-evidence/kakao-r24-site-linked-copy-2026-09-20/README.md), 결정은 [ADR 0010](../architecture/0010-kakao-site-linked-copy-forms.md)에 기록한다.

## 다음 패치 추천

1. **회원 확인 후 신청 연결**: 현재 미등록·동명이인은 안전하게 확인 대기 상태로 보존된다. 가입 후 운영진이 원래 신청을 연결하는 흐름을 더 짧게 만들면 재입력 부담이 줄어든다.
2. **모집 정보 전용 수정**: 활성 모집의 일반 복사 참가에서는 시간·게임 변경을 차단한다. 별도의 권한 확인·미리보기를 갖춘 정보 수정 흐름이 필요하다.
3. **만료 원본 정기 정리**: 현재 정리는 요청당 최대 256건이다. 무트래픽 시에도 보존기간을 지키도록 기존 운영 작업과 연계하고 누적 건수·지연을 모니터링한다.
4. **실기기 대량 명단 QA**: 공개 파일의 CRLF 기준 길이는 64,769자로 제한까지 766자다. 실제 MessengerBot R 복사·컴파일·긴 명단 전송과 서버 응답시간을 확인한 뒤 추가 기능 크기 예산을 관리한다.
