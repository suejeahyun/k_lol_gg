# 경기 결과 제출과 재참가 안내 개선

- 접수를 만든 뒤 정보 수정, 이미지 등록, 접수 취소와 카카오 접수 연결이 내부 요청 식별 오류로 실패하는 문제를 수정했습니다.
- 취소한 내전에 다시 참여할 때 버튼을 ‘다시 참가 신청’으로 표시합니다. 모집 마감이나 검토 완료 후에는 신청 상태를 확인하는 화면임을 명확히 안내합니다.
- 접수·팀 저장의 실제 요청, 중복 재시도, 동시에 수정하는 경우와 권한을 격리된 테스트 환경에서 추가 검증했습니다. 최종 배포 상태는 해당 릴리스의 운영 기록을 기준으로 합니다.

홈 배치와 이미지 테마, 참가 정원, 계정 권한과 경기 점수 계산 규칙은 유지합니다.
