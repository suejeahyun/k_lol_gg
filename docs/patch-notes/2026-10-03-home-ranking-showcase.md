# 홈 화면과 랭킹이 새로워졌어요

- 홈 순서를 **우리 같이 롤하자 → 랭킹 → 무엇을 하러 왔나요? → 지금 올라온 소식 → 내 활동 이어보기 → 지금 볼 수 있는 기록**으로 정리했어요.
- 랭킹은 한 공간에서 넘겨보는 슬라이드로 바뀌었어요. 지표마다 달라지는 배경과 왕관·메달로 상위 플레이어를 더 돋보이게 했어요.
- 화살표, 아래쪽 점, 키보드 좌우 키와 모바일 스와이프로 이동할 수 있어요. 재생 버튼을 누르면 자동으로 넘기고, 정지 버튼으로 멈출 수 있어요.
- 플레이어를 누르면 전적을, 전체 순위 링크를 누르면 해당 지표의 랭킹을 볼 수 있어요. 시즌 이름과 참여 기준도 표시해요.
- 반복되던 숫자와 안내 문구를 줄이고, 마지막 기록 영역에 플레이어·경기 목록 바로가기를 추가했어요.

기능 버전: `home-ranking-showcase@1.0.0`
