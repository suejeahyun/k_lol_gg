# 하고 싶은 일을 더 쉽게 찾도록 바꿨어요

- 홈에서 내전 참가, 파티 찾기, 팀 나누기, 경기 결과 올리기를 바로 시작할 수 있습니다. 내 활동도 위로 올렸습니다.
- 메뉴를 목적별로 묶고, 모바일 하단에 주요 기능을 고정했습니다. 로그인 전에도 기능 위치를 확인할 수 있습니다.
- 검색에 “팀 만들기”처럼 입력하고 Enter를 누르면 해당 기능으로 이동합니다. 로그인·가입 후에는 원래 작업으로 이어집니다.
- 모집 중인 이벤트전과 멸망전에서 바로 참가 신청으로 이동합니다. 칼바람 이벤트 신청이 거부되던 문제도 수정했습니다.
- 파티 모집에는 카카오톡 참여용 명령 복사와 이용 방법을 추가했습니다. 상세에서 목록으로 돌아올 때 검색 조건과 위치를 이어갑니다.
- 도움말과 운영팀 문의를 추가했습니다. 계정 없이 문의할 수 있으며 접수번호를 제공합니다. 운영팀이 남겨 주신 연락 방법으로 답변합니다.
- 검색엔진·공유 미리보기를 정리하고 모바일 화면, 키보드 이동, 로딩 비용을 개선했습니다.

새 사이트 문의는 접수 후 180일을 기준으로 정리합니다. 구체적인 수집 항목·정리 방식·개인정보 요청 절차는 사이트의 개인정보 처리 안내에서 확인할 수 있습니다.
