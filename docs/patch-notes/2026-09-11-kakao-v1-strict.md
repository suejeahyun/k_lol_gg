# Kakao V1 strict 복원 패치 공지

> 상태: V1 strict 소스·휴대폰용 단일 파일 생성, 타입·린트와 전체 계약/단위 테스트를 검증했습니다. Vercel 배포, 휴대폰 MessengerBot R 설치와 실제 카카오톡 송수신은 아직 확인하지 않았습니다.

## 디스코드 복붙용

```text
[K-LOL.GG 카카오봇 V1 복원 안내]

- 카카오봇의 명령어, 양식 모양, 문구와 처리 순서를 실제 V1 기준으로 되돌렸습니다.
- 5인파티 같은 양식 호출은 V1처럼 편집할 전체 양식만 보여주며, 내용을 채워 다시 보낼 때 저장됩니다.
- 최초 파티 양식의 시작시간·게임정보 입력 줄, 반영 안내, 상세 전체 양식, 구인중·대기중·진행중·대형파티 현황 구분을 V1 서버 문구로 복원했습니다.
- 내전현황은 0회차·1회차·여러 회차를 V1 방식으로 구분하며, 없는 내전/스크림 상세도 V1 안내 문구로 응답합니다.
- 활성 시즌이 없어도 내전현황은 오류 대신 빈 현황을 안내하고, 스크림의 날짜·오전/오후·`9시`·`협의` 일시 표기를 V1처럼 유지합니다.
- 명령어 앞의 / 유무, 구인현황, 상세, 수정과 마감 방식도 V1 기준을 유지합니다.
- 한 휴대폰에서 구인 기능과 나머지 기능을 함께 처리하며, 방 이름이나 특정 발신자만 허용하는 제한은 사용하지 않습니다.
- 서버 연결은 기존 V1의 오래된 인증 대신 현재 서명 방식만 사용하도록 교체했습니다.
- V1에 없던 진단 명령이나 새 문구는 V1 복원본에 섞지 않았습니다.

휴대폰 설치 후 /봇버전 → 5인파티 → 양식 작성·전송 → 구인현황 → 번호ㅉ 순서로 최종 확인할 예정입니다.
```
