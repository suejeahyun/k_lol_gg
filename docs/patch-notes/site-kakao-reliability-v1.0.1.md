# 사이트·카카오 봇 안정성 보완 1.0.1

- 경기 접수·수정 저장 중 입력을 잠가 작성 내용이 사라지지 않게 합니다. 실패하면 입력을 유지하고 다시 편집할 수 있습니다.
- 내전의 `예비삭제`로 본 참가자가 취소되는 문제를 수정합니다.
- 고정 코드·숫자 명령의 한글 자모 닉네임을 입력한 그대로 보존합니다.
- 팀 초안 조회에 서로 다른 재평가 시점의 정보가 섞이지 않도록 합니다.
- 새벽 0~6시에도 최근 신청자 조회가 실제 모집 운영일을 따릅니다.
- 팀 초안에서 다른 수정과 충돌하면 최신 상태와 수동 배치를 확인하고 복구할 수 있습니다.

이번 변경은 서버·사이트 수정입니다. 휴대폰 R29 파일은 변경하지 않습니다. [검증·배포 기록](../qa-evidence/repeat-audit-2026-10-16/README.md).
