# 내전 최신 양식·자동 회원 연결 1.0.0

처음 받은 빈 양식으로 이미 등록한 사람의 라인을 바꾸면 중복 이름으로 잘못 안내되던 상황을 정정했습니다. 저장 후에는 최신 양식코드와 전체 참가 명단을 바로 반환합니다. 다음 참가와 수정은 이 명단을 복사하면 됩니다. 오래된 양식과 최신 수정이 충돌하면 실제 원인과 최신 명단을 안내하며 다른 사람의 수정을 덮어쓰지 않습니다.

사이트에 등록된 활성 회원의 이름 또는 닉네임이 정확히 한 명과 일치하면 참가 명단에 자동 연결됩니다. 동명이인은 이름(사이트 닉네임)으로 구분할 수 있습니다. 미가입자는 이름으로 계속 참가할 수 있으며, 이미 참가한 같은 계정의 중복 추가와 사이트 신청·운영진 확정 항목 변경은 막습니다. 기존 미연결 명단은 다음 저장 때 자동 연결 조건을 확인합니다.

일반 R25나 설치된 사이트 알림 1.0.3을 다시 교체할 필요가 없는 서버 변경입니다. 참가 명단 연결이며 로그인·계정 소유권 인증은 변경하지 않았습니다. 운영 반영 여부와 검증 근거는 같은 버전 QA를 확인하세요.
