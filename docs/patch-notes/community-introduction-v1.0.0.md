# 커뮤니티 소개 1.0.0

GG HUB의 사이트 카드에 **소개 보기**를 추가했습니다. 사이트 방문 전에 커뮤니티 분위기·활동·가입 안내를 볼 수 있습니다.

각 사이트 관리자 메뉴의 **커뮤니티 소개**에서 한 줄 소개, 상세 소개, 주요 활동, 시간, 가입 안내, 문의 주소, 배너와 공개 여부를 설정합니다. 해당 사이트의 일반 관리자와 최고 관리자가 사용할 수 있고, 작성하면서 미리보기를 확인할 수 있습니다.

공개를 켜고 저장해야 GG HUB에 상세 소개가 표시됩니다. 끄면 작성 내용은 보존되고 HUB에는 기본 등록 정보가 표시됩니다. 동시에 수정하면 최신 내용을 덮어쓰지 않도록 안내합니다.

K-LOL·NEXUS·GG HUB 운영 반영을 확인했습니다. 새 사이트 개설 엔진에도 포함했습니다. 소개는 각 사이트 DB에 저장하며 기존 회원·경기·모집 자료와 별개입니다. [설정 안내](../operations/community-introduction.md), [검증·배포](../qa-evidence/community-introduction-v1.0.0-2026-10-29/README.md).
