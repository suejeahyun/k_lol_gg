# 카카오 R19 랜덤 입장 안내 톤

`오픈채팅봇`이 `입장시 할 일` 안내를 올리면 K-LOL 봇이 아래 네 가지 분위기 중 하나를 무작위로 선택해 안내 한 건을 보낸다.

- 환영 인사
- 공지형 안내
- 게임형 합류 안내
- 가벼운 입장 퀘스트

분위기는 달라도 닉네임 형식·예시·띄어쓰기, 구인구직방 링크·참여코드·규칙, 디스코드 링크는 항상 포함한다. 원시 `들어왔습니다`에는 답하지 않아 같은 입장에 안내가 겹치지 않으며, 서버 HTTP 요청 없이 휴대폰에서 즉시 처리한다.

휴대폰 설치본 버전은 `KLOL_KAKAO_BOT_V40_R19_2026_09_16`이다. `.private/KLOL_KAKAO_BOT_R19_RANDOM_JOIN_TONES_REPLACE_ALL.js` 전체로 기존 코드를 교체해야 한다.

DB migration과 운영 데이터 직접 수정·삭제는 없다.
