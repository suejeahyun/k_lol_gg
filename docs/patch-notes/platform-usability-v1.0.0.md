# 운영 화면 사용성·복구 개선 1.0.0

GG HUB와 각 커뮤니티의 편집·검색·카카오 방 관리 화면을 개선했습니다. 사이트 간 제휴나 새 MMR 산식을 추가한 버전은 아닙니다.

## 편집 내용 보호

- 소개, 사이트·방 등록, 개설 설정 편집 중 사이트 내부 링크로 이동할 때 저장하지 않은 내용을 확인합니다. 새 탭 열기·다운로드·같은 화면의 위치 이동은 막지 않습니다. 브라우저 뒤로가기를 모두 차단하는 기능은 아닙니다.
- 소개·사이트/방 정보를 다시 불러오기 전에 편집 내용을 버릴지 확인합니다.
- 개설 심사의 안내 문구도 이동·새로고침 때 보호하고, 심사 완료 뒤 다른 신청에 남지 않도록 초기화합니다.
- 현재 게시본을 초안으로 복원할 때 기존 미저장 편집을 확인합니다.
- 원래 값으로 되돌린 설정은 미저장 변경으로 잘못 표시하지 않습니다.

## 저장과 진행 상태

- 빠른 중복 클릭을 막고, 서버 응답이 멈추면 다시 시도할 수 있도록 요청 대기 시간을 제한합니다.
- 개설 요청이 성공했는지 알 수 없는 응답에서도 같은 요청 번호를 유지해 재시도합니다.
- 사이트 등록의 다른 탭에 잘못된 입력이 있으면 해당 커뮤니티를 선택해 안내합니다. 중복 주소·식별자도 저장 전 확인합니다.
- 사이트 목록에서도 진행 중 작업 상태를 갱신합니다. 숨겨진 브라우저 탭에서는 주기 조회를 쉬고, 조회 실패 시 마지막 확인 결과임을 알립니다.
- 로그인 만료·권한 부족·접근할 수 없는 사이트를 구분해 안내합니다.

## 둘러보기와 화면 표시

- GG HUB에 이름·소개·도메인 검색, 검색 결과 수, 검색 초기화를 추가했습니다. 한글·대소문자·전각 영문과 여러 검색어를 처리합니다.
- 공개 홈의 관리 안내를 사용자의 **내 사이트 관리**로 연결합니다.
- 긴 사이트 이름·주소·상태 문구가 모바일에서 넘치지 않도록 보강했습니다.
- 사이트 이름이 이모지로 시작할 때 미리보기 로고가 깨진 문자로 표시되는 문제를 수정했습니다.
- 등록 소개 길이를 서버와 같은 600자로 맞추고, 보관한 사이트를 다시 공개할 때 방을 다시 켜야 한다는 안내를 추가했습니다.
- 관리자 감사 로그·MMR 조정 시각·비공개 파일 시각·대회 갱신 시각을 한국 시간으로 표시합니다.

## 카카오 방 관리

- 통신 실패 시 **요청 결과 다시 확인**으로 원래 요청을 재확인합니다. 불확실한 이전 요청을 두고 다른 변경을 중복 제출하지 않습니다.
- 상태·역할 변경 후 최신 서버 상태를 자동 조회하며, 새 버전을 받기 전 이전 버전으로 다시 변경하지 않습니다.
- 동시 변경 충돌과 로그인/권한 문제를 구분하고 수동 새로고침을 제공합니다.
- 연결 코드는 최초 응답에서만 보인다는 서버 정책을 재시도 결과에 정확히 안내하고, 만료 시각은 한국 시간으로 표시합니다.
- 요청 중 연결 코드 폼을 잠그고 긴 항목을 모바일에서 줄바꿈합니다. 기술 용어와 상태 버튼을 이해하기 쉬운 표현으로 바꿨습니다.

휴대폰 설치본·실제 카카오톡방 연결·기존 경기/MMR·운영 자료는 변경하지 않습니다. 배포 상태와 검증 범위는 [릴리스 근거](../qa-evidence/platform-usability-v1.0.0-2026-10-31/README.md)를 기준으로 확인합니다.
