# 카카오 파티 이름 빠른 추가·삭제 v1.0.0

파티 전체 양식을 복사하지 않아도 `상세 번호 추가 이름`과 `상세 번호 삭제 이름`으로 한 사람을 빠르게 반영할 수 있게 했다.

단축 명령은 현재 운영일·현재 `RECRUIT` 설치 범위의 `DRAFT | IN_PROGRESS` 파티만 대상으로 한다. 기존 편집 가능한 전체 양식과 A→B→A 전체 스냅샷, 마감 명령은 그대로 유지한다.

추가 성공, 삭제 성공, 이미 등록된 이름, 없는 이름, 대상 모집 없음, 동명이인, 전체 99명 한도를 각각 구체적인 한국어 응답으로 안내한다. 입력 문법이 유효한 업무상 무변경 결과는 일반 입력 오류 400으로 바꾸지 않으며, 응답 아래에 최신 전체 구인현황을 붙인다.

구인 도움말과 파티 상세에도 새 단축 명령 형식을 추가했다. `kakao-party-member-shortcuts-v1.0.0` 태그와 커밋 `524d7938`을 Vercel 프로덕션에 배포했고 고정 주소의 상태·도움말·서명된 RECRUIT/FEATURES 게이트웨이가 정상 응답하는 것을 확인했다. 휴대폰 MessengerBot R에는 새 비공개 단일 파일을 직접 붙여넣어야 하므로 실기기 설치와 실제 방 송수신은 아직 확인되지 않았다.
