# 랭킹 갱신 안내 · 1.0.0

- MMR 랭킹에 공개 경기 변경을 확인하는 5분 주기 작업을 연결했습니다. 중복 실행과 잠금 충돌을 처리하고 실패하면 마지막 정상 점수를 유지합니다.
- 일반 랭킹에 마지막 집계 시각과 참가 기준을 표시하고 **전체 참가자 보기** 링크를 추가했습니다. 기본 기준인 내전 10회는 유지하며 게임 수와 내전 회차의 차이를 안내합니다.
- MMR 랭킹과 개인 기록에도 집계 시각을 표시합니다.

이번 운영 점검에서 일반 통계는 공개 경기 47회·104게임과 일치했습니다. 최근 참가자 29명의 개인 통계 API도 원본과 일치했습니다. 최근 참가자 중 20명은 기본 내전 10회 기준에 미달했습니다.

기존 MMR은 이전 계산 방식으로 42회·91게임까지만 집계되어 있었습니다. 새 방식 전환은 기존 점수도 바꾸므로 최고 관리자의 명시적 재계산 확인이 필요합니다. 이번 예약 코드 배포만으로 기존 점수 전환과 최신 MMR 반영을 완료했다고 표시하지 않습니다. 특정 개인 기록이 보이지 않는 경우에는 해당 플레이어 링크로 등록 대상을 확인해야 합니다.

DB 스키마와 휴대폰 봇 코드는 변경하지 않습니다.
