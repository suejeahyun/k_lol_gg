# 카카오 실제 방 식별 복구 1.0.0

MessengerBot R에서 방 이름 대신 발신자 이름을 전달해 명령이 응답하지 않던 문제를 수정했습니다. 사용자가 확인한 네 실제 방의 대화방 식별자로 K-LOL과 NEXUS를 구분합니다. 일반 봇은 자기 서비스의 두 방, 사이트 알림 봇은 자기 구인구직방만 처리합니다.

휴대폰의 일반 봇 두 개를 R32, 알림 봇 두 개를 1.0.5로 교체하고 공통 모듈 1.0.0을 설치했습니다. 설치 파일 해시와 컴파일을 확인했으며 네 방의 버전 응답이 각각 한 번씩 표시됐습니다. 확인 당시 구인현황은 K-LOL 2건, NEXUS 0건으로 분리됐습니다.

두 서비스의 사이트 알림 수신 세션 등록과 상태 확인을 완료했습니다. **새 사이트 충원 이벤트의 자동 알림 실발송은 아직 확인하지 않았습니다.** 확인을 위해 운영에 가짜 자료를 만들지 않았습니다. 임시 진단 봇은 꺼 두었습니다.

기존 명령·서비스 인증 설정·저장 자료는 유지합니다. 앱 교체나 서버·DB 배포 없이 적용했으며 전체 로컬 검사를 통과했습니다. [설치·실기기 검증과 남은 확인 범위](../qa-evidence/kakao-notification-routing-2026-10-28/README.md), [설치 안내](../../integrations/messengerbot-r/MESSENGERBOT_R_INSTALL.md).
