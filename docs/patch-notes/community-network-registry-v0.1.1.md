# 커뮤니티 연결 관리 0.1.1

2026-10-29 · NEXUS 운영 배포

검증한 사이트·방 등록 관리와 공개 목록을 NEXUS 운영 환경에 활성화합니다. 최고 관리자는 `/admin/community-network`, 공개 목록은 `/community-network`에서 이용할 수 있습니다. 등록 정보는 빈 상태에서 시작하며 관리자 저장 후 공개됩니다.

이번 버전은 0.1.0의 동일 기능에 대한 운영 전환입니다. 등록은 실제 사이트·폰 연결과 별개입니다. 독립 중앙 허브·회원 연결·공유 API·연합/공동 대회는 후속 단계입니다.
