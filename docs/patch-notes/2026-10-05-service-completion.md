# 이용 흐름과 상태 표시 개선

- 내전 회차를 바꾸면 해당 회차의 라인·참가 구분을 정확하게 불러옵니다. 칼바람·증바람은 포지션 구분 없이 표시합니다.
- 경기 접수 코드를 이어 열거나 새 접수를 시작할 때 이전 폼이 남지 않도록 고쳤습니다. 로그인·비밀번호 변경 후에도 하던 작업으로 돌아갑니다.
- 결과 제출의 계정 상태, 조회 실패 재시도, 거절 사유와 승인 경기 연결을 정리했습니다.
- MMR 순위에 페이지 이동과 검색 초기화를 추가하고, 포지션 검색에는 해당 포지션 점수와 표본을 표시합니다.
- 홈·시즌 랭킹·API의 동률 순서를 통일하고 필터에 실제 적용한 조건이 표시되도록 했습니다.
- 팀 도구의 응답 유실 재시도와 공통 화면 효과의 초기 표시 충돌을 보완했습니다.

기존 생성 이미지 테마, 홈 영역 순서, 하나의 랭킹 슬라이드와 데이터 집계 공식은 유지합니다.
