# V2 S08 멸망전 운영 패치

## 반영 내용

- 승인 계정은 공개 멸망전 화면에서 참가 신청을 만들고 수정·취소할 수 있습니다.
- 관리자는 모집, 주장과 경매 포인트 확정, seeded 경매, 예선·4강 본선, 선수 교체, 경기별 MVP와 완료까지 한 작업 공간에서 운영합니다.
- 결과 정정·선수 교체·MVP 초기화/강제 지정·취소 복구는 SUPER_ADMIN과 관리자 TOTP를 다시 확인합니다.
- 모든 변경은 `If-Match`, `Idempotency-Key`, 트랜잭션 세션 재검사, 감사 기록과 독립 outbox를 함께 사용합니다.
- 기존 경기 로스터 스냅샷은 선수 교체 후에도 바뀌지 않으며, 상위 경기 결과 정정은 하위 결과와 MVP를 무효화합니다.

## 디스코드 공지 복붙본

```text
🌸 K-LOL.GG V2 멸망전 기능이 준비됐어요!

• 공개 상세 화면에서 팀, 예선·본선 결과와 경기 MVP를 확인할 수 있어요.
• 승인된 플레이어 계정은 참가 신청·수정·취소와 경기 MVP 투표에 참여할 수 있어요.
• 운영 화면에는 주장 포인트, seeded 경매, 선수 교체와 결과 정정 보호 기능이 추가됐어요.

현재 소스·격리 DB 검증까지 완료했으며 실제 운영 배포는 아직 진행하지 않았습니다.
```
