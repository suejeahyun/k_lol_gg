# 카카오 R24 복사·붙여넣기 참가 복귀

요청 확인: 파티·내전 참가를 **양식 전체 복사 → 빈칸에 이름 추가 → 전체 전송**으로 사용하며 사이트 연동을 유지한다.

기존 로컬 R24 구현을 이어서 검증했다. 이번 소스 보완은 내전 예비 앞번호가 취소되면 빈칸이 표시되지 않던 문제다. 이제 예비 2~10이 남고 1번이 비면 `예비 1.`을 다시 출력해 복사 신청을 이어갈 수 있다. 실제 생성 양식을 재전송해 신청과 기존 명단 보존을 확인하는 DB 회귀 검사를 추가했다.

운영 배포·운영 DB migration·휴대폰 설치는 하지 않았다. 기존 R24의 추가 전용 저장, 사이트 신청 보존, 양식코드, 스크림 종료 정책은 유지한다. 취소는 명시적인 삭제 명령으로 처리한다.
