# 사용 흐름·모바일 가독성 개선 1.0.0

- 홈 첫 화면에 오늘 내전 참가와 파티 찾기를 배치했습니다. 소개 → 랭킹 → 무엇을 하러 왔나요 → 소식 → 내 활동 → 기록 순서를 유지합니다.
- 하나의 랭킹 슬라이드를 유지하면서 모바일 시상대 높이를 줄이고 다음 순위 종류를 표시했습니다. 화살표·점·키보드·수동 재생을 유지합니다.
- 모바일 로그인과 가입은 입력 폼부터 보여 줍니다. 소개 이미지와 보조 설명은 폼 뒤에서 확인할 수 있습니다.
- 경기 목록의 상세 조건을 접고, 사용 중인 조건은 개수와 함께 펼쳐 보여 줍니다. 빈 날짜·승패 값으로 검색이 실패하던 오류와 초기화 후 선택값이 남던 현상을 수정했습니다.
- 파티에 남은 자리와 정원 마감을 표시합니다. 정원 마감 상태는 최신 명단 확인을 안내하며, 카카오톡 참가와 저장 완료 확인 절차를 제공했습니다. 실제로 등록된 시작 시간·모집 안내를 표시하고 미등록 정보는 확인 경로를 안내합니다.
- 홈의 최근 경기는 게시 시각 대신 경기일을 표시합니다. 예비 참가자를 정원 인원에서 제외하고 빈자리가 있는 파티만 홈에서 소개합니다.
- 홈 대회 현황은 진행 중인 대회를 우선합니다. 준비 단계와 `test`, `테스트 2`, `임시` 등 임시 제목만 있는 항목은 홈 소개에서 제외합니다. 원래 대회·모집 기록은 유지됩니다.
- 메뉴의 주요 기능 명칭을 통일하고, 전체 메뉴에서 부가 항목을 펼쳐 찾도록 정리했습니다. 공용 팀 목록은 ‘저장한 팀’으로 안내합니다.
- 기능 아이콘 16종을 선명한 생성 이미지로 교체하고, 입력·목록 영역의 이미지 질감을 낮춰 글자를 읽기 쉽게 했습니다.
