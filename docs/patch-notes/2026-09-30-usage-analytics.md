# 사이트 이용 현황과 관리자 조회

- 관리자 운영·감사에서 일별 방문자, 실제 이용 회원, 비로그인 방문자, 월별 방문 빈도와 인기 페이지·클릭을 확인합니다. 일별 CSV를 내려받을 수 있습니다.
- 가입하지 않은 방문자도 무작위 브라우저 식별자로 집계합니다. 검색어와 입력 내용은 저장하지 않으며 개인정보 안내에서 이 브라우저의 수집을 제외할 수 있습니다.
- 사이트 설정을 제외한 로그·카카오 운영 조회를 일반 관리자에게 개방했습니다. 2단계 인증과 기존 변경 권한은 유지합니다.
- 배포 후 첫 수집부터 데이터가 쌓입니다. 이전 기간은 미수집으로 표시하며 방문자는 브라우저 기준 추정치입니다.
