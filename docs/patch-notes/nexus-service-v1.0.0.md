# NEXUS.GG 독립 서비스 1.0.0

K-LOL.GG 기능을 같은 코드에서 NEXUS.GG 브랜드로 운영할 수 있다. 별도 Vercel 프로젝트와 Neon DB를 사용하며 기존 회원·경기·시즌·모집 기록을 복사하지 않는다.

NEXUS 카카오 봇은 같은 휴대폰의 `NEXUS`, `NEXUS 구인구직방`에서 사용하도록 설정·요청·알림 저장소를 분리했다. 기존 K-LOL 봇 설정은 유지된다. NEXUS 양식을 복사해 다시 제출하는 흐름도 지원한다.

새 서비스의 초기화·최초 관리자·휴대폰 설치 절차는 [운영 시작](../operations/NEXUS_RUNBOOK.md)을 따른다. 웹 배포와 실제 휴대폰 설치 상태는 별도 검증 근거로 기록한다.
