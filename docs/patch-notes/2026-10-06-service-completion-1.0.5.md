# 팀 편성·운영 저장과 복구 개선

- 팀을 수동 교체하면 평가가 필요한 상태를 표시하고, 이전 팀을 복사하거나 경기 접수에 연결하는 동작을 막았습니다.
- 저장한 팀을 열기 위해 로그인한 뒤에도 선택한 목록 조건과 화면으로 돌아갑니다.
- 문의·건의의 관리자 상태와 메모 저장 오류를 수정하고, 다른 운영자의 수정과 충돌하면 최신 내용을 불러올 수 있게 했습니다.
- 이벤트전·멸망전·징계·미디어 생성 중 응답을 받지 못했을 때 같은 요청의 결과를 다시 확인합니다. 완료 화면으로 이동하는 동안 중복 생성을 막았습니다.
- 이벤트 생성의 동시 요청 처리와 갤러리 이미지 연결 결과 표시를 보완했습니다.
- 키보드 포커스와 랭킹 배지의 대비를 높이고, 긴 이름이 승률과 겹치지 않게 했습니다. 홈 순서와 기존 이미지·배경은 유지합니다.
