# 사이트 알림 1.0.3 오픈채팅 호환 수정 후보

실제 내전 구인 오픈채팅방에서 명령어를 보냈지만 MessengerBot R의 그룹 표시 값이 꺼져 전달되어 알림 봇이 응답하지 않는 문제를 수정했습니다. 실기기 1.0.2 로그의 INIT_READY, CALLBACK_RECEIVED, GROUP_REQUIRED와 사용자의 실제 방 확인을 근거로 수정했습니다.

그룹 표시 값을 필수 조건에서 제외하고 진단 정보로만 사용합니다. 카카오톡 패키지 검사와 일회용 등록 코드, 서버 승인, 원래 수신 세션 고정은 유지합니다. 원하는 내전 구인 오픈채팅방에서 새 개인 안내의 등록 명령을 직접 보내면 됩니다. 개인방/그룹방은 더 이상 자동 구분하지 않습니다.

18개 휴대폰 계약·합성 실행 테스트가 통과했습니다. 로컬 후보이며 1.0.3의 실제 휴대폰 응답과 충원 수신은 아직 확인하지 않았습니다. 운영 서버·DB·일반 R25는 변경하지 않았습니다.
