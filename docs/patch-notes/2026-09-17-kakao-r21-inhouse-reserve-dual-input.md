# 카카오 R21 내전 일반·예비 명단 이중 입력

내전 명단을 채팅 명령과 전체 양식 복사·붙여넣기 중 편한 방식으로 관리할 수 있다.

- 일반 추가: `내전상세 1 추가 민혁/mid/ad`
- 일반 삭제: `내전상세 1 삭제 민혁`
- 예비 추가: `내전상세 1 예비추가 정민/all`
- 예비 삭제: `내전상세 1 예비삭제 정민`
- `예비 추가`, `예비 삭제`, `대기추가`, `대기 삭제`처럼 띄어 쓴 별칭도 허용한다.

협곡은 `이름/주라인/부라인` 단축형과 기존 `이름/현티어/최고티어/주라인/부라인` 전체 형식을 모두 지원한다. 칼바람·증바람은 기존대로 이름만 받는다. 전체 양식에 `예비 1. 이름/라인`을 적으면 예비 명단도 함께 동기화되고, 해당 줄을 비운 뒤 다시 보내면 예비 참가가 취소된다.

예비 줄이 없던 옛 양식을 다시 보내도 기존 예비 명단은 삭제하지 않는다. 일반 정원과 예비 정원은 별도로 검사하므로 예비 참가자가 일반 참가 정원을 차지하지 않는다.
