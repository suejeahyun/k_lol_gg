# 관리자 갤러리 여러 장 등록

갤러리 등록 화면에서 제목·설명과 사진을 한 번에 작성할 수 있습니다.

- 사진은 한 번에 최대 5장까지 선택할 수 있습니다.
- 기존 갤러리에는 남은 칸만큼 여러 장을 바로 추가할 수 있습니다.
- 선택한 순서대로 갤러리에 표시됩니다.
- 형식·용량이 잘못된 파일은 제외 사유를 파일별로 알려줍니다.
- 일부 업로드가 실패해도 성공한 사진은 안전하게 보존되어 다시 연결할 수 있습니다.
- 기존 하이라이트 등록, 게시·게시 내리기, 비공개 저장소 보안 검사는 그대로 유지됩니다.

현재 상태는 소스와 로컬 검증 완료이며 운영 배포 전입니다.
