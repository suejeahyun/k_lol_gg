# 카카오 파티 구인 2단계 활성화

`2인파티`, `5인파티` 등 파티 생성 명령은 이제 모집번호만 DRAFT로 예약합니다. 처음 받는 양식에서 주최자를 채워 전체 전송하면 참가자가 없어도 구인이 활성화됩니다. 시작시간은 비우면 작성본을 받은 현재 KST, 게임정보는 비우면 `미입력`으로 자동 저장됩니다.

- 초기 양식에 `》시작시간 :`, `》게임정보 :`, `》주최자 :`를 표시합니다.
- 세 줄이 모두 빈 무편집 양식은 활성화하지 않습니다.
- 주최자는 별도 저장·표시하며 참가 명단에는 자동 등록하지 않습니다.
- 활성화 후 `상세 번호 추가 이름`, `상세 번호 삭제 이름`으로 참가·탈퇴할 수 있고 최신 구인현황이 함께 표시됩니다.
- 기존 참가행 전체 양식, 선행 `/`, 오전 6시 운영일, 같은 설치 범위 사용자 수정은 유지합니다.
- DRAFT는 현황·상세·빠른 명단 변경에서 숨깁니다.

현재 상태는 소스·마이그레이션·로컬 생성본 반영이며 운영 배포는 하지 않았습니다.
