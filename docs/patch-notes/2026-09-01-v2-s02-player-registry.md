# 디스코드 복붙용 패치 공지 — V2 S02 플레이어 등록부

```text
[K-LOL.GG V2 개발 현황 — 플레이어 등록부]

V2 플레이어 등록부의 사용자 호환 주소와 관리자 CRUD를 한 도메인 계약으로 연결했습니다.

• V1 숫자 플레이어 번호를 보존할 nullable unique legacy ID 추가
• 숫자 상세 주소는 실제 UUID mapping이 있을 때만 308 이동, 없으면 404 처리
• 관리자 플레이어 목록·검색·상세·등록·수정·복구 가능한 비활성화·명시적 재활성화 추가
• 회원명과 사이트 계정 정보는 관리자 화면·API에서만 조회
• 중복 Riot ID/기존 번호 409, 동시 수정 412, 없는 대상 404를 분리
• 생성·수정·비활성화·재활성화와 감사 로그·멱등성 영수증을 하나의 DB transaction으로 처리
• 멱등성 영수증은 24시간 후 만료하고 player mutation 때 만료 행 정리
• 데스크톱·모바일 목록/등록/상세와 empty/error/404/409 상태 화면 검수
• 격리 PostgreSQL 18과 실제 ADMIN/SUPER HTTP 계약 검증 통과
• production 런타임 의존성 취약점 0건과 Git 비밀정보 검사 통과

이 변경은 V2 로컬 후보에만 있으며 운영 Vercel이나 운영 DB에는 반영하지 않았습니다.
라인별 밸런스·MMR 통계는 S05, Riot 계정 연결·동기화는 S12에서 연결합니다.
```
