# 플레이어 전적 화면 개선

- PC에서 모스트·라인·함께한 소환사와 최근 경기를 좌우로 배치했습니다.
- 핵심 성적을 상단에 모으고 필터와 보조 분석은 필요할 때 펼쳐 볼 수 있습니다.
- 모바일에서는 요약을 접거나 펼칠 수 있어 최근 경기까지 빠르게 이동합니다.
- 함께한 소환사와 경기 참가자는 실제 닉네임#태그로 표시합니다. 이름 가리기는 표시 설정에서 선택할 수 있습니다.
- 기록 없는 라인과 중복 정보를 줄였습니다. 이름을 제공받지 못한 경우 이를 명확히 안내합니다.

데이터베이스나 계정 연결 설정을 바꾸지 않으며 전체 동기화는 기존 요청을 계속 처리합니다.
