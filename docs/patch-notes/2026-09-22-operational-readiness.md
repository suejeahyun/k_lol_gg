# 운영 준비 보완 1.0.0 — 공지 준비본

아래 공지는 신규 production 배포·DB·운영 확인 후 게시한다. 디스코드에 자동 게시하지 않았다.

```text
📢 K-LOL.GG 운영 안정화 패치

• 경기 기록 변경이 랭킹·통계에 자동 반영되도록 정기 처리와 재시도를 추가했습니다.
• 파티 목록 누락을 줄이고, 번호로 상세 조회·작성 취소·저장 후 목록 확인을 개선했습니다.
• 오전 6시 내전 모집 마감 후에도 참가·예비 명단을 보관하도록 수정했습니다.
• 회원 연결이 아직 확인되지 않은 신청을 운영 화면에서 구분할 수 있습니다.
• 팀 편성에 작성 중·무효화된 경기 경력이 포함되던 문제를 수정했습니다.
• 최고 관리자용 팀 편성 보정과 서버 진단·처리 시간 기록을 추가했습니다.

사이트 내전 충원 카카오 알림은 별도 휴대폰 설치·대상방 검증 후 활성화합니다.
Riot 최근 솔로 경기 반영은 Riot 연동 설정과 실제 계정 확인 후 사용할 수 있습니다.
기존 휴대폰 봇은 이번 서버 패치만을 위해 교체할 필요가 없습니다.
```

실제 적용 상태와 검사 수치는 [릴리스 QA](../qa-evidence/operational-readiness-v1.0.0-2026-09-22/README.md)를 기준으로 한다.
