# 멸망전 확정 진출 표시 개선 · 1.0.10

- 과거 대회의 확정 진출팀과 현재 계산 순위가 다른 경우, 표를 ‘예선 경기 기록’으로 표시합니다. 오해를 주던 순위 번호는 숨기고 승패·승점·세트 기록과 확정 진출 표시는 유지합니다.
- 본선 진출팀이 확정된 대회는 요약에 실제 확정 팀 수를 표시합니다.
- 원래 경기 결과·진출팀·대진·우승자는 변경하지 않습니다. 현재 계산과 확정 진출이 일치하는 대회 및 진행 중 대회의 순위 표시는 유지합니다.
