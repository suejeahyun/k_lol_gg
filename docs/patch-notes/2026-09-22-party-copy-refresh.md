# 파티 저장 후 최신 양식과 취소 안내

파티 양식을 저장하면 최신 인원·명단·양식코드가 담긴 편집 양식을 함께 보여줍니다. 다음 참가·수정·삭제는 이 양식을 복사해 진행할 수 있습니다.

오래된 빈 양식에서 이름을 지워도 이후 참가자를 자동 삭제하지 않습니다. 변경이 없는 경우 실제로 수정되지 않았다는 점과 최신 양식 사용·구인상세 번호 삭제 이름 명령을 안내합니다. 다른 사람의 동시 참가를 지우는 사고를 방지하는 규칙은 유지합니다.

서버 변경이며 이 기능 때문에 휴대폰을 다시 교체할 필요는 없습니다. 응답 지연은 별도 문제로 R26 설치 여부와 봇속도 확인이 필요합니다. 운영 회원의 참가 상태를 이 배포에서 임의로 변경하지 않습니다.
