# 카카오 V1 strict R11 private 설치본 정합성 수정

운영 서버의 주최자 전용 파티 양식을 R9 휴대폰 코드가 참가행 없는 양식으로 판단해 아무 서버 요청도 보내지 않던 버전 드리프트를 확인했다. 공개 R11 생성 기준은 그대로 두고, 기존 private 설정 4개를 보존해 실제 한 번 붙여넣기 파일을 R11로 재생성했다.

private 생성 과정은 공개 검토본의 런타임 미사용 provenance 배열만 제외해 MessengerBot R의 CRLF 65,535자 제한을 지킨다. 설치 문서는 공개 파일과 과거 R9를 설치하지 않도록 경로·버전·해시를 갱신했다. 실제 제보 양식의 휴대폰 분류와 서버 파서 회귀 테스트, ES5/Rhino 생성 검사, 대상 ESLint를 통과했다.

서버와 사이트는 Vercel 운영 배포 및 health 확인을 마쳤고 운영 데이터는 변경하지 않았다. 실제 휴대폰 파일 교체·컴파일·카카오방 E2E는 아직 수행하지 않았으므로 운영 휴대폰 반영 완료로 보지 않는다.
