# 카카오 R22 간결 명단·미등록 회원가입 안내

내전 명단의 일반 추가와 `수정` 명령은 같은 참가자 슬롯을 갱신한다. 예를 들어 `내전상세 1 수정 02정민/mid/ad`는 기존 참가자를 중복 추가하지 않고 주라인과 부라인을 변경한다.

내전 명단 응답은 `본명 / 닉네임`을 함께 표시하고, 너무 긴 닉네임은 유니코드 문자 기준 9자 뒤에 `...`을 붙여 읽기 쉽게 줄인다. 명단 변경 결과와 현재 인원은 첫 줄에 모아 카카오톡에서 빠르게 확인할 수 있다.

등록 회원 정보에서 찾지 못한 이름은 임의 참가자로 저장하지 않는다. 대신 `https://k-lol-gg.vercel.app/signup`을 표시하고 회원가입 완료 후 다시 추가하도록 안내한다.

파티·내전·스크림의 평상시 양식, 상세, 동기화 응답에서는 빠른 명령과 기능 설명을 반복 출력하지 않는다. 전체 사용법은 `/구인도움말`에서만 확인한다. 서버 파서는 이전 응답에 포함되던 안내 문구도 계속 허용해 기존 복사본 호환성을 유지한다.

휴대폰 설치본 버전은 `KLOL_KAKAO_BOT_V40_R22_2026_09_18`이다. `.private/KLOL_KAKAO_BOT_V1_STRICT_PRIVATE_MESSENGERBOT_R.js` 전체로 기존 코드를 교체해야 한다.

DB migration과 운영 데이터 직접 수정·삭제는 없다.
