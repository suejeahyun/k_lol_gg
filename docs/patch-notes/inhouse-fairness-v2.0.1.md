# 내전 공정성 2.0.1 — 신규 참가자 점수 표시 수정

신규 참가자의 티어가 계산에 반영되어 있어도 선수 카드에 “기본 점수 50”이 표시되던 문제를 수정했습니다.

- 선수 카드에 해당 팀·포지션에 실제 적용된 점수를 표시합니다.
- 두 사람을 교환하면 새 배치의 미리보기 점수로 바뀝니다.
- 현재·최고 티어, 내전 경기 수를 따로 보여 줍니다. 티어가 없으면 확인이 필요하다고 표시합니다.
- 내전 집계 정보가 없다는 이유로 모든 사람이 같은 점수인 것처럼 안내하던 문구를 바로잡았습니다.
- 잘못된 티어 문구를 첫 글자만 보고 정상 티어 점수로 계산하지 않도록 검증을 맞췄습니다.

첫 참가자도 등록 티어로 계산합니다. 예를 들어 별도 보정 없는 주 포지션의 다이아몬드 IV는 68점, 플래티넘 IV는 50점입니다. 최고 티어가 다르거나 부 포지션을 맡으면 점수도 달라집니다.

기존 초안은 페이지를 새로 열면 올바른 적용 점수를 볼 수 있습니다. 프로필 티어를 새로 입력하거나 수정했다면 ‘최신 통계로 재평가’를 눌러 반영해 주세요. 저장된 편성과 점수, 정상 티어의 점수 가중치, 조합 규칙 1→6 및 자동 조정 정책은 유지합니다.
