# NEXUS 마스코트 테마 1.0.0

NEXUS의 대표 마스코트 NEXI와 다섯 친구를 사이트에서 만나보세요.

- 검정·네이비 배경과 블루·보라 포인트로 화면을 변경했습니다.
- 홈에 NEXI 메인 이미지와 NEXI, VEX, RIN, ZANE, LUMI 소개 카드를 추가했습니다.
- 메뉴, 검색, 로그인, 랭킹과 공통 입력 화면에도 같은 색상을 적용했습니다.
- 작은 휴대폰 화면에서도 마스코트를 볼 수 있고 카드를 옆으로 넘길 수 있습니다.
- 앱 아이콘과 링크 공유 이미지도 NEXUS에 맞췄습니다.

기존 회원·경기 기록, 관리자 권한과 카카오톡 기능은 그대로 유지됩니다.
