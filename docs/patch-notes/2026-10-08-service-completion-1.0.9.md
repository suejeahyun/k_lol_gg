# 관리자 목록·확인창·이미지 확대 조작 개선 · 1.0.9

전체 MMR 재계산 확인창에서 Escape로 취소하고 Tab으로 확인창 안의 버튼을 이동할 수 있도록 개선합니다. 처음 열면 취소 버튼을 선택하고, 닫으면 재계산 버튼으로 돌아갑니다. 확인창이 열린 동안 배경의 수동 조정은 잠깁니다.

기존 재계산·수동 조정 권한, 중복 요청 방지와 결과 확인은 유지합니다. 홈 순서, 랭킹 슬라이드와 생성 이미지 테마는 변경하지 않습니다.

Riot 일괄 작업 확인창에도 키보드 이동·취소·초점 복원을 적용합니다. 일괄 연결을 처리하는 동안에는 확인창을 유지하고, 실패하면 창 안에서 결과를 확인할 수 있습니다.

대회 갤러리의 확대 이미지를 Escape로 닫고 원래 이미지로 돌아갈 수 있습니다. 확대 중에는 키보드 초점이 배경으로 빠져나가지 않습니다.

관리자 대회 목록의 진행 상태와 방식을 한국어로 표시해 필터와 대회 현황을 바로 알아볼 수 있도록 정리합니다.

대회·MMR·징계·로그 관리 목록에 페이지 이동과 빈 페이지 복귀를 연결합니다. 챔피언 목록도 페이지를 이동할 때 검색 조건을 유지합니다. 잘못된 조건은 초기화할 수 있으며, MMR 포지션별 정렬과 표시 점수를 일치시킵니다.

작은 화면에서 관리자 대회 검색 입력칸이 카드 밖으로 밀리던 문제를 수정합니다.

운영 MMR은 검증된 백업·복원 후 새 공식으로 전환했습니다. 공개 경기 47회차·104게임을 반영하고 대기 기록 13건을 처리했습니다. 화면 수정의 배포 및 상세 검증 여부는 [최신 검증 기록](../qa-evidence/service-completion-final-2026-10-08/README.md)에 기록합니다.
