# 2026-09-22 사이트 알림·Riot API·운영 진단

사이트 충원 알림을 설치할 수 있도록 별도 MessengerBot R companion 1.0.1을 준비하고, Riot의 RSO 승인이 없어도 운영 API 키를 이용한 직접 계정 연결과 티어·최근 솔로 전적 갱신을 사용할 수 있게 한다. 운영자는 관리자 첫 화면에서 자동 작업과 외부 연동의 기록을 확인한다.

## 적용 내용

- 일반 R25 봇은 유지한다. 별도 사이트 알림 봇에 `사이트알림버전`, `사이트알림상태`, 등록 결과 안내를 추가했다. 명시 등록한 카카오 그룹 세션으로 SITE 본 참가가 9명 이하에서 10명이 될 때 안내하며, 과거 충원을 소급 발송하지 않는다.
- Riot API 설정과 선택적인 RSO 설정을 분리했다. 직접 연결은 Riot 로그인으로 확인한 본인 인증과 구분한다. RSO 승인·클라이언트 설정이 없으면 Riot 로그인은 준비 중으로 표시한다.
- 티어 조회를 현재 League API의 PUUID 경로로 변경했다. 5분마다 동기화 한 건을 처리하며, 대기 작업이 없을 때 이미 연결된 활성·승인 계정 중 최근 요청에서 6시간 이상 지난 계정 한 건을 선택한다. 모든 계정이 정확히 6시간마다 갱신된다는 의미는 아니다.
- 운영자 첫 화면에서 경기 통계 대기·실패, 일일 마감, 실제 이미지 저장소 검사, Riot API/RSO 설정 및 처리 상태, 사이트 충원 알림의 대기·최근 인증 요청을 확인한다. 외부 수신처로 장애 메시지를 발송하지 않는다.
- Riot API 키 진단은 서명된 내부 요청으로 고정된 한국 서버 상태 경로만 한 번 확인한다. 응답 본문·비밀값·회원 식별자는 표시하지 않는다.

## 구분해서 확인할 사항

운영 배포 결과와 검사 근거는 [통합 QA](../qa-evidence/integrations-activation-v1.0.0-2026-09-22/README.md)에 기록한다. 휴대폰 코드 제공은 실제 설치·잠금화면 유지·충원 알림 수신 완료를 뜻하지 않는다. 일반 R25 버전·구인현황·내전현황은 사용자가 실기기 응답을 확인했고, 새 companion은 별도로 설치해야 한다.

Riot 서버 상태 API의 200 응답은 그 경로가 설정된 키를 수락했다는 의미다. League/Match 전 권한이나 RSO 승인 증거로 사용하지 않는다. RSO는 Riot의 별도 승인과 클라이언트 자격이 필요하다. [Riot 공식 RSO 안내](https://developer.riotgames.com/docs/lol#rso-integration).
