# 카카오 파티 주최자 자동 참가 v1.0.0

`2인파티`, `5인파티` 등으로 받은 메타데이터 양식에 주최자를 입력해 처음 활성화하면, 주최자를 파티의 1번 참가자로 같은 transaction에서 자동 등록한다. 따라서 주최자만 입력한 5인 파티는 즉시 `1/5`로 표시된다.

자동 등록은 DRAFT를 처음 활성화하는 순간에만 한 번 적용한다. 활성화 후 주최자 문구를 바꾸거나 같은 메타데이터 양식을 다시 보내도 기존 참가 명단을 교체하거나 삭제된 주최자를 다시 넣지 않는다. 주최자 참가자를 빠른 삭제하는 것은 허용하며, 이때 주최자 표시 정보는 유지된다. 동일 이름을 빠른 추가하면 기존 `ALREADY_PRESENT` 계약으로 중복을 만들지 않는다.

휴대폰 MessengerBot R의 “양식 불러오는 중…” 안내와 R12 입력·전송 방식은 변경하지 않았다. 이번 변경은 서버 도메인 처리만 바꾸므로 휴대폰 코드 재설치가 필요 없다.

오전 6시 이전에도 격리 PostgreSQL 계약 검사가 안정적으로 실행되도록, 카카오 내전 테스트 날짜를 달력 날짜가 아닌 실제 모집 운영일 계산 함수로 통일했다. 운영 로직이나 운영 데이터는 변경하지 않았다.
