# 카카오 구인 마감 대상 조회 핫픽스 v1.0.1

`번호ㅉ`를 정상 명령으로 인식하고도 마감 대상 조회 실패를 입력 형식 오류로 표시하던 문제를 수정했다.

마감 대상은 현재 운영일·같은 설치 범위·같은 번호의 `IN_PROGRESS` 상태로 제한한다. 수정 대상은 `DRAFT | IN_PROGRESS`로 제한한다. 같은 번호의 더 높은 reset 종료·초안 행, 이전 운영일과 다른 방 데이터는 변경하지 않는다.

대상이 없거나 이미 마감된 경우에는 mutation 없이 성공 응답으로 정확한 안내와 최신 전체 구인현황을 반환한다. 전각 숫자·슬래시와 `#` 뒤 공백도 V1 허용 범위에 맞춰 수용한다. 휴대폰 코드는 변경하지 않았다.

운영 배포와 검증 상세는 [`docs/qa-evidence/kakao-party-finish-hotfix-2026-09-12/README.md`](../qa-evidence/kakao-party-finish-hotfix-2026-09-12/README.md)에 기록했다.
