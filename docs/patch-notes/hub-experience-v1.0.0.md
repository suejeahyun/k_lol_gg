# GG HUB 시작 화면·운영 홈 1.0.0

커뮤니티를 만들기 전에는 분위기를 직접 비교하고, 개설한 뒤에는 확인할 일을 먼저 찾을 수 있도록 GG HUB의 시작과 운영 화면을 개선했습니다.

- 첫 화면에 Arena·Lounge·Club 테마 체험을 넣었습니다. 실제 설정 편집기와 같은 미리보기로 비교하며, 선택한 테마로 신청할 수 있습니다.
- 로그인 전 고른 테마는 로그인 후 신청서에도 유지됩니다. 지원하지 않거나 중복된 테마 값은 기본 테마로 처리합니다.
- 개설 신청 성공 후 해당 사이트의 관리 주소로 이동합니다. 새로고침해도 새 신청 화면으로 돌아가지 않습니다.
- 내 사이트에 전체·확인할 일·운영 중 현황, 검색, 상태 필터와 다음 행동을 표시합니다. 확인할 일이 있는 사이트가 먼저 보입니다.
- 설정 게시 실패와 사이트 개설 실패를 구분합니다. 운영 중인 사이트에도 별도로 확인할 일이 표시될 수 있습니다.
- 반려·취소한 신청도 목록에서 찾을 수 있고, 검색 조건을 한 번에 초기화할 수 있습니다.
- 사이트가 없는 첫 운영자에게 신청 순서와 시작 경로를 안내합니다. 목록을 불러오는 중이거나 실패한 경우를 0개 사이트로 표시하지 않습니다.
- 모바일 헤더·계정 버튼·테마 선택·상태 필터와 좁은 화면의 글자 배치를 다듬었습니다. 키보드로 테마를 선택할 수 있습니다.

개설 현황은 조회한 신청·작업 상태이며 실시간 서비스 가용성을 보증하는 수치가 아닙니다. 유료 결제·동적 휴대폰 설정·제휴·공동 대회는 이번 릴리스의 완료 범위가 아닙니다. 회원·경기·점수·DB 스키마·휴대폰 설치본은 변경하지 않았습니다.
