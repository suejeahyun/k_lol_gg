# 카카오 응답 속도 개선·내전 정보

일반 봇 R26은 글자 명령 처리 전에 불필요하게 이미지 조회를 시도하던 경로를 건너뜁니다. 내전 명단 회원 확인과 기존 참가 확인을 묶어 DB 왕복을 줄였습니다. 10명 등록의 SQL 요청은 격리 테스트에서 58회에서 40회로 감소했습니다. 휴대폰에서 보고한 30초 지연이 해결됐는지는 R26 설치 후 확인해야 합니다.

일반 봇의 전체 코드를 R26으로 교체하고 저장·컴파일 후 /봇버전, 내전상세 1, 봇속도를 한 줄씩 보내 확인합니다. 봇속도는 직전 처리·서버 왕복 시간을 보여주며 카카오 알림 수신 전 대기는 포함하지 않습니다. 사이트 알림 companion 1.0.3은 유지합니다.

최신 내전 양식에서 내전 정보: 저티어 내전 / 일반내전처럼 자유 설명을 적을 수 있습니다. 설명을 비우면 삭제하고, 항목이 없는 예전 양식은 기존 설명을 유지합니다. 다른 사람이 먼저 바꾼 정보를 오래된 양식이 덮어쓰지 않습니다. 명단·라인·참가 인원은 그대로 보존됩니다.
