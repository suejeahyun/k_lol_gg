# 검색·팀 만들기·오류 복구 개선

- 이벤트전과 멸망전에서 상태나 방식을 선택하지 않아도 정상적으로 검색할 수 있습니다.
- 필터를 초기화하면 화면의 선택값도 전체 상태로 돌아옵니다.
- 내 제출 기록의 '전체 상태' 조회 오류를 수정했습니다.
- 잘못된 검색 주소에서 전체 목록으로 돌아갈 수 있도록 안내를 보완했습니다.
- 팀을 만들면 결과가 바로 보이며, 입력 오류가 있으면 수정할 칸으로 이동합니다.
- 모바일 참가자 입력 글씨를 키웠습니다.
- 참가·제출 기록을 불러오지 못했을 때 다시 불러오는 버튼을 추가했습니다.

- 작은 휴대폰에서도 긴 플레이어 이름·MMR 입력·갤러리 작성·이벤트 운영 화면이 옆으로 밀리지 않도록 조정했습니다.

홈의 요청 순서, 단일 랭킹 슬라이드와 생성 이미지 테마는 유지합니다.
