# 멸망전 점수표

상태: 로컬 구현·검증 완료, 운영 미배포.

멸망전 상세 화면에 **점수표** 메뉴를 추가했습니다.

- 칼바람·증바람의 등급별 최소 입찰가와 주장 시작 포인트를 표로 확인할 수 있습니다.
- 평가가 완료된 선수의 전적, 등급, 경매 포인트와 전적 출처를 함께 볼 수 있습니다.
- 소환사의 협곡은 기존 티어·포지션별 점수표를 복원했습니다. 실버 3 이하부터 마스터·그랜드마스터·챌린저 LP 구간까지 38개 구간, 5개 포지션의 주장 시작 포인트를 확인할 수 있습니다.
- 협곡 팀별 실제 시작·사용·잔여 포인트와 선수별 낙찰 포인트도 함께 표시합니다. 주장은 경매 제외, 낙찰 전 선수는 경매 대기로 구분합니다.
- 모바일에서는 표를 좌우로 밀어 전체 항목을 볼 수 있습니다.

기존 점수 계산과 경매 규칙은 그대로 유지됩니다.
협곡 표의 기준값은 운영자가 확인해 입력하며, 팀 확정 이후 저장된 실제 포인트를 자동 변경하지 않습니다.
