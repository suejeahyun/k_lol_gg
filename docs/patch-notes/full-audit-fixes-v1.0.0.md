# 전체 점검 후 안정성·사용 흐름 개선 1.0.0

2026-10-13 KST. `full-audit-fixes@1.0.0`을 **운영 반영했습니다**. 최종 통합 검사와 주요 브라우저 흐름 검증, 운영 DB 개선 및 배포 후 HTTP 34조건·DB 무결성 검사를 통과했습니다. 세부 검증 범위는 [QA 기록](../qa-evidence/full-audit-fixes-2026-10-13/README.md)과 [배포 기록](../qa-evidence/full-audit-fixes-2026-10-13/production.md)을 기준으로 확인합니다.

## 경기 기록과 정보 갱신

- MMR에 반영한 경기의 제목·결과를 수정할 때 과거 MMR 기록과 충돌하던 문제를 해결했습니다. 계산에 사용한 경기 이력을 보존하면서 정정과 재집계를 이어갈 수 있습니다.
- 경기가 많이 쌓이면 MMR 저장 요청이 데이터베이스 한도를 넘던 문제를 수정했습니다. 나누어 저장하되 중간 실패 시 전체 계산을 되돌립니다.
- Riot 정기 갱신은 한 번에 최대 4개 작업을 차례로 처리하도록 개선했습니다. 제공자의 재시도 대기와 호출 제한을 유지하며, 실제 완료 시간은 대기량과 외부 응답에 따라 달라집니다.
- 모집·참가 현황에 마지막 조회 시각과 새로고침을 추가했습니다. 다른 탭에서 돌아오면 일정 간격을 두고 최신 상태를 확인합니다.

## 신청·가입·관리 화면

- 정원이 찬 모집에서는 예비 참가를 직접 선택해야 신청할 수 있도록 안내를 바로잡았습니다.
- 시즌 생성·수정·심사와 카카오 대기 연결 요청이 실패해도 작성한 입력을 유지합니다.
- 사용자·관리자 플레이어 정보와 참가 신청을 다른 곳에서 동시에 수정했을 때 작성 내용을 보존합니다. 최신 저장값을 비교한 뒤 입력을 유지하거나 버리는 선택을 할 수 있습니다.
- 운영 신청 목록에 조건별 건수와 이전·다음 페이지를 추가해 100건 이후의 기록도 확인할 수 있습니다. 유형·상태 필터는 페이지를 이동해도 유지됩니다.
- 가입 후 승인·연결 검토 결과를 충분히 읽고 로그인으로 계속할 수 있습니다. 아이디·비밀번호·Riot ID 오류는 해당 입력에서 안내합니다.
- 좁은 휴대폰 화면에서 긴 최근 경기명이 플레이어 상세 화면 밖으로 넘치던 문제를 수정했습니다.

## 이미지·로그인·운영 관리

- 공개 이미지는 위치 등 EXIF 메타데이터를 제거한 파생본으로 제공합니다. 저장된 원본과 증거 자료는 보존합니다. 공개를 철회한 이미지의 새 요청은 게시 상태를 다시 확인합니다.
- 미사용 일반 미디어와 오래된 인증 정보를 보관기간과 참조 확인을 거쳐 제한된 수량씩 정리하는 예약 작업을 추가했습니다. 참조 중인 사진과 경기·징계 증거는 일반 미디어 정리에서 제외합니다.
- Riot 외부 로그인 콜백을 시작한 세션과 정확히 연결하도록 보완했습니다. **실제 RSO 제공자 연결은 활성화하지 않았으며 실제 제공자 왕복 검증도 아직 수행하지 않았습니다.**
- 설치 앱에서 같은 주소의 정적 이미지가 바뀌었을 때 최신 파일을 다시 확인하도록 했습니다. 로컬 캐시 공간이 부족해도 정상적으로 받은 새 파일을 화면에 전달합니다.
- 운영 의존성 취약점은 이번 감사 기준 0건입니다. CI의 비밀정보·운영 의존성 검사와 주간 의존성 업데이트 구성을 보강했습니다. 개발 도구에만 걸친 감사 항목 12개(moderate 4, high 8)는 호환 가능한 수정 확인이 더 필요합니다.

이미 내려받았거나 과거 캐시에 남은 이미지 원본을 소급 회수하지는 않습니다. 기존 **카카오 실기기·방 확인과 MMR v2 적용의 사용자 확인 완료 상태는 유지**합니다.
