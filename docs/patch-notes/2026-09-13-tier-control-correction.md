# 티어·단계 입력 구조 정정

내 정보의 현재 티어와 최고 티어 입력을 사용자 요구에 맞게 두 칸으로 분리했다. 왼쪽은 아이언부터 챌린저까지 티어 10종을 선택하고, 오른쪽은 다이아몬드 이하에서 1·2·3·4 단계를 선택한다. 마스터 이상을 고르면 같은 오른쪽 칸이 LP 수기 입력으로 바뀐다.

기존 저장 형식과 API는 `DIAMOND II`, `MASTER 120`처럼 그대로 유지한다. 기능 커밋은 `fd87e5f47703f92f09e1d4db70617ee2aa49fc92`, tag는 `ui-workflow-refinement-v1.0.1`이다. 실제 PostgreSQL·Chromium 저장 및 412 충돌 복원, 전체 테스트·빌드, 105개 페이지 339개 화면 캡처가 통과했다. 운영 배포와 운영 DB 변경은 하지 않았다.
