# 대회·MMR 데이터 일관성 1.0.0

2026-10-29 · 소스 수정 단계, 운영 미배포

- 대회 선수를 교체하면 이전 선수의 임시 등급·수집 상태·자기 신고 전적이 새 선수에게 남지 않게 수정했습니다. 기존 경기 명단과 구매 가격 이력은 보존합니다.
- 10명이 필요한 이벤트에서 11명 이상 활성 참가자로 등록되는 문제를 막았습니다. 기존 참가자의 선호 포지션 수정은 가능합니다.
- 포지션 MMR이 없는 선수의 순위를 화면에 표시하는 종합 대체 점수와 같은 기준으로 정렬합니다.
- 공개 순위와 관리자 목록의 ‘종합 신뢰도’를 ‘종합 표본 충족도’로 바꾸고 30경기 기준을 설명합니다. 예측 정확도를 뜻하는 수치가 아닙니다.

MMR 산식과 기존 점수는 바꾸지 않았습니다. 입력 경기 묶음·포지션 보정의 영향, 대회 방식과 실제 동작 차이, 다음 산식의 검증 계획은 [전체 점검 보고서](../architecture/drafts/balance-mmr-audit-2026-10-29.md)에 정리했습니다.
