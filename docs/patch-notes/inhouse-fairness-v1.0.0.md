# 내전 밸런스 규칙 개선

- 선택한 주·부 포지션 안에서 먼저 편성하며, 한 포지션만 선택하면 해당 포지션을 유지합니다. 다른 포지션 배정은 별도로 허용한 경우에만 사용합니다.
- 원딜끼리와 서포터끼리 현재 티어를 각각 비교합니다. 큰 등급이 3단계 이상 차이 나는 조합은 추천·수동 배치·저장에서 제한합니다. 골드와 다이아몬드는 골드→플래티넘→에메랄드→다이아몬드로 3단계입니다.
- 팀 총점뿐 아니라 라인별 격차, 바텀 합산 전력, 주·부 포지션 이탈 분포와 양 팀의 승리 가능 경로를 함께 봅니다.
- 고티어 미드·정글 분산, 탑·미드 우세 분산, 바텀 상호 보완과 서포터 열세 측의 정글 보완을 조건으로 평가합니다. 불가능한 조건을 맞췄다고 표시하지 않습니다.
- 공정성 충족·조건부·정보 확인 필요를 구분합니다. 승률 수치는 점수 기반 참고 추정치이며 실제 승률을 보장하지 않습니다.

자세한 기준은 [내전 밸런스 규칙](../inhouse-balance-rules.md)에 정리했습니다.
