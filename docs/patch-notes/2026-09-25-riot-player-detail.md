# 플레이어 Riot 전적 상세 · 1.0.0 안내 초안

현재는 소스 반영과 검증 중인 초안입니다. 운영 배포, 모든 회원 동기화, 과거 경기 전체 수집이 완료됐다는 공지가 아닙니다.

플레이어 상세의 Riot 화면에서 전적을 종합·챔피언·분석 리포트로 나누어 볼 수 있도록 확장했습니다.

- 모스트 챔피언, 라인별 비율·승률·게임 수, 최근 20경기 흐름과 날짜별 성적을 표시합니다.
- 연도, 게임 종류, 여러 패치, 라인, 챔피언, 승패, 기간을 선택해 현재 불러온 경기를 분석합니다. 더 보기를 통해 저장된 이전 경기를 이어서 확인합니다.
- 경기 상세에서 참가자별 성적, 아이템·룬·주문, 10/15분 비교와 시간대별 골드·CS·경험치·팀 골드 차이를 확인합니다. 수집되지 않은 정보는 없는 상태로 표시합니다.
- 챔피언 화면에서 개인의 아이템·룬·주문 조합, 시작 아이템·신발·1~3코어 구매 순서·스킬 선택의 빈도와 승률을 확인합니다. 개인 기록의 통계이며 서버 전체 추천 빌드는 아닙니다.
- 분석 리포트는 성장·교전·오브젝트·시야·15분 골드 차이·초반 킬 관여를 실제 경기 수치로 계산합니다. 산식과 표본 수를 함께 표시합니다.
- 현재 분석을 이 브라우저에 최대 10개까지 저장하여 이전 결과와 확인할 수 있습니다. 다른 기기나 서버로 공유되지 않습니다.
- 관리자 Riot 목록에 전체 건수, 현재 표시 범위, 이전/다음 페이지를 추가했습니다. 전체 동기화가 목록 한 페이지가 아닌 연결된 전체 계정 대상임을 안내합니다.

전적은 최근 180일 범위에서 차례로 수집하며 경기 상세와 큰 타임라인은 수집 속도가 다를 수 있습니다. 화면에 저장된 경기 수, 현재 불러온 경기 수와 수집 진행 상태를 표시합니다. 사이트 내전 기록과 Riot 매칭 전적은 별도로 유지합니다.

날짜별 티어·LP는 동기화한 날부터 기록됩니다. 동기화 전의 LP나 게임별 LP 증감은 추정해서 만들지 않습니다. 연도 필터와 수집 완료 표시는 시즌 전체 통계 수집을 의미하지 않습니다.

lol.ps의 독자 인분·MVP·팀운·멘탈 점수, 전체 티어 대비 백분위, 지역 전체 승픽밴율, 유료 AI 분석은 이번 개인 경기 통계와 같은 기능이 아닙니다. 참고 화면의 모든 기능 32개를 동일하게 완료했다고 안내하지 않습니다. 구매 순서의 완성 아이템 분류는 Data Dragon 16.17.1 기준이며 패치별 차이가 있을 수 있습니다.

최종 전체 검사, 운영 DB 변경, 배포와 실제 동기화 결과를 확인한 뒤 운영 반영 여부를 확정합니다. 검증 시점별 상태는 [QA 근거](../qa-evidence/riot-player-detail-v1.0.0-2026-09-25/README.md)에 기록합니다.
