# GG HUB 사이트 개설 스튜디오 0.1.1

[GG HUB](https://gg-community-hub.vercel.app)에 자동 개설용 전용 연결과 두 가지 오류 수정을 반영하고 예약 실행을 켰습니다. 실제 운영 worker가 QA 사이트를 소유자 확인 대기 상태까지 준비했으며 사후 검증과 QA 정리도 완료했습니다. 실패한 작업을 수정 후 재개한 검증입니다. 빈 큐에서 자연 예약 호출이 HTTP 200으로 완료된 것도 확인했습니다. 사이트 생성 완주는 인증된 수동 worker 호출로 검증했습니다. [검증 근거와 범위](../qa-evidence/community-site-provisioning-enabled-2026-10-29/README.md).

- Blob 저장소 연결이 빈 HTTP 201 응답을 반환할 때 개설이 멈추던 오류를 수정했습니다. 실제 운영 worker가 저장소를 다시 연결하는 경로도 확인했습니다.
- 사이트 이름에 괄호 등 정규식 특수 문자가 들어가면 빌드가 실패하던 오류를 수정했습니다.
- 공급자 연결 결과 조회는 최대 4회로 제한하며, 다른 소유자나 프로젝트가 발견되면 즉시 중단합니다.
- 전체 검사에서 계약 801개·단위 1,286개가 통과했고 기존 단위 1개는 건너뛰었습니다. 별도 provider 28개와 이름·브랜드 호환성 44개 검사도 통과했습니다.

개설 신청, Arena·Lounge·Club 세 테마, 사이트별 기능 켜기·끄기와 기록 보존은 1단계 범위입니다. 연합·공동 대회·운영 기록 공유·기존 사이트의 본인 계정 연결·휴대폰 봇의 동적 설정은 후속 작업입니다.

기존 요금제의 사용량에 따른 비용은 발생할 수 있습니다. 새 고정 월정액 구독이나 요금제 업그레이드는 진행하지 않았습니다.
