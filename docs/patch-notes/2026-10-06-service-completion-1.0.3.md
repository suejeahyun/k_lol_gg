# 처음 와도 더 쉽게 참가하고 결과를 남겨요

- 홈 랭킹에서 승률·최다 참여·최다 MVP를 이름으로 바로 선택할 수 있습니다.
- 경기 결과 제출은 필요한 정보부터 입력하고 이미지 등록으로 이어집니다. 선택 정보와 접수 코드 이어하기를 보조 영역으로 정리했습니다.
- 신청 종류에 맞는 메뉴 표시와 한글 포지션 안내를 맞췄습니다.
- 팀 검색을 지우거나 초기화하면 검색 중 표시도 정상 종료됩니다.
- 존재하지 않는 경기·플레이어 또는 잘못된 접수 주소에서 메뉴와 배경이 두 번 표시되는 문제를 수정했습니다.
- 관리자 오류 화면은 관리자 메뉴를 유지하며 관리 홈과 검색으로 돌아갈 수 있습니다.
- 기존 참가·팀 편성·결과 제출 기능, 홈 영역 순서와 이미지 테마는 유지합니다.
