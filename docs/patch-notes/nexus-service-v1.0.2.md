# NEXUS.GG 1.0.2 — Riot 사이트 소유 확인

NEXUS.GG 전용 Riot 운영 키 신청이 접수되어, 공식 포털이 지정한 사이트 소유 확인 파일을 `/riot.txt`에 추가했다. 이 파일은 공개 검증 코드이며 API 키가 아니다.

참가비와 상금은 없음, 대회 방식·최소 경기 수·일정은 미정으로 기재했다. 내전 MMR·공개 순위·팀 배치·대회 등급 산정 기능을 설명하고 Riot의 명시적인 검토를 요청했다.

운영 키 승인·발급 전에는 실제 Riot 연동을 활성화하지 않는다. 카카오 봇 설치 상태와 기존 K-LOL 운영 자원은 변경하지 않는다. [검증·신청 상태](../qa-evidence/nexus-riot-verification-2026-10-27/README.md).
