# 카카오 R17 내전 종목별 양식 복구

파티 구인은 현재 동작을 유지하고, 내전 구인은 종목에 따라 기존 사용자가 익숙한 전체 양식을 생성하도록 복구했다.

- `내전구인 협곡`은 `이름/현티어/최고티어/주라인/부라인` 10칸 양식을 생성한다.
- `내전구인 칼바람`, `내전구인 증바람`은 이름 10칸 양식을 생성한다.
- 양식 생성만으로 내전이 공개되지 않는다. 게임정보·주최자와 참가자를 작성해 전체 전송하면 활성화된다.
- 칼바람·증바람에서 참가자 칸을 비우고 주최자만 작성하면 주최자를 1번 참가자로 등록한다.
- 협곡 빠른 추가는 `내전상세 번호 추가 이름`과 `내전상세 번호 추가 이름/현티어/최고티어/주라인/부라인`을 모두 허용한다.
- 이름만 빠르게 추가하면 포지션은 `ALL`, 상세 입력하면 입력한 주·부 포지션으로 저장한다.
- 빠른 삭제, 전체 양식 재전송, `내전 번호ㅉ` 마감과 같은 방의 다중 사용자 사용 규칙은 유지한다.
- 파티 구인 생성·활성화·추가·삭제·현황·마감 코드는 변경하지 않았다.

휴대폰 설치본 버전은 `KLOL_KAKAO_BOT_V40_R17_2026_09_14`이다. `.private/KLOL_KAKAO_BOT_R17_MODE_FORMS_REPLACE_ALL.js` 전체로 기존 코드를 교체해야 한다.

DB migration과 운영 데이터 직접 수정·삭제는 없다.
