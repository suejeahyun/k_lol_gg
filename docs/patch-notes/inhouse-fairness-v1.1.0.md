# 내전 공정성 1.1.0 — 규칙 우선순위와 자리 교환 설명

## 변경 내용

- 조합 규칙을 1번부터 6번 순서대로 비교합니다. 상위 규칙이 같을 때만 다음 규칙을 보므로 하위 규칙 여러 개가 상위 규칙을 덮지 않습니다.
- 참가자의 허용 역할·바텀 큰 등급 3단계 금지, 심한 불균형 검사와 기타 포지션 부담 기준은 유지합니다.
- 화면과 복사 결과의 미검증 ‘예상 승률’을 팀 전력 점수로 바꿨습니다. 이전 비율은 팀 합계 차이 40점을 90.9%로 환산했으며 실제 경기 승률을 뜻하지 않았습니다.
- 수동 교환 중에는 적용 전 결과와 교환 후 점수 미리보기를 구분합니다. 최종 적용은 서버 평가를 거칩니다.
- 과거 초안은 새 우선순위로 평가됐다고 표시하지 않습니다. 최신 통계로 재평가하면 새 규칙을 적용합니다.

## 두 명만 바꿨는데 숫자가 크게 달라지는 이유

서로 다른 팀의 20점 차이 선수를 바꾸면 한 팀은 20점 줄고 상대는 20점 늘어 격차가 40점 변합니다. 같은 팀 내 교환도 주·부·기타 역할 보정이 달라지면 전력이 변합니다. 마스터 합성 사례에서는 두 명을 주→부로 옮길 때 36점이 줄어 이전 표시값이 상대 88.8%가 됐습니다.

기존 개인 점수·관리자 보정·저장 이력은 유지합니다. 실제 경기 결과로 검증하지 않은 비율을 확률처럼 보여주던 부분을 수정했습니다.
