# 내전 공정성 2.0.0 — 막힘 없는 자동 팀 편성

10명을 골랐지만 포지션이나 바텀 티어 조건이 충돌해 팀이 만들어지지 않던 흐름을 개선합니다.

- 먼저 요청한 포지션과 바텀 제한을 모두 만족하는 팀을 찾습니다.
- 가능한 조합이 없으면 같은 참가자들의 배치를 자동으로 조정합니다. 바텀 큰 티어 격차를 우선 줄이고, 추가로 맡아야 하는 포지션 인원을 최소화한 뒤 전력과 조합 규칙 1→6 순서로 추천합니다.
- 결과에서 누가 어떤 포지션으로 조정됐는지와 남은 티어 차이를 확인할 수 있습니다. 원래 등록한 포지션과 개인 점수는 바꾸지 않습니다.
- 자동 조정된 팀도 선택·수동 평가·저장·재평가까지 이어서 사용할 수 있습니다.
- 기존 초안은 ‘최신 통계로 재평가’를 누르면 새 계산을 적용합니다.

참가자는 여전히 서로 다른 10명이어야 합니다. 팀당 5명과 각 역할 1명은 유지합니다. 이번 변경은 밸런스 계산 시 동작하며 시간마다 자동 실행하는 기능이 아닙니다.
