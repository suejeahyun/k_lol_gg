# 카카오 R24 1.0.1 — 파티 양식 문구 정리

파티 양식에서 중간 복사 안내와 양식코드 뒤 괄호 설명을 제거하고 참가/예비 명단 사이에 빈 줄을 넣는다. 사용자가 제시한 간단한 복사 양식에 맞춘 서버 응답 변경이다.

기존 휴대폰 봇 산출물은 유지한다. 생성·상세·참가 저장 후 최신 양식 모두 같은 renderer를 사용하며 사이트 연동과 저장 정책은 유지한다.
