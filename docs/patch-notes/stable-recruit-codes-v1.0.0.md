# 파티 모집코드 유지와 명단 버전 분리 1.0.0

2026-10-14 KST. `stable-recruit-codes@1.0.0` 서버 운영 반영을 완료했습니다. 최종 통합 검사·격리 DB 검증, 운영 DB 적용·health·서명 조회를 통과했습니다. [QA 기록](../qa-evidence/stable-recruit-codes-2026-10-14/README.md)에 배포 근거를 기록했습니다. **새 코드 직접 명령을 위한 R28 휴대폰 설치는 별도로 필요합니다.**

## 같은 모집은 같은 코드를 사용합니다

파티를 처음 만들 때 발급한 **모집코드**를 이름·시간·게임을 수정해도 그대로 유지합니다. 다른 모집을 새로 만들 때 새 코드를 발급합니다. 마감한 모집의 코드를 다시 사용해 새 모집을 열지는 않습니다.

양식에는 다음 두 줄이 표시됩니다.

```text
모집코드: ABCDE-23456
명단버전: 4
```

모집코드는 모집을 식별하고, 명단버전은 복사한 당시 내용을 구분합니다. 사용자는 두 줄을 수정하지 않고 명단 전체를 복사하면 됩니다. 여러 사람이 함께 작성할 때 먼저 참가한 이름을 지우거나 다른 사람의 수정을 덮어쓰지 않도록 기존 충돌 검사를 유지합니다.

## 코드로 조회·참가·취소·마감할 수 있습니다

- 최신 양식: `구인상세 ABCDE-23456`
- 참가: `상세 ABCDE-23456 추가 홍길동`
- 취소: `상세 ABCDE-23456 삭제 홍길동`
- 마감: `구인마감 ABCDE-23456` 또는 `ABCDE-23456ㅉ`

코드 명령은 운영일이 바뀌어도 원래 모집을 찾습니다. 기존 `구인상세 3`, `상세 3 추가/삭제 이름`, `3ㅉ`는 현재 운영일의 번호를 대상으로 계속 사용할 수 있습니다.

**새 코드 명령은 휴대폰 봇 R28 설치가 필요합니다.** 새 두 줄이 포함된 전체 양식 복사는 기존 compact copy 전달과 호환됩니다. 공개 생성본·비공개 설치본·실제 휴대폰 설치 상태는 [설치 안내](../../integrations/messengerbot-r/MESSENGERBOT_R_INSTALL.md)에서 구분합니다.

## 오전 6시와 기존 양식 안내

고정 모집코드는 유지되지만 복사 원본은 다음 운영일 경계인 오전 6시에 만료됩니다. 오래된 양식이 거부되면 같은 모집코드로 최신 양식을 다시 받으면 됩니다. 모집 자체의 기존 자동 마감·오래된 초안 정리 정책은 유지합니다.

기존 모집은 다음 상세 조회나 저장 때 고정 모집코드를 처음 받습니다. 이미 받은 `양식코드`가 있는 파티 양식도 해당 운영일 유효기간 안에서 계속 지원합니다. 기존 코드를 다른 모집에 재할당하지 않습니다. **내전 양식과 참가 방식은 이번 변경 대상이 아닙니다.**
