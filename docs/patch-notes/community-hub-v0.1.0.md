# GG HUB 0.1.0

K-LOL과 NEXUS를 관리하는 중앙 사이트를 별도로 분리했습니다.

- 독립 주소·DB·로그인을 갖춘 GG HUB 홈과 관리자 화면
- K-LOL/NEXUS 소개와 사이트 방문, 사이트·방 추가와 수정
- 중앙 인증 정보와 기존 사이트 인증 정보 분리
- 중앙 사이트에서 게임·카카오·기존 사이트 관리 API 접근 차단
- 기존 회원·모집·경기·MMR 및 휴대폰 봇 유지

현재는 등록·관리 기반입니다. 실제 사이트 API 연결, 내 가입 사이트, 연합, 공동 대회, 운영 기록 공유와 동적 폰 설정 배포는 후속 구축 범위입니다.
