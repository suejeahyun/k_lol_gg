# 사이트 시각 효과·가독성 개선 v1.0.0

## 사용자 화면

- 홈 핵심 영역에 짧은 1회 등장 효과와 표면 깊이를 적용했습니다.
- 구인 카드에서 모집 유형, 상태, 정원, 주최자를 더 빠르게 구분할 수 있습니다.
- 경기 카드에 블루·레드·무승부 결과 밴드와 승리 팀 텍스트를 추가했습니다.
- 랭킹 상위 1~3위와 내 순위, MMR 상태의 시각적 위계를 강화했습니다.
- 팀 밸런스의 활성 단계와 결과, 이벤트 대회와 멸망전의 색조를 구분했습니다.
- 미디어 카드의 이미지 비율, 대표 카드, 포커스와 오버레이를 개선했습니다.

## 계정·관리자

- 입력, 선택, 성공, 경고, 오류 상태를 명확히 구분했습니다.
- 작은 본문과 메타 정보의 대비와 가독성을 보강했습니다.
- 장시간 사용하는 운영 화면에는 반복·무한 효과를 적용하지 않았습니다.

## 접근성·성능

- hover 효과는 정밀 포인터에서만 동작합니다.
- `prefers-reduced-motion`과 forced-colors 경계를 추가했습니다.
- 영상, 파티클, 새 폰트, 새 애니메이션 라이브러리는 추가하지 않았습니다.
