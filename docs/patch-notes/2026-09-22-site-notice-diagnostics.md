# 사이트 알림 1.0.2 진단 후보

별도 알림 봇을 설치·실행한 후에도 버전 명령에 응답하지 않는다는 실기기 보고에 따라, 원인을 확인할 수 있는 휴대폰 진단을 추가했습니다. 실제 원인은 아직 확정하지 않았으며 실기기 해결 완료로 표시하지 않습니다.

- 초기화가 실패해도 버전 확인과 `사이트알림진단`을 사용할 수 있습니다.
- 초기화·메시지 수신·답장 실패 단계를 비밀정보 없는 고정 로그로 구분합니다.
- 일반 R25와 동일하게 Java SDK 답장 메서드를 JS 함수로 감싸고 원래 수신 세션을 유지합니다.
- 새 개인 설치본에는 새 로컬 등록 코드가 포함됩니다. 서버 대상은 동일하며 운영 서버·DB·일반 R25는 변경하지 않았습니다.

로컬 후보만 준비했습니다. 사용자가 1.0.2로 교체한 뒤 버전·진단 응답 또는 로컬 로그를 확인해야 합니다. 이전 경고 사진은 사용자가 다른 코드 화면이라고 정정하여 원인 근거에서 제외했습니다.
