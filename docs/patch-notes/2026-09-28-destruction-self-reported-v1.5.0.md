# 칼바람·증바람 멸망전 신청 시 승패 입력

- 참가 신청에 해당 모드의 누적 승수·패수를 숫자로 입력합니다. 캡처 첨부는 필요하지 않습니다. 증바람 대회에는 증바람, 일반 칼바람 대회에는 일반 칼바람 승패를 입력합니다.
- 총 판수·승률·소표본 보정 점수를 입력 화면에서 확인할 수 있습니다. 음수·소수는 입력할 수 없으며 0승 0패는 미확인으로 처리합니다.
- 최종 점수는 본인 기재 승패 20% + 솔랭 40% + 내전 20% + 챔피언 대응력 15% + 도전과제 5%로 계산합니다. 나머지 네 항목은 자동 수집합니다.
- 참가 확정 후에도 주장·팀 확정 전까지 본인이 승패를 수정할 수 있으며, 수정하면 해당 항목과 경매 가격을 다시 계산합니다. 확정 후에는 수정할 수 없습니다.
- 이미 확정된 대회는 기존 평가를 유지합니다. 미확정 대회의 기존 자동 칼바람 점수는 본인 기재 승패 방식으로 전환하며, 입력이 없으면 평가 대기로 표시합니다.
