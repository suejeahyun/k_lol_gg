# V2 S09 구인·스크림·Kakao — 개발 검증 공지 초안

> 상태: 소스·정적·단위·격리 PostgreSQL 18 집중 검증 단계. 운영 Kakao와 Vercel에는 반영하지 않았습니다.

## 디스코드 복붙용

```text
[K-LOL.GG V2 개발 소식 — 구인·스크림]

구인과 스크림 모집 흐름을 V2 구조로 새로 만들었습니다.

• 공개 모집판: 진행 중인 구인을 한눈에 보고 승인 회원이 새 파티를 등록할 수 있습니다.
• 상태 흐름: 모집 생성, 인원 동기화, 마감·취소와 스크림 참가·확정·완료 상태를 안전하게 관리합니다.
• 관리자 작업대: 진행 목록과 상태를 확인하고, 위험한 전체 초기화는 SUPER 권한으로 분리했습니다.
• Kakao 연동 경계: 요청 원문 서명, 시간 제한, 일회용 nonce, 허용 방·발신자, 봇 자기 호출을 모두 확인합니다.
• 재시도 안전성: 같은 요청은 같은 결과를 돌려주고, 같은 키로 다른 내용을 보내면 거부합니다.
• 개인정보 보호: 공개 화면에는 검토된 모집 정보만 노출합니다.

현재는 개발 검증 단계이며 운영 사이트에는 아직 반영되지 않았습니다.
전체 브라우저·접근성·운영 설정 검증이 끝난 뒤 다시 안내하겠습니다.
```
