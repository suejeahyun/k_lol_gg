# 칼바람·증바람 멸망전 임시 평가 1.6.0

- 평가 비중을 해당 모드 판수 30%, 솔랭 실력 50%, 협곡 내전 10%, 챔피언 대응력 5%, 칼바람 도전과제 5%로 변경했습니다.
- 참가 신청 시 승수·패수를 숫자로 입력하면 합계를 총 판수로 평가합니다. 승률은 점수에 반영하지 않습니다.
- 초기 판수 환산 기준은 `min(총 판수 / 300 × 100, 100)`입니다. 150판은 항목 50점·최종 총점 15점, 300판 이상은 항목 100점·최종 총점 30점입니다. 경험량의 임시 기준이며 검증된 실력 추정치는 아닙니다.
- 직접 기재한 0판은 0점입니다. 미입력은 0점으로 간주하지 않고 평가 대기로 남깁니다.
- 주장·팀 확정 전 본인 수정과 자동 재계산이 가능합니다. 기존 기본 비중의 미확정 대회는 새 공식으로 전환하고, 별도로 설정한 대회 비중은 보존합니다. 이미 확정한 경매의 공식·점수·금액은 유지합니다.
- 대회별 비중은 기존 관리자 화면에서 합계 100%로 변경할 수 있습니다.
