# 칼바람·증바람 멸망전 자동 임시 티어

소스 구현 버전: destruction-modes 1.4.0. 운영 미배포.

- 참가자 확정 후 일반 칼바람 20%·솔랭 40%·내전 20%·챔피언 대응력 15%·칼바람 도전과제 5%로 자동 평가합니다.
- 각 항목을 100점으로 환산하고 고정 기준으로 S/A/B/C/D 등급을 정합니다. 일반 칼바람과 증바람 멸망전에 동일하게 적용합니다.
- 공개 점수표에서 항목별 점수·비중·총점·등급·경매 포인트를 확인할 수 있습니다.
- 운영자는 주장 확정 전 비중을 조정할 수 있습니다. 확정 후에는 점수와 경매 기준이 고정됩니다.
- 자료가 없으면 0점으로 처리하지 않고 확인 대기로 표시합니다. 누락 자료는 근거를 남겨 보완하거나 자동 수집을 재시도할 수 있습니다.

S 80점·A 65점·B 50점·C 35점 이상, 나머지 D를 초기 기준으로 적용합니다. 증바람 직접 전적이나 판수를 자동으로 가져오는 기능은 포함하지 않으며, 최초 환산 기준의 실력 예측력은 추후 검증이 필요합니다.
