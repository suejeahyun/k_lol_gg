# V2 S07 이벤트전 — 개발 검증 공지 초안

> 상태: 소스·타입·단위·격리 PostgreSQL 18 집중 검증 단계. 전체 build, 브라우저 QA, 운영 DB와 Vercel에는 반영하지 않았습니다.

## 디스코드 복붙용

```text
[K-LOL.GG V2 개발 소식 — 이벤트전]

이벤트전의 모집부터 우승 확정까지 이어지는 V2 흐름을 연결했습니다.

• 공개 화면: 이벤트 목록, 일정, 참가자 수, 팀 편성, 대진과 결과
• 참가 신청: 승인 계정과 연결된 본인 플레이어만 신청·수정·취소
• 관리자 작업대: 생성 → 모집 → 10명 마감 → 팀 편성 → 대진 → 결과 → 완료
• 팀 편성: V2 팀 밸런스와 최신 MMR/통계 점수를 사용
• 결과 정정: 앞 경기 승자가 바뀌면 영향을 받은 하위 결과를 명시적으로 무효화
• 안전성: 관리자 2단계 인증 재확인, revision 충돌 방지, 중복 요청 방지, 감사·outbox 기록

현재는 개발 검증 단계이며 운영 사이트에는 아직 반영되지 않았습니다.
전체 화면과 모바일 브라우저 검증이 끝난 뒤 다시 안내하겠습니다.
```
