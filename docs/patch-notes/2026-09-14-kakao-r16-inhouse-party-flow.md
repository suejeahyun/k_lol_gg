# 카카오 R16 내전 구인을 파티와 같은 흐름으로 통일

내전 구인도 파티 구인처럼 `양식 생성 → 시작시간·게임정보·주최자 작성 → 활성화 → 상세 명령으로 참가자 관리` 순서로 동작하도록 통일했다.

- `내전구인 협곡|칼바람|증바람`은 참가자 칸이 아닌 활성화 양식을 생성한다.
- 완성 양식을 전송할 때만 내전이 활성화되고, 주최자는 참가자 1번으로 자동 등록된다.
- 활성화 응답에 최신 내전 상세를 함께 표시한다.
- `내전상세 번호 추가 이름`, `내전상세 번호 삭제 이름`, `내전 번호ㅉ`으로 참가자와 마감을 관리한다.
- 기존 참가자 전체 양식도 계속 인식해 이전 사용 방식을 깨지 않는다.
- 주최자를 삭제한 뒤 정보를 다시 전송해도 주최자가 자동으로 재삽입되지 않는다.

휴대폰 설치본 버전은 `KLOL_KAKAO_BOT_V40_R16_2026_09_14`이다. `.private/KLOL_KAKAO_BOT_R16_INHOUSE_PARTY_FLOW_REPLACE_ALL.js` 전체를 기존 코드와 교체해야 한다.

DB migration과 운영 데이터 직접 수정·삭제는 없다.
