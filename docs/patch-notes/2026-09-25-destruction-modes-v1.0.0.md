# 협곡·칼바람·증바람 멸망전

- 대회 생성 시 세 모드를 선택할 수 있습니다.
- 칼바람·증바람은 해당 모드 전적으로 이번 대회 전용 임시 등급을 계산합니다. 등급에 따라 선수 최소 경매금과 주장 보유 포인트가 정해집니다.
- 칼바람 Riot 전적은 최근 최대 100판을 나누어 수집하고 중단 지점부터 이어갈 수 있습니다. 증바람은 운영자가 확인한 전적을 입력합니다. 조회·확인 출처는 공개하며 다른 모드 전적을 합산하지 않습니다.
- 카드 뒤집기, 포인트 공개, 효과음이 세 모드에 공통 적용됩니다. 효과음은 화면의 켜기 버튼으로 활성화합니다.
- 모집부터 경매, 예선·본선, MVP, 최종 종료까지 단계별 안내와 실시간 갱신을 제공합니다. 중복 클릭·응답 유실에도 같은 작업이 중복 반영되지 않습니다.
- 기존 팀 구성과 본선 BO3 규칙을 유지합니다. 임시 등급은 Riot 공식 티어·MMR이 아닙니다.
