# 마감된 모집의 이용 안내 개선 · 1.0.11

- 종료되거나 취소된 멸망전에서 신규 참가·MVP 투표를 위해 로그인하도록 안내하던 문제를 수정합니다.
- 모집 기간 이후에는 기존 참가자를 위한 ‘내 신청 확인’으로 목적을 표시합니다. 자신의 신청 기록과 허용된 승패 수정은 유지합니다.
- MVP 투표는 실제 투표 기간에만 로그인·승인 상태를 안내하고, 그 밖의 기간에는 대기·종료 상태를 표시합니다.
- 마감된 이벤트전·내전에서도 모집 상태를 먼저 보여 주고, 신청할 수 없는 상태의 로그인·계정 연결 유도를 정리합니다. 기존 참가자의 신청 기록 확인은 유지합니다.

신청·취소·투표 권한과 서버 정책은 변경하지 않습니다. 운영 반영과 실제 검증 결과는 [배포 기록](../qa-evidence/service-completion-v1.0.11-2026-10-08/production.md)을 기준으로 확인합니다.
