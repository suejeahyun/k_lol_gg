# 운영·감사 신청 메뉴 · 1.0.0

운영·감사 화면에서 **모임 / 외출 / 건의사항 / 디스코드 초대**를 바로 열 수 있도록 메뉴를 추가했습니다. 전체 신청과 기존 징계 관리도 같은 메뉴에서 이동할 수 있습니다.

기존의 ‘친구 신청’은 ‘디스코드 초대’, ‘탈퇴·휴식’은 ‘외출’, ‘건의’는 ‘건의사항’으로 표시합니다. 목록 제목, 유형 필터, 상세 제목과 모바일 메뉴를 같은 명칭으로 맞췄습니다.

기존 카카오 접수 내역과 처리 기능을 그대로 연결합니다. 기존 주소도 계속 사용할 수 있으며 신청 데이터·상태·권한은 변경하지 않습니다.
