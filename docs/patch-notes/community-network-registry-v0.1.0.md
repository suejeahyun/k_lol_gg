# 커뮤니티 연결 관리 0.1.0

2026-10-29 · 소스 구현 단계, 운영 미배포

사이트와 카카오톡 방을 고정된 네 개의 슬롯 대신 목록으로 등록할 수 있는 관리 기반을 추가했습니다. 최고 관리자가 사이트 소개·공개 여부·방 용도·모집 공유 그룹을 편집할 수 있고, 공개로 지정한 커뮤니티만 탐색 목록에 나옵니다.

동시에 편집할 때 다른 관리자의 변경을 덮어쓰지 않도록 했으며, 저장 결과가 불명확할 때 같은 요청을 다시 보내도 중복 저장하지 않습니다. 저장된 방을 다른 커뮤니티로 옮기거나 이력을 지우는 대신 사용 해제·보관합니다. 저장 전 추가한 항목은 개별 취소할 수 있습니다.

이번 버전은 등록 정보를 관리합니다. 등록만으로 실제 카카오톡 연결이나 사이트 간 회원·모집 공유가 활성화되지는 않습니다. 기존 네 방의 폰 설정은 그대로이며, 동적 연결은 후속 단계입니다. 기능은 기본적으로 비활성 상태입니다.
