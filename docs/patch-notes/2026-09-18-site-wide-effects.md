# 사이트 전체 효과·휠 캐러셀 v1.1.0

## 사용자 화면

- 공개·계정 화면 전반에 일관된 짧은 reveal, surface 깊이, 스크롤 진행선을 적용했습니다.
- 참가 신청, 경기 결과 접수, 징계 현황, 가이드 화면의 상태와 작업 우선순위를 강화했습니다.
- 홈 멸망전 우승 사진과 이미지 상세은 마우스 휠로 한 장씩 가로 이동합니다.
- 캐러셀 양 끝에서는 페이지 세로 스크롤로 빠져나오며, 키보드와 버튼 조작도 유지합니다.

## 관리자 화면

- 검색·표·폼의 focus와 행 구분을 강화했습니다.
- 장식 모션보다 선택·성공·경고·오류 상태를 우선하도록 공개 화면과 효과 강도를 분리했습니다.

## 접근성·성능

- hover는 fine pointer에서만 동작합니다.
- `prefers-reduced-motion`과 forced-colors에서 모션·그림자·색상 의존을 제한했습니다.
- 모바일 header blur를 줄이고 `transition-all`을 필요한 속성 전환으로 교체했습니다.
- 새 영상·폰트·캔버스·애니메이션 라이브러리는 추가하지 않았습니다.
