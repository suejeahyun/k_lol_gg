# NEXUS.GG 1.0.1 — Riot 연동의 독립 DB 인식

Riot 전적 연동, 운영 상태 점검과 자동 레이팅 작업이 모두 NEXUS 전용 DB 설정을 사용하도록 정리했다. 기존 서비스의 DB 주소를 복제하지 않고도 연동 구성을 판단한다. 전용 주소가 없거나 기존 서비스와 같은 DB를 가리키면 연동을 차단한다.

기존 Riot API 키 공유는 사용자가 승인했다. 현재 보관된 로컬 키의 실제 요청은 401이며 Vercel의 sensitive 변수는 원문을 반환하지 않아 유효한 키 입력을 기다린다. 이 코드 수정만으로 외부 연동이 활성화되지는 않는다. 인증·DB·Riot 저장 암호화 키는 서비스별로 독립 유지한다.

검증과 배포 상태는 [QA 근거](../qa-evidence/nexus-riot-2026-10-27/README.md)에 기록한다. 기존 1.0.0 배포 근거와 휴대폰 설치 상태는 덮어쓰지 않는다.
