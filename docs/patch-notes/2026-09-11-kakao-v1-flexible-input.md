# Kakao V1 유연 입력 패치 공지

## 디스코드 복붙용

```text
[K-LOL.GG 카카오봇 입력 개선]

- 기존 V1 구인 양식과 사용 순서는 그대로 유지했습니다.
- 참가자 번호 뒤에 점을 빠뜨려 `2 이름`처럼 작성해도 정상 반영됩니다.
- `2.이름`, `2) 이름`, 카카오에서 표시되는 `2\. 이름`, 전각 숫자·점도 같은 참가자로 처리합니다.
- 양식 제목의 첫 대괄호가 빠져도 전체 양식 구조가 맞으면 반영됩니다.
- 일반 대화나 시간 표기는 참가자로 잘못 저장되지 않습니다.
- 입력 형식 오류, 봇 인증 설정 오류, 실제 서버 연결 오류를 서로 다르게 안내하도록 개선했습니다.

서버 수정은 운영에 반영되었습니다. 새 오류 안내를 사용하려면 휴대폰 코드를 R3 설치본으로 교체한 뒤 `봇버전`을 확인해 주세요.
```

## 확인 순서

```text
봇버전
5인파티
생성된 양식의 한 줄을 `2 이름`으로 작성해 전체 전송
구인현황
상세 번호
번호ㅉ
```
