# 설명은 줄이고 행동과 상태를 바로 보여 드립니다

- 전체 기능을 먼저 분석한 뒤 홈·계정·참가·대회·팀·경기·기록·관리 순서로 점검했습니다.
- 반복 소개, 장식 문구, 버튼을 다시 설명하는 문장과 내부 구현 설명을 정리했습니다. 입력 이름, 오류·완료 상태, 정책과 실제 게시 내용은 유지합니다.
- 참가·파티·대회 제목과 명령 복사 버튼을 실제 행동에 맞춰 정리하고, 연결이 필요한 경우에는 문의로 바로 이동할 수 있습니다.
- 멸망전 방식 필터에서 단판과 3판 2선승을 구별할 수 있습니다. 로그인 중복 링크와 관리자 내부 분류 코드도 제거했습니다.
- 신청·관리자 오류 화면의 다시 시도가 서버 데이터를 새로 조회하도록 수정했습니다. 신청 오류 화면의 중복 본문 영역도 정리했습니다.
- 앱 설치 실패와 중복 요청을 처리하고, 설치 요청 수락과 실제 설치 완료를 구분합니다.
- 홈 여섯 영역의 순서, 단일 랭킹 슬라이드, 생성 이미지·배경, 참가·저장·권한·집계 규칙은 유지합니다.
