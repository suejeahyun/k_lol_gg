- 기능 버전: `team-balance-admin@1.0.0`
- 상태: `NOT_DEPLOYED` - 로컬 변경, 운영 미배포
- [QA 근거](../qa-evidence/team-balance-admin-2026-10-08/README.md)

## 소스 변경 사항

일반 관리자도 관리자 로그인 후 내전 팀 편성 점수를 저장할 수 있도록 변경했다. 최고 관리자도 계속 사용할 수 있으며, 일반 회원과 일반 사이트 로그인 세션은 저장할 수 없다. MMR 조정 원장 추가와 재계산 권한은 최고 관리자에게 유지한다.

관리자의 `내전 점수 · MMR 관리` 화면 상단에 점수 편집을 배치했다. 플레이어 검색 후 현재 점수가 자동으로 표시되고, 저장 전후 점수를 비교할 수 있다. 0점 초기화와 변경 사유 입력을 제공하며, 다른 관리자의 변경과 충돌하면 최신 점수를 확인한 뒤 다시 저장할 수 있다. 저장 결과가 불확실하면 같은 요청으로 결과를 재확인한다.

보정은 새 팀 계산 또는 초안 재평가부터 적용한다. 기존 경기와 MMR은 유지하며, 저장 시 변경 기록과 동시 수정 방지 검사를 수행한다.

## 검증 상태

보정 도메인·HTTP 4개, 격리 PostgreSQL DB 계약 3개, 전체 계약 테스트 672개가 통과했다. 변경 범위 lint, 타입 검사, diff 검사와 프로덕션 빌드를 통과했다. 실제 Chromium에서 일반 관리자 저장·초기화·충돌·연결 복구와 PC·390px·320px 화면을 확인했다.

이 변경을 위한 Git commit/tag와 운영 배포는 생성하지 않았다.
