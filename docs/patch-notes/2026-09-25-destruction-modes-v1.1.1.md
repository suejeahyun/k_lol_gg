# 멸망전 1.1.1 · 참가 심사 연속 처리

참가 확정을 누른 뒤 모든 선수의 심사 버튼이 잠기던 불편을 개선했습니다.

- 처리 중인 선수와 대기 중인 선수의 행에 진행 상태를 표시합니다. 다른 선수는 계속 참가 확정·예비 선수·신청 거절을 선택할 수 있습니다.
- 선택한 순서대로 저장하며 같은 선수의 중복 클릭을 막습니다. 모집 인원과 포지션 제한은 기존 규칙을 따릅니다.
- 연결 문제나 다른 운영자와의 충돌이 발생하면 아직 전송하지 않은 심사를 취소하고 안내합니다. 응답을 받지 못한 요청은 ‘요청 결과 다시 확인’으로 중복 처리 없이 확인할 수 있습니다.

협곡·칼바람·증바람 멸망전에 공통 적용됩니다.
