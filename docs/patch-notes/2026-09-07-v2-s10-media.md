# V2 S10 하이라이트·갤러리 — 개발 검증 공지 초안

> 상태: 소스·정적·단위·격리 PostgreSQL 18 집중 검증 단계. 운영 스토리지와 Vercel에는 반영하지 않았습니다.

## 디스코드 복붙용

```text
[K-LOL.GG V2 개발 소식 — 하이라이트·갤러리]

영상 하이라이트와 커뮤니티 갤러리를 밝고 가벼운 V2 화면으로 새로 만들었습니다.

• 하이라이트: 지원하는 YouTube 주소만 안전하게 정리해 목록과 상세에서 보여줍니다.
• 갤러리: 게시된 이미지 묶음을 목록과 상세에서 편하게 확인할 수 있습니다.
• 관리자 작업대: 작성, 수정, 게시, 보관, 복구와 홈 노출을 한 흐름으로 관리합니다.
• 안전한 이미지 처리: 업로드 완료와 용도를 확인한 비공개 자산만 게시할 수 있습니다.
• 개인정보 보호: 원본 저장 경로, 파일명, 해시와 내부 작성자 정보는 공개하지 않습니다.
• 삭제 안전성: 즉시 삭제 대신 보관·복구 흐름을 사용합니다.

현재는 개발 검증 단계이며 운영 사이트에는 아직 반영되지 않았습니다.
실제 업로드·스토리지와 전체 모바일/접근성 검증이 끝난 뒤 다시 안내하겠습니다.
```
