# 이미지 테마 업데이트 1.0.0

하늘색·라벤더 판타지 테마로 메뉴와 화면 배경을 새로 꾸몄습니다.

- 메뉴, 버튼, 상태 안내의 선형 아이콘과 별 문자를 보석·금속 질감의 이미지 아이콘으로 바꿨습니다.
- 모든 페이지의 공통 배경에 판타지 정원을 적용하고, 랭킹 슬라이드는 달빛 경기장으로 꾸몄습니다.
- 카드와 입력 화면에는 은은한 유리 질감 배경을 적용했습니다. 글자 뒤의 밝기를 조절해 내용을 읽기 편하게 했습니다.
- 모바일 배경을 별도 크기로 제공하고, 작은 아이콘을 공통 이미지 파일로 묶어 다운로드 용량을 줄였습니다.
- 좁은 화면의 팀 편성 너비와 계정 진입 화면의 제목 크기를 보완했습니다.

홈의 섹션 순서와 랭킹 슬라이드 조작은 그대로 이용할 수 있습니다. 플레이어·경기 기록과 신청 방식은 기존과 같습니다.
