# 내전 팀 배치 2.1.0 — 드래그 교환과 이름 복사

수동 팀 배치에서 선수 카드를 드래그해 자리를 교환할 수 있습니다. 모바일에서는 닉네임과 이름이 있는 카드 머리 부분을 끌어 옮깁니다. 키보드에서는 카드에 초점을 맞춘 뒤 Space 또는 Enter로 집고 놓으며, Esc로 취소합니다. 별도의 ‘교체할 카드 선택’ 버튼은 제거했습니다.

교환하면 새 포지션의 선수 적용 점수와 팀 합계, 밸런스 점수, 규칙 판정을 즉시 미리 보여줍니다. 서버 평가가 끝난 뒤 저장하거나 복사할 수 있으며, 수동 변경 결과는 자동 최선 추천과 구분합니다. 카드에는 포지션 적합도와 해당 역할의 내전 표본 수를 표시합니다.

닉네임 옆에 등록 이름을 표시하고, 팀 결과 복사는 아래 두 줄만 사용합니다. 이름이 없는 경우에는 `이름미등록`으로 표시합니다.

```text
BLUE 이름 이름 이름 이름 이름
RED 이름 이름 이름 이름 이름
```

티어 누락·포지션 변경·남은 격차에 대한 안내는 결과 화면에서 확인할 수 있습니다. 점수를 실제 승률로 표시하지 않습니다. 등록 이름은 기존 소유자·관리자 권한으로 접근한 초안에만 추가하며, 과거 점수와 원본 포지션은 보존합니다.

조합 규칙 변경 후보는 실제 선수의 새 500조합으로 비교했습니다. 사전 정의한 유의미한 개선은 24조합에서 있었지만 역할 표본과 신규·저표본 집단의 신뢰도 조건을 통과하지 못해 채택하지 않았습니다. 기존 `V2_INHOUSE_RELAXED_2026_10_16` 계산식과 개인 점수를 유지하며, 이번 변경은 위 화면·조작 개선입니다.
