# 고객 문의·운영 시작 안내 1.0.0

GG HUB에서 운영자가 문의를 처리하고 사이트 개설 후 다음 할 일을 찾는 흐름을 보완했습니다.

- 중앙 관리자 메뉴에 **고객 문의**, 모든 HUB 화면 하단에 **도움·문의·이용약관·개인정보 처리 안내**를 연결했습니다.
- 문의 상태 필터와 이전/다음 페이지가 HUB에서 허용하는 주소를 유지하도록 수정했습니다. 고객 문의 화면에서 관련 없는 신청 유형·운영 감사 주소로 이동하지 않습니다.
- HUB 관리자 화면의 누락된 색상 변수를 연결해 필터 버튼·입력·상태·표의 대비와 구획을 복구했습니다.
- 문의 접수는 연속 클릭을 막고 20초 안에 응답이 없으면 원래 내용과 요청 번호로 결과를 재확인합니다. 결과를 모르는 동안 입력을 잠가 다른 문의가 중복 제출되지 않도록 합니다.
- 문의 작성 중 이동 시 미저장 내용 확인을 제공하고, 성공하면 접수번호로 초점을 옮깁니다.
- 개설 상태별 다음 할 일을 안내합니다. 보완 요청·심사 대기·개설 중·공개 확인·실패를 구분하고 운영팀 문의에 사용할 신청번호를 보여줍니다.
- 공개 가능한 사이트에서는 관리자·소개 설정으로, 실제 게시된 설정에서 모집을 켠 운영 사이트에서는 모집 화면으로 이동할 수 있습니다.
- 개발용 HUB에서 Next의 대괄호 포함 스크립트 경로가 차단되어 로딩이 멈추는 문제를 수정했습니다. 운영 경로 제한과 인코딩된 경로 구분자·탐색 차단은 유지합니다.

관리 메모·처리 상태 저장은 고객에게 답변을 발송하지 않습니다. 현재 답변은 접수된 연락 방법으로 운영자가 직접 진행합니다.

유료 서비스의 고객 가치·결제·해지·지원·복구·출시 조건은 [사업화 기준](../product/gg-hub-commercial-readiness-v1.md)에 정리했습니다. 이 버전은 고객지원·운영 안내의 첫 구현이며 실제 과금, 구독·환불, 계정 통합, 동적 폰 설정, 제휴·공동 대회를 완성한 버전이 아닙니다.
