# 멸망전 모집과 단계 이동 개선

- 칼바람·증바람 멸망전은 포지션을 나누지 않고 총인원으로 모집합니다. 참가 신청에서 포지션을 선택할 필요가 없습니다.
- 칼바람·증바람 경매는 포지션 제한 없이 팀당 5명을 편성합니다. 남은 선수를 구매할 최소 포인트는 보존합니다.
- 협곡 멸망전은 기존 포지션별 모집과 팀 편성을 유지합니다.
- 상단의 대회 준비·참가 모집·주장/포인트·선수 경매·예선·본선·종료를 누르면 각 단계의 기록을 볼 수 있습니다. 단계 조회로 대회 진행 상태가 바뀌지는 않습니다.
- 카드 뒤집기, 선수·포인트 공개, 효과음은 계속 사용할 수 있습니다.
