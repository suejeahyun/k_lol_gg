## 변경 내용

### 오전 6시 운영일

구인 생성·수정·삭제·마감과 현황 조회가 KST 오전 6시를 같은 운영일 경계로 사용한다. 서명된 요청 시각을 기준으로 하므로 요청 처리 도중 오전 6시가 지나도 수정 결과와 후속 현황이 서로 다른 날짜를 보지 않는다.

오전 6시 전환은 이전 운영일 데이터를 삭제하지 않는다. 새 운영일 조회에서 이전 운영일 모집을 제외하는 논리 리셋이다.

### mutation 후 최신 전체 현황

참가자가 입력된 양식의 신규 저장, 기존 모집 수정, 빈 슬롯 삭제, 모집 마감이 성공하면 mutation 결과 아래에 최신 전체 구인 현황을 표시한다. 후속 현황 조회만 실패할 경우 이미 성공한 mutation은 유지하고 `구인현황` 재입력을 안내한다.

빈 `2인파티`·`5인파티` 명령은 기존처럼 양식만 생성한다. 참가자를 적은 전체 양식을 보낸 뒤에 저장한다.

### 유연한 구인 입력

- 번호 뒤 `.`, `)`, 공백, 이스케이프된 `\.`과 들여쓰기를 허용한다.
- 이름 뒤 포지션·괄호·쉼표·태그·메모를 같은 참가자 정보로 보존한다.
- 명시적으로 비운 번호 행은 해당 슬롯 삭제로 처리한다.
- 참가자가 없는 자동번호 양식은 새 모집을 만들지 않는다.
- 같은 방의 다른 일반 사용자가 만든 모집도 기존 권한 계약대로 수정·마감할 수 있다.

### 내전 참가 신청 400 복구

- `이름/현티어/최고티어/주라인/부라인` 구조를 유지한다.
- tier와 포지션의 대소문자, `ALL`, `Mid all`, `TOP, MID`, 빈 부라인을 처리한다.
- 이름만 입력하거나 포지션을 해석할 수 없는 행은 안전한 기본값으로 확인 필요 대기열에 보낸다.
- 같은 번호가 중복되면 마지막 행을 적용하고, 마지막 빈 행은 취소로 처리한다.
- 번호 행이 통째로 빠지면 기존 슬롯을 보존한다.
- 다른 별칭으로 같은 플레이어를 중복 입력하면 첫 슬롯을 반영하고 이후 슬롯만 확인 필요로 분리한다.
- 정상 행과 확인 필요 행을 분리해 한 행의 문제 때문에 전체 요청이 HTTP 400으로 실패하지 않게 했다.
- 빈 행 취소는 같은 방·날짜·회차·모드의 카카오 신청에만 적용하며 사이트 신청, 확정 신청, 다른 방 신청을 보존한다.
