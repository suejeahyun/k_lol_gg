# 사이트·카카오 봇 안정성 보완 1.0.0

사이트와 카카오 봇 재점검에서 확인한 9건을 보완합니다. 배포·검증 상태는 [QA 기록](../qa-evidence/site-kakao-reliability-2026-10-14/README.md)에서 확인할 수 있습니다.

- 모집 카드에서 복사하는 조회 명령이 고정 모집코드를 사용합니다. 아직 코드가 없는 옛 모집은 확인 방법을 안내합니다.
- 오전 6시나 시즌 변경을 넘겨 열린 참가 화면은 다른 모집에 잘못 신청·취소하지 않습니다. 입력을 보존하고 최신 모집 확인을 요청합니다.
- 휴대폰 시계 차이 때문에 양식이 일찍 만료되지 않도록 서버 시각을 기준으로 처리합니다.
- 관리자 전체 중지·유지보수·기능별 중지가 V4 봇 요청에도 적용됩니다.
- 답장 실패나 연결 오류 후 다시 시도했을 때 정상 결과가 숨겨지지 않도록 수정합니다.
- `상세 번호 예비추가 이름`, `상세 모집코드 예비추가 이름`은 빈 본 참가 자리가 있어도 예비로 등록합니다.
- 경기 접수 수정 충돌 시 최신값과 작성 중인 내용을 확인하고 다시 저장할 수 있습니다.
- 관리자 설정 저장 중에는 입력을 잠가 작성 내용이 사라지는 문제를 막습니다.
- `내전 7쫑`, `내전 7마감`, `내전 7종료`, `내전 #7ㅉ` 등 마감 명령을 휴대폰에서도 전달합니다.

휴대폰 답장·명령 전달 수정에는 **R29 파일 교체**가 필요합니다. 서버 배포만으로 휴대폰 JavaScript가 자동으로 바뀌지는 않습니다. [설치 안내](../../integrations/messengerbot-r/MESSENGERBOT_R_INSTALL.md)를 따르세요.
