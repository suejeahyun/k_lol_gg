# GG HUB 사이트 개설 스튜디오 0.1.0

[GG HUB](https://gg-community-hub.vercel.app)에 신청·테마·기능 설정을 반영했습니다. 승인 후 자동 개설은 전용 Vercel 연결을 기다리고 있습니다. [검증·남은 조건](../qa-evidence/community-site-studio-2026-10-29/README.md).

- 중앙 계정으로 가입한 뒤 새 커뮤니티 개설을 신청할 수 있습니다.
- Arena·Lounge·Club 테마와 색상·이미지·홈 배치를 선택합니다.
- 사이트별 기능을 켜고 끌 수 있습니다. 중지 전에 영향 범위를 확인하고, 기존 기록을 보존한 상태로 다시 사용할 수 있습니다.
- 초안을 저장한 뒤 게시하므로 편집 중인 내용이 즉시 운영 화면에 반영되지 않습니다.
- 운영진 검토와 독립 사이트 개설을 거친 뒤 소유자가 점검하고 공개를 시작합니다.
- 신규 사이트는 자기 DB·인증 키를 사용하며 기존 커뮤니티의 회원·경기 자료를 복사하지 않습니다.

Riot 연결, 제휴·정보 공유·공동 대회와 휴대폰 동적 설정은 후속 단계입니다. 현재 K-LOL/NEXUS 사이트와 휴대폰 봇의 운영 내용은 유지합니다.
