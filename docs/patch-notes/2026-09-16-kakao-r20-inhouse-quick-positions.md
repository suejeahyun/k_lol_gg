# 카카오 R20 내전 빠른 라인 입력

협곡 내전의 빠른 추가에서 아래 두 형식을 모두 사용할 수 있다.

- `내전상세 1 추가 민혁/mid/ad`
- `내전상세 1 추가 민혁/mid,ad`

이름 뒤 첫 라인은 주라인, 이후 입력은 모두 부라인이다. `민혁/mid,all`은 주라인 MID를 제외한 TOP·JGL·ADC·SUP을 부라인으로 저장한다. 이미 명단에 있는 카카오 미검토 참가자에게 구조형 추가를 다시 보내면 기존 슬롯은 유지하고 라인만 수정한다.

이름만 추가하는 방식, `이름/현티어/최고티어/주라인/부라인` 전체 형식, 파티, 스크림, 칼바람·증바람 이름 전용 동작은 그대로 유지한다. SITE 신청과 확정·검토 완료 신청은 빠른 명령으로 덮어쓰지 않는다.

휴대폰 설치본 버전은 `KLOL_KAKAO_BOT_V40_R20_2026_09_16`이다. `.private/KLOL_KAKAO_BOT_R20_INHOUSE_QUICK_POSITIONS_REPLACE_ALL.js` 전체로 기존 코드를 교체해야 한다.

DB migration과 운영 데이터 직접 수정·삭제는 없다.
