# 커뮤니티 상세 소개 운영 안내

GG HUB에 표시할 상세 소개는 **각 사이트 운영진이 해당 사이트에서 작성**한다. 저장 위치도 해당 사이트의 독립 DB다. HUB의 등록 이름·주소·기본 소개와 별개이며, 회원·경기·제재 기록을 함께 공유하지 않는다.

이 문서는 구현된 기능의 사용 절차다. 운영 반영 여부는 [현재 상태](../STATUS.md)와 해당 릴리스의 배포 근거로 확인한다. 아래 주소가 있다는 사실만으로 배포 완료를 뜻하지 않는다.

## 관리 화면과 권한

| 사이트 | 소개 관리 주소 |
|---|---|
| NEXUS.GG | https://nexus-gg-kr.vercel.app/admin/community-introduction |
| K-LOL.GG | https://k-lol-gg.vercel.app/admin/community-introduction |
| 신규 관리형 사이트 | 해당 사이트 주소 뒤에 `/admin/community-introduction` |

해당 사이트의 **ADMIN 또는 SUPER_ADMIN 관리자 세션**으로 접속한다. 관리자 메뉴의 **커뮤니티 소개**, 또는 기존 **사이트 설정**의 소개 관리 링크로도 이동할 수 있다. 일반 회원 로그인과 관리자 로그인은 구분된다. HUB 관리자 권한만으로 기존 K-LOL/NEXUS의 소개를 수정할 수는 없다.

이 기능이 포함된 엔진으로 새 사이트를 개설하면 신청 소유자는 그 사이트의 SUPER_ADMIN으로 연결된다. 소유자가 해당 사이트에 로그인하여 소개를 작성하며, 이후 권한을 부여받은 해당 사이트 ADMIN도 편집할 수 있다. 새 소개는 **빈 내용·비공개**로 시작한다. 다른 사이트의 소개나 회원 자료를 복사하지 않는다.

## 입력 항목

| 항목 | 제한 | 사용 방법 |
|---|---|---|
| 한 줄 소개 | 160자, 한 줄 | 커뮤니티의 성격을 간단히 설명한다. 공개 시 필수다. |
| 상세 소개 | 3,000자 | 활동 방향과 분위기를 설명한다. 공개 시 필수다. |
| 주요 활동 | 600자 | 내전·구인구직·자유 대화 등 실제 활동을 적는다. |
| 주 활동 시간 | 160자, 한 줄 | 평일 저녁, 주말 등 참여 가능한 시간을 안내한다. |
| 가입 안내 | 1,000자 | 가입 대상과 절차를 안내한다. |
| 문의·참여 링크 | 500자 | 공개 HTTPS 주소를 입력한다. 비우면 표시하지 않는다. |
| 배너 이미지 주소 | 500자 | 공개 HTTPS 이미지 주소를 입력한다. 파일 업로드 기능은 아니다. |

로그인 정보가 포함된 주소, 사설 주소, 별도 포트가 있는 주소는 허용하지 않는다. 소개는 일반 텍스트로 출력하며 HTML을 실행하지 않는다. 상세 소개·주요 활동·가입 안내의 줄바꿈은 유지한다. 문의 링크는 새 창으로 열리고, 배너는 방문자 브라우저에서 해당 이미지 주소를 읽는다.

## 저장과 공개

1. 내용을 입력하고 옆의 미리보기로 확인한다. 미리보기는 현재 편집 내용이며, 저장 전에는 방문자에게 반영되지 않는다.
2. **공개 여부**를 선택한 뒤 저장한다. 공개하려면 한 줄 소개와 상세 소개를 모두 입력해야 한다.
3. [GG HUB 사이트 목록](https://gg-community-hub.vercel.app/community-network)에서 해당 카드의 **소개 보기**를 열어 확인한다. 소개를 공개해도 미등록 사이트가 HUB에 자동 등록되지는 않는다.
4. 소개를 내리려면 공개를 끄고 저장한다. 저장된 문구는 유지되어 다시 공개할 수 있다. HUB의 기본 등록 카드와 사이트 방문 링크는 유지된다.

공개 내용은 `/api/community-introduction`에서 제공되므로 로그인하지 않은 방문자도 읽을 수 있다. 작성자 계정·권한·내부 수정 번호는 응답에 포함하지 않는다. 비공개 상태에서는 공개 소개 API가 404를 반환한다.

다른 운영진이 먼저 수정했다는 안내가 나오면 현재 편집 내용은 화면에 남는다. 필요한 문구를 확보한 뒤 **편집 취소하고 최신 소개 불러오기**로 최신 내용을 읽고 다시 편집한다. 통신 실패 시에도 편집 내용은 유지된다. 저장 성공 안내를 확인하기 전에는 반영된 것으로 판단하지 않는다.

## HUB에서 보이는 상태

HUB는 공개 등록된 기존 사이트와 활성화된 관리형 사이트를 목록에 표시한다. 상세 소개는 **소개 보기**를 열 때 해당 사이트에서 읽는다. 카드마다 모든 소개를 미리 수집하지 않는다.

| 상태 | 방문자에게 표시하는 내용 |
|---|---|
| 공개 소개를 정상 조회함 | 해당 사이트 운영진이 작성한 소개·배너·링크·수정일 |
| 소개가 비공개이거나 아직 없음 | 공개된 상세 소개가 없다는 안내 + HUB에 등록된 기본 소개 |
| 사이트가 소개 API를 지원하지 않음 | 상세 소개 준비 중 안내 + 등록된 기본 소개 |
| 통신 장애 등으로 조회할 수 없음 | 일시적으로 불러오지 못했다는 안내 + 등록된 기본 소개 |

상세 소개를 가져오지 못해도 등록된 사이트 방문 링크는 사용할 수 있다. HUB의 등록 목록 자체를 확인할 수 없는 경우에는 목록 조회 장애를 안내하며, 사이트가 삭제되었다고 단정하지 않는다.

기존 사이트의 **사이트 기본 소개 문구**, HUB에 등록된 **기본 소개**, 이 화면의 **상세 소개**는 자동으로 덮어쓰지 않는다. 관리형 사이트의 테마·모듈 설정은 계속 HUB에서 관리하고, 상세 소개는 각 사이트 운영진이 관리한다. 이 기능은 연합·공동 대회·회원 정보·운영 기록 공유의 동의를 대신하지 않는다.
