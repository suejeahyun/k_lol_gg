# 내전 팀 밸런스 운영 기준

적용 계산식: `V2_INHOUSE_RELAXED_2026_10_16` · 정리일: 2026-10-18

2026-10-18 실제 자료 비교에서도 계산식과 아래 우선순위를 유지한다. 부 포지션 부담·격차 우선 후보에 이어, 사용자가 조합 규칙 개편을 허용한 뒤 기존 추천의 지표를 보호하는 `ANCHORED_PARETO`도 별도로 평가했다. 새 500조합 중 24개에서 사전 정의한 유의미한 개선이 있었지만 역할 표본 부족·신뢰도 집단 기준을 통과하지 못해 기각했다. 개인 점수와 과거 초안은 바꾸지 않는다. [최신 실험 근거](qa-evidence/balance-policy-2026-10-18/README.md), [이전 격차 우선 실험](qa-evidence/balance-severity-2026-10-18/README.md), [기존 표본 0건 진단 정정](qa-evidence/balance-research-2026-10-18/README.md).

**조건이 충돌해도 팀 생성을 중단하지 않는다.** 먼저 모든 포지션·바텀 제한을 충족하는 조합을 찾고, 없으면 같은 10명 안에서 필요한 조건만 자동 조정하여 추천한다. [정책 결정](architecture/0015-inhouse-automatic-constraint-relaxation.md).

팀 합계가 비슷하다는 이유만으로 공평하다고 판단하지 않는다. 실제 맡는 포지션의 전력, 대면 격차, 포지션 양보 부담, 양 팀이 활용할 수 있는 라인을 함께 비교한다. 아래 점수 기준은 현재 계산식에 맞춘 운영 기준이며, 특정 점수 차이를 실제 승률로 검증한 값은 아니다.

## 참가자 입력

- 대표 포지션은 기본적으로 주 포지션, 세부 설정에서 추가한 역할은 기본적으로 부 포지션이다. 기존 선호 설정에서 개별 역할을 주·부·자동 배치 가능으로 조정할 수 있다.
- 선택한 포지션 안에서 배정하는 것이 기본이다. 한 포지션만 선택하면 해당 역할 배정을 우선한다. 다만 전체 편성이 불가능하면 자동 조정 과정에서 다른 역할을 맡을 수 있으며 결과에 해당 선수를 표시한다.
- 주·부 이외의 역할도 가능한 참가자만 **선택하지 않은 기타 포지션도 허용**을 켠다. 켜면 선택하지 않은 역할을 자동 배치 가능(AUTO)으로 추가하고 기존 역할 보정을 적용한다. 주·부 선호는 유지한다.
- **전체**는 다섯 포지션 모두를 자동 배치 가능으로 명시적으로 허용한다. 주 포지션 다섯 개와 같은 의미가 아니다.
- 허용 포지션이 없는 입력은 거절한다. 신청자를 불러오면 신청한 주·부 포지션을 허용하고, 부 포지션이 전체인 신청은 나머지 네 역할을 부 포지션으로 반영한다.
- 배정할 자리가 부족해도 생성을 막지 않는다. 예를 들어 미드만 선택한 사람이 3명이면 두 명은 미드에 배치하고, 최소 한 명은 다른 역할로 조정하는 후보를 비교한다. 원래 선택값은 그대로 보관한다.

## 신규 참가자와 개인 점수

첫 참가자도 평가 시점에 등록된 현재·최고 티어로 개인 점수를 계산한다. 내전 전적이 없다는 이유로 모든 사람을 50점으로 처리하지 않는다. 개인 기준 점수는 **최고 티어 환산값 60% + 현재 티어 환산값 30% + 내전 성적값 10%**이며, 내전 성적이 없을 때는 그 10% 항목에만 50을 사용한다. 최고 티어만 없으면 계산에 현재 티어를 대신 쓰되, 최고 티어가 실제 등록된 것처럼 표시하지 않는다.

다음은 내전 전적·최근 솔랭 보조값·관리자 보정이 없고 주 포지션을 맡으며 현재·최고 티어가 같은 경우의 예시다. 최고 티어가 비어 있고 현재 티어만 있는 경우도 같은 예시 점수다.

| 등록 티어 | 개인 기준·주 포지션 점수 |
|---|---:|
| 골드 IV | 41.0 |
| 플래티넘 IV | 50.0 |
| 에메랄드 IV | 59.0 |
| 다이아몬드 IV | 68.0 |
| 마스터 100 LP | 81.5 |

최종 배정 점수에는 맡은 역할과 숙련도, 최근 솔로랭크 보조값, 신뢰도가 반영된 내전 점수 보정, 관리자 보정이 추가로 반영될 수 있다. 선수 카드의 **적용 점수**는 이 최종 배정 결과다. 두 사람을 교환하는 중에는 새 역할의 **미리보기 점수**를 표시하며 서버 평가 후 확정한다. 티어와 내전 표본 수는 점수와 별도로 표시한다.

현재·최고 티어가 모두 없으면 기존 계산의 임시 기준 점수는 32점이다. 이는 확인된 실력이 아니므로 **티어 확인 필요**로 안내한다. Riot 연동 화면의 랭크와 내전에 등록된 티어는 별도 자료다. 등록 티어가 누락된 경우 실제 값을 확인해 입력해야 하며, 미확인 티어를 임의로 만들어 넣거나 바텀 제한을 통과한 것으로 처리하지 않는다.

저장한 초안은 평가 당시 점수와 등록 정보를 보존한다. 나중에 프로필 티어를 고쳤다면 **최신 통계로 재평가**를 해야 새 값을 반영한다. 이번 표시 수정은 페이지를 새로 열면 적용되며, 기존 초안의 점수 자체를 바꾸지 않는다. 이전에는 카드가 최종 배정 점수 대신 별도 전적 점수를 보고 신규 참가자에게 “기본 점수 50”을 표시하는 오류가 있었다.

## 기본 편성 조건

| 조건 | 적용 방법 |
|---|---|
| 인원과 역할 | 서로 다른 10명, 양 팀 각 5명, 각 팀 탑·정글·미드·원딜·서폿 1명씩 |
| 등록 포지션 | 먼저 참가자별 등록 목록 안에서 배정하며, 불가능할 때만 미등록 역할 배정을 최소화 |
| 바텀 큰 티어 차이 | 먼저 원딜끼리와 서폿끼리 **각각** 현재 티어의 큰 등급 차이가 3단계 미만인 조합을 탐색. 불가능한 경우 위반 수와 초과 정도를 최소화하여 표시 |

큰 등급은 아이언 → 브론즈 → 실버 → 골드 → 플래티넘 → 에메랄드 → 다이아몬드 → 마스터 → 그랜드마스터 → 챌린저 순서로 센다. 골드↔다이아몬드는 3단계이므로 기본 탐색에서 제외하고, 골드↔에메랄드는 2단계이므로 이 조건만으로 제외하지 않는다. 골드4↔골드1은 같은 큰 등급이다. 원딜 격차를 서폿 우세로 평균내어 충족한 것으로 처리하지 않는다.

현재 티어를 확인할 수 없는 참가자는 최고 티어나 임시 점수로 통과시키지 않는다. 해당 편성에 **정보 확인 필요**를 표시하고, 특히 바텀 티어가 없으면 3단계 제한을 검증할 수 없다고 안내한다.

## 전력과 대면 격차

배정 역할에 따른 기존 개인 점수를 사용한다. 새 규칙을 만족했다는 이유로 개인 전력에 점수를 더하지 않는다.

| 검사 항목 | 현재 기준 |
|---|---|
| 동급으로 보는 대면 | 점수 차이 3점 이하 |
| 전체 전력 | 양 팀 평균 점수 차이 3점 이하 권장: 팀 합계 차이 15점 이하 |
| 최악의 대면 | 한 포지션의 점수 차이 25점 이하 권장 |
| 큰 대면 격차 | 15점 이상 차이 나는 포지션은 최대 1곳 권장 |
| 바텀 합산 | 두 팀의 원딜·서폿 평균 점수 차이 5점 이하 권장: 합계 차이 10점 이하 |

예를 들어 A팀 탑이 크게 강하고 B팀 미드가 크게 강하면 합계는 같을 수 있다. 그러나 큰 격차가 두 곳이므로 균형 편성으로 간주하지 않는다. 큰 격차의 방향이 서로 달라도 각각 센다.

이 기준을 넘는 편성은 필수 조건을 통과했더라도 **조건부 편성**으로 남긴다. 기준을 충분히 만족하는 후보가 있으면 우선 선택한다. 조건부 후보만 가능한 경우에는 남은 이유를 표시한다.

## 원문의 여섯 가지 조합 규칙

**번호가 작을수록 우선순위가 높다: 1 → 2 → 3 → 4 → 5 → 6.** 비교 가능한 후보에서 상위 규칙의 위반 수가 같을 때만 다음 규칙을 비교한다. 하위 규칙을 여러 개 만족한다고 상위 규칙의 위반을 상쇄하지 않는다. 예를 들어 2번 바텀 분산을 지킨 후보와 5·6번만 지킨 후보가 같은 필수 조건·전력 기준·포지션 부담이라면 전자를 선택한다.

| 우선순위 | 규칙 | 실제 적용 기준 |
|---:|---|---|
| 1 | 고티어 두 명을 미드·정글에 분산 | 기본 전력 상위 두 명을 양 팀에 나누는 조합을 우선한다. 등록한 주·부 포지션으로 가능할 때 서로 다른 팀에서 미드와 정글을 맡는 조합을 선호한다. 동점자는 동등하게 취급한다. |
| 2 | 바텀은 양쪽에 강점이 남도록 | 원딜·서폿이 동시에 한 팀에서 뚜렷하게 우세하면 경고한다. 우세 방향이 반대여도 바텀 합산 격차를 별도로 검사한다. 동급 매치업도 허용한다. |
| 3 | 강한 정글에게 활용 가능한 라인 | 정글 우세 팀의 탑·미드·원딜 중 최소 한 곳은 동급 이상이어야 한다. 상대 팀에도 동급 이상 라인이 남아 있는지 함께 검사한다. |
| 4 | 바텀 3티어 이상 차이 방지 | 현재 티어의 큰 등급 3단계 이상 차이를 원딜 대면과 서폿 대면에서 독립적으로 검사한다. 기본 탐색에서 제외하고, 자동 조정에서도 위반 수와 초과 정도를 가장 먼저 줄인다. |
| 5 | 약한 서폿에게 정글 보상 | 서폿이 뚜렷하게 열세인 팀은 정글이 동급 이상인 후보를 선호한다. 서폿과 정글이 모두 열세이면 경고한다. |
| 6 | 탑과 미드의 우세를 분산 | 탑과 미드가 동시에 같은 팀에서 뚜렷하게 우세하면 경고한다. 한 곳이 동급이면 통과하며 동급을 일부러 열세로 바꾸지 않는다. |

미드·정글 분담은 실제 숙련 역할을 우선한다. 자동 조정으로 다른 역할을 맡았다는 이유만으로 그 역할을 등록된 주·부 포지션으로 간주하지 않는다.

**중복 보상 방지:** 약한 서폿에 대한 보상으로 강한 정글을 배치한 뒤 다시 강한 라이너를 계속 추가하지 않는다. 최종 배치의 팀 합계·대면 격차·바텀 격차·양 팀의 활용 라인을 한 번 더 비교한다. 승리 경로는 챔피언 선택 전 점수 기준으로 활용 가능한 라인이 있다는 뜻이며, 확정 캐리를 보장하지 않는다.

## 편성 순서와 포지션 양보

1. 입력과 허용 포지션을 검사하고 가능한 팀 구성과 양 팀 역할 배치를 함께 비교한다.
2. 허용 포지션과 바텀 3등급 제한 등 필수 조건을 어기는 후보를 제외한다.
3. 전체 전력·최대 대면·큰 격차 수·바텀 격차를 검사한다.
4. 기타 포지션 배치 인원을 줄이고, 남은 부담이 한 팀에 몰리지 않게 한다.
5. 위 기준이 같은 후보끼리 원문 1→6 순서로 위반 수를 비교한다. 4번은 이미 필수 검사에서 통과한 후보만 남아 있다.
6. 여섯 규칙도 같으면 팀·라인·바텀 격차와 부 포지션 배정 수를 비교하고, 완전히 같으면 고정된 선수 순서로 결정한다.

위 과정에서 후보가 하나라도 있으면 이전과 같은 추천을 사용한다. 후보가 없을 때만 모든 역할 배치를 다시 탐색하며 아래 순서로 자동 조정한다.

1. 바텀 큰 티어 제한의 위반 수와 초과 정도를 최소화한다.
2. 등록하지 않은 역할에 배치되는 선수 수를 최소화한다.
3. 기존 전력 기준, 기타 포지션 부담과 조합 규칙 1→6을 비교한다.
4. 남은 동률은 팀·라인·바텀 격차와 부 포지션 수, 고정된 선수 순서로 결정한다.

미등록 역할은 기존 AUTO 감점을 적용하고 원래 선택값·MMR·관리자 보정은 유지한다. 조정된 선수와 역할, 불가피한 바텀 티어 차이는 결과 화면에 남긴다. 복사문은 등록 이름 두 줄만 사용한다. 참가자 변경이나 추가 승인 화면을 요구하지 않고 추천을 바로 제공한다. 번호 규칙끼리의 비교에는 가중치 합산을 사용하지 않는다.

양 팀 부담을 맞춘다는 이유로 다른 참가자까지 일부러 기타 포지션에 보내지 않는다. 과거 경기에서 누가 반복해서 양보했는지는 현재 자동 계산에 반영하지 않으므로, 여러 판 진행 시 운영자가 함께 확인한다.

## 화면 판정과 수동 조정

| 화면 표시 | 의미와 처리 |
|---|---|
| 균형 추천 | 현재 검사에서 필수 조건, 전력 기준, 조합 선호와 주·부 배정 조건을 충족한 편성 |
| 조건부 편성 | 필수 조건은 지켰지만 전력 격차, 조합 규칙 또는 기타 포지션 배치에 주의가 필요한 편성 |
| 조건 조정 편성 | 기본 조건 후보가 없어 자동 조정한 편성. 조정 사유를 보여주며 바로 선택·저장·공유 가능 |
| 정보 확인 필요 | 현재 티어 등 판정에 필요한 자료가 부족한 편성 |
| 필수 조건 위반 | 인원·역할 구성 오류 또는 일반 초안의 수동 제한 위반. 저장 불가 |
| 규칙 평가 대기 | 수동 변경 후 서버 평가를 기다리거나 검사 정보가 없는 상태 |

추천안과 최종 결과에 판정 및 주의사항을 표시하고, 세부 검사를 펼치면 각 규칙의 통과·주의·위반 사유를 볼 수 있다. 복사 결과는 `BLUE 등록이름 5명`과 `RED 등록이름 5명`의 두 줄이며 판정·경고·점수는 덧붙이지 않는다. 카드에는 닉네임 옆에 현재 등록 이름을 표시한다. 이름이 없으면 누락을 표시하며 닉네임으로 대신하지 않는다. 이름 조회는 기존 소유자·관리자 초안 접근 권한을 통과한 경우로 한정한다. [표시·복사 결정](architecture/0016-inhouse-drag-and-name-copy.md).

기본 조건을 만족한 초안에서는 역할 제한이나 바텀의 큰 티어 제한을 위반하는 수동 교체를 계속 막는다. 서버가 자동 조정을 적용한 초안에서는 해당 자동 추천을 근거로 수동 변경도 같은 완화 정책으로 평가한다. 어느 경우든 **수동 배치 평가·선택**으로 서버에서 다시 계산한 뒤 적용한다. 수동 변경만 하고 서버 평가를 완료하지 않은 상태에서는 저장·복사·경기 접수로 넘어가지 않는다. 저장된 자동 추천을 다시 선택하거나 저장할 때도 원본 포지션과 점수로 검증하며, 자동 조정 결과가 종전 제한 때문에 다시 막히지 않게 한다.

화면에는 **팀 전력 점수와 점수 차이**를 표시한다. 이 점수는 승리 확률이 아니다. 수동 변경은 카드 사이 드래그로 교환하며 별도 카드 선택·교체 버튼을 사용하지 않는다. 키보드에서도 드래그 시작·놓기·취소가 가능하다. 교환 즉시 같은 도메인 계산으로 배정 역할의 적용 점수와 밸런스 미리보기를 갱신하고, 서버 평가 후 확정한다. 데이터가 적거나 챔피언 숙련·팀 호흡이 크게 다른 경우 운영자가 추가로 검토한다.

### 같은 10명 중 두 사람만 교환했는데 90%가 나온 이유

이전 표시값은 실제 경기 결과로 보정한 승률이 아니라 `RED 비율 = 100 / (1 + 10^((BLUE 총점 - RED 총점) / 40))`라는 점수 환산이었다. 팀 총점 차이가 약 38.17점이면 90%, 40점이면 90.9%가 된다. 각 팀 5명의 평균 격차로는 약 7.63점만 있어도 90%로 표시됐다.

- **서로 다른 팀 사이의 교환:** 20점 높은 선수를 상대 팀의 선수와 교환하면 한 팀은 20점 줄고 다른 팀은 20점 늘어, 부호 있는 팀 총점 차이는 40점 변한다. 역할 감점 변화가 없어도 50%에서 90.9%로 변할 수 있다.
- **같은 팀 안의 포지션 교환:** 맡는 역할에 따라 개인 점수가 달라진다. 기존 계산에서 마스터 이상 선수는 주→부 18점, 주→기타 35점이 감점된다. 같은 팀 두 명이 함께 주→부로 이동하면 36점, 주→기타로 이동하면 70점이 줄 수 있다.
- **실제 도메인 함수의 합성 재현:** 양 팀 394점에서 한 팀 두 명을 주→부로 교환하면 358 대 394점으로 바뀌고 이전 환산값은 상대 88.8%가 된다. 주→기타 교환은 324 대 394점과 상대 98.3%가 된다. 실제 사용자 경기의 기록을 분석한 결과는 아니다.

이 문제를 숨기기 위해 퍼센트를 임의로 제한하거나 개인 점수를 낮추지는 않는다. 기존 점수와 과거 저장 자료는 보존하고, 미검증 비율을 승률로 표시하던 부분을 제거한다. 교환 후에는 팀 합계, 역할 변경, 라인별 차이와 규칙 경고를 함께 확인한다. 이전 초안은 재평가해야 최신 자동 조정 기준이 적용된다.

기존 초안에는 참가자의 선택 포지션이 저장되어 있지만 새 규칙 판정은 없을 수 있다. 이 결과는 **규칙 재평가 필요**로 안내하고 과거 결과를 새 규칙으로 통과했다고 표시하지 않는다. 새 판정은 기존 점수 JSON에 함께 보관하므로 DB 스키마 변경이 필요하지 않다. 재평가 시에도 기본 조건 후보가 없으면 자동 조정을 수행한다.

## 구현 검증

`npm run check`에 포함된 단위·계약 검사로 공통 규칙, 팀·포지션 동시 탐색, 수동 평가와 화면 동작을 확인한다. 큰 등급 3단계 경계, 포지션 고정 충돌, 미확인 티어, 반대 방향의 큰 격차, 팀 색 교환, 기존 개인 점수 유지와 최대 1,814,400개 배치 탐색을 검사한다. 후보 축소 결과는 전체 후보를 정렬한 기준 결과와 대조한다.

저장 경로는 `V2_DB_CONTRACT_SCOPE=team-tools` 환경에서 `npm run test:db`로 격리 PostgreSQL을 생성해 검증한다. 자동 조정 초안의 생성·선택·수동 평가·저장·재평가, 일반 초안의 수동 제한, 실패 시 rollback, 멱등성 및 과거 JSON 보존을 검사한다. 운영 DB에 시험 초안을 쓰지 않는다. HTTP 오류 매핑·인증 경계 검사는 별도로 실행하며 실제 결과는 [자동 조정 검증 기록](qa-evidence/inhouse-auto-balance-2026-10-16/README.md)에 남긴다. 이 검사는 구현의 일관성을 확인하며 실제 경기 승률을 입증하지는 않는다.

## 운영자 공유용 문구

> 앞으로 내전 팀은 팀 총점뿐 아니라 라인별 격차와 포지션 숙련도까지 함께 보고 짭니다.
>
> 주·부 포지션 안에서 배정하고 원딜끼리·서폿끼리 큰 티어 3단계 이상 차이를 피하는 것이 기본입니다. 이 조건으로 팀을 만들 수 없으면 같은 10명 안에서 필요한 포지션을 최소한으로 자동 조정하고 이유를 보여드립니다.
>
> 조합 규칙은 1번부터 6번 순서로 비교합니다. 고티어 두 명의 미드·정글 분산, 바텀 강점 분산, 강한 정글의 활용 라인, 바텀 3등급 제한, 약한 서폿의 정글 보완, 탑·미드 우세 분산 순서입니다. 자동 조정에서도 바텀 격차를 우선 줄입니다. 하위 규칙 여러 개를 맞췄다고 상위 규칙을 무시하지 않습니다.
>
> 팀 합계가 같아도 크게 밀리는 라인이 두 곳 이상이면 좋은 밸런스로 보지 않습니다. 완벽히 맞는 조합이 없어도 계산을 중단하지 않고 현재 자료에서 최선의 추천과 남은 차이를 함께 보여드립니다.
>
> 두 명만 교환해도 팀 전력과 포지션 감점이 함께 바뀔 수 있습니다. 이전의 90% 같은 숫자는 실제 승률이 아닌 점수 환산값이었으므로, 이제는 전력 점수와 교환 전후 차이를 보여드립니다. 이전 초안은 재평가하면 최신 자동 조정 기준이 적용됩니다.
