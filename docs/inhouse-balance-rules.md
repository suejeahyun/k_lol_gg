# 내전 팀 밸런스 운영 기준

적용 계산식: `V2_INHOUSE_FAIRNESS_2026_10_15` · 정리일: 2026-10-15

팀 합계가 비슷하다는 이유만으로 공평하다고 판단하지 않는다. 실제 맡는 포지션의 전력, 대면 격차, 포지션 양보 부담, 양 팀이 활용할 수 있는 라인을 함께 비교한다. 아래 점수 기준은 현재 계산식에 맞춘 운영 기준이며, 특정 점수 차이를 실제 승률로 검증한 값은 아니다.

## 참가자 입력

- 대표 포지션은 기본적으로 주 포지션, 세부 설정에서 추가한 역할은 기본적으로 부 포지션이다. 기존 선호 설정에서 개별 역할을 주·부·자동 배치 가능으로 조정할 수 있다.
- **선택한 포지션만 허용**이 기본이다. 한 포지션만 선택하고 기타 허용 옵션을 끄면 해당 역할에 고정된다.
- 주·부 이외의 역할도 가능한 참가자만 **선택하지 않은 기타 포지션도 허용**을 켠다. 켜면 선택하지 않은 역할을 자동 배치 가능(AUTO)으로 추가하고 기존 역할 보정을 적용한다. 주·부 선호는 유지한다.
- **전체**는 다섯 포지션 모두를 자동 배치 가능으로 명시적으로 허용한다. 주 포지션 다섯 개와 같은 의미가 아니다.
- 허용 포지션이 없는 입력은 거절한다. 신청자를 불러오면 신청한 주·부 포지션을 허용하고, 부 포지션이 전체인 신청은 나머지 네 역할을 부 포지션으로 반영한다.
- 배정할 자리가 부족하면 고정을 무시하지 않는다. 예를 들어 미드만 가능한 사람이 3명이면 미드 자리는 2개이므로 참가자 또는 허용 역할을 변경해야 한다.

## 반드시 지키는 조건

| 조건 | 적용 방법 |
|---|---|
| 인원과 역할 | 서로 다른 10명, 양 팀 각 5명, 각 팀 탑·정글·미드·원딜·서폿 1명씩 |
| 허용 포지션 | 참가자별 허용 목록 밖의 역할로 배정하지 않음 |
| 바텀 큰 티어 차이 | 원딜끼리와 서폿끼리 **각각** 현재 티어의 큰 등급 차이가 3단계 이상이면 제외 |

큰 등급은 아이언 → 브론즈 → 실버 → 골드 → 플래티넘 → 에메랄드 → 다이아몬드 → 마스터 → 그랜드마스터 → 챌린저 순서로 센다. 골드↔다이아몬드는 3단계이므로 금지하고, 골드↔에메랄드는 2단계이므로 이 조건만으로 금지하지 않는다. 골드4↔골드1은 같은 큰 등급이다. 원딜 격차를 서폿 우세로 평균내서 이 제한을 피할 수 없다.

현재 티어를 확인할 수 없는 참가자는 최고 티어나 임시 점수로 통과시키지 않는다. 해당 편성에 **정보 확인 필요**를 표시하고, 특히 바텀 티어가 없으면 3단계 제한을 검증할 수 없다고 안내한다.

## 전력과 대면 격차

배정 역할에 따른 기존 개인 점수를 사용한다. 새 규칙을 만족했다는 이유로 개인 전력에 점수를 더하지 않는다.

| 검사 항목 | 현재 기준 |
|---|---|
| 동급으로 보는 대면 | 점수 차이 3점 이하 |
| 전체 전력 | 양 팀 평균 점수 차이 3점 이하 권장: 팀 합계 차이 15점 이하 |
| 최악의 대면 | 한 포지션의 점수 차이 25점 이하 권장 |
| 큰 대면 격차 | 15점 이상 차이 나는 포지션은 최대 1곳 권장 |
| 바텀 합산 | 두 팀의 원딜·서폿 평균 점수 차이 5점 이하 권장: 합계 차이 10점 이하 |

예를 들어 A팀 탑이 크게 강하고 B팀 미드가 크게 강하면 합계는 같을 수 있다. 그러나 큰 격차가 두 곳이므로 균형 편성으로 간주하지 않는다. 큰 격차의 방향이 서로 달라도 각각 센다.

이 기준을 넘는 편성은 필수 조건을 통과했더라도 **조건부 편성**으로 남긴다. 기준을 충분히 만족하는 후보가 있으면 우선 선택한다. 조건부 후보만 가능한 경우에는 남은 이유를 표시한다.

## 원문의 여섯 가지 조합 규칙

| 규칙 | 실제 적용 기준 |
|---|---|
| 고티어 두 명을 미드·정글에 분산 | 기본 전력 상위 두 명을 양 팀에 나누는 조합을 우선한다. 등록한 주·부 포지션으로 가능할 때 서로 다른 팀에서 미드와 정글을 맡는 조합을 선호한다. 동점자는 동등하게 취급한다. |
| 바텀은 양쪽에 강점이 남도록 | 원딜·서폿이 동시에 한 팀에서 뚜렷하게 우세하면 경고한다. 우세 방향이 반대여도 바텀 합산 격차를 별도로 검사한다. 동급 매치업도 허용한다. |
| 강한 정글에게 활용 가능한 라인 | 정글 우세 팀의 탑·미드·원딜 중 최소 한 곳은 동급 이상이어야 한다. 상대 팀에도 동급 이상 라인이 남아 있는지 함께 검사한다. |
| 바텀 3티어 이상 차이 금지 | 현재 티어의 큰 등급 3단계 이상 차이를 원딜 대면과 서폿 대면에서 독립적으로 금지한다. |
| 약한 서폿에게 정글 보상 | 서폿이 뚜렷하게 열세인 팀은 정글이 동급 이상인 후보를 선호한다. 서폿과 정글이 모두 열세이면 경고하되 다른 라인의 강점까지 함께 판단한다. |
| 탑과 미드의 우세를 분산 | 탑과 미드가 동시에 같은 팀에서 뚜렷하게 우세하면 경고한다. 한 곳이 동급이면 통과하며 동급을 일부러 열세로 바꾸지 않는다. |

미드·정글 분담은 실제 숙련 역할을 우선한다. 기타 포지션 배치를 허용했다는 이유만으로 고티어 원딜 유저에게 미드·정글을 강제하지 않는다.

**중복 보상 방지:** 약한 서폿에 대한 보상으로 강한 정글을 배치한 뒤 다시 강한 라이너를 계속 추가하지 않는다. 최종 배치의 팀 합계·대면 격차·바텀 격차·양 팀의 활용 라인을 한 번 더 비교한다. 승리 경로는 챔피언 선택 전 점수 기준으로 활용 가능한 라인이 있다는 뜻이며, 확정 캐리를 보장하지 않는다.

## 편성 순서와 포지션 양보

1. 입력과 허용 포지션을 검사하고 가능한 팀 구성과 양 팀 역할 배치를 함께 비교한다.
2. 허용 포지션과 바텀 3등급 제한 등 필수 조건을 어기는 후보를 제외한다.
3. 전체 전력·최대 대면·큰 격차 수·바텀 격차를 검사한다.
4. 기타 포지션 배치 인원을 줄이고, 남은 부담이 한 팀에 몰리지 않게 한다.
5. 비슷한 후보에서는 고티어 분산, 바텀과 탑·미드 강점 분산, 서폿·정글 보완, 양 팀의 활용 라인을 함께 비교한다.

양 팀 부담을 맞춘다는 이유로 다른 참가자까지 일부러 기타 포지션에 보내지 않는다. 과거 경기에서 누가 반복해서 양보했는지는 현재 자동 계산에 반영하지 않으므로, 여러 판 진행 시 운영자가 함께 확인한다.

## 화면 판정과 수동 조정

| 화면 표시 | 의미와 처리 |
|---|---|
| 균형 추천 | 현재 검사에서 필수 조건, 전력 기준, 조합 선호와 주·부 배정 조건을 충족한 편성 |
| 조건부 편성 | 필수 조건은 지켰지만 전력 격차, 조합 규칙 또는 기타 포지션 배치에 주의가 필요한 편성 |
| 정보 확인 필요 | 현재 티어 등 판정에 필요한 자료를 확인해야 하는 편성 |
| 필수 조건 위반 | 허용 역할 또는 바텀 티어 제한 등 필수 조건을 어긴 편성. 저장 불가 |
| 규칙 평가 대기 | 수동 변경 후 서버 평가를 기다리거나 검사 정보가 없는 상태 |

추천안과 최종 결과에 판정 및 주의사항을 표시하고, 세부 검사를 펼치면 각 규칙의 통과·주의·위반 사유를 볼 수 있다. 복사한 결과에도 판정과 주의사항이 포함된다.

선수 카드를 바꾸는 경우에도 허용 포지션은 유지된다. 역할 제한이나 바텀의 큰 티어 제한을 위반하는 교체는 화면에서 막고 기존 카드를 유지한다. 허용되는 교체는 **수동 배치 평가·선택**으로 서버에서 다시 검사한 뒤 적용한다. 수동 변경만 하고 서버 평가를 완료하지 않은 상태에서는 저장·복사·경기 접수로 넘어가지 않는다. 저장된 자동 추천을 다시 선택하거나 저장할 때도 서버에서 현재 규칙을 검사한다.

화면의 예상 승률은 점수 기반 참고 추정이다. 균형 추천이라는 표시와 50%에 가까운 숫자가 실제 반반 승률을 입증하지는 않는다. 데이터가 적거나 챔피언 숙련·팀 호흡이 크게 다른 경우 운영자가 추가로 검토한다.

기존 초안에는 참가자의 선택 포지션이 저장되어 있지만 새 규칙 판정은 없을 수 있다. 이 결과는 **규칙 재평가 필요**로 안내하고 과거 결과를 새 규칙으로 통과했다고 표시하지 않는다. 새 판정은 기존 점수 JSON에 함께 보관하므로 DB 스키마 변경이 필요하지 않다. 과거에는 미선택 역할도 자동 배정할 수 있었으므로 재평가가 불가능하면 참가자와 허용 역할을 확인해 새 초안을 만든다.

## 구현 검증

`npm run check`에 포함된 단위·계약 검사로 공통 규칙, 팀·포지션 동시 탐색, 수동 평가와 화면 동작을 확인한다. 큰 등급 3단계 경계, 포지션 고정 충돌, 미확인 티어, 반대 방향의 큰 격차, 팀 색 교환, 기존 개인 점수 유지와 최대 1,814,400개 배치 탐색을 검사한다. 후보 축소 결과는 전체 후보를 정렬한 기준 결과와 대조한다.

저장 경로는 `V2_DB_CONTRACT_SCOPE=team-tools` 환경에서 `npm run test:db`로 격리 PostgreSQL을 생성해 검증한다. 기존 후보 선택·수동 평가·저장의 필수 조건, 실패 시 rollback, 멱등성 및 과거 JSON 보존을 검사한다. 운영 DB에 시험 초안을 쓰지 않는다. HTTP 오류 매핑·인증 경계 검사는 별도로 실행하며, 실제 결과는 [릴리스 검증 기록](qa-evidence/inhouse-fairness-2026-10-15/README.md)에 남긴다. 이 검사는 구현의 일관성을 확인하며 실제 경기 승률을 입증하지는 않는다.

## 운영자 공유용 문구

> 앞으로 내전 팀은 팀 총점뿐 아니라 라인별 격차와 포지션 숙련도까지 함께 보고 짭니다.
>
> 주·부 포지션만 배정하는 것이 기본이며, 한 포지션만 고르면 해당 포지션 고정입니다. 다른 포지션도 가능한 분만 기타 배정을 허용해주세요. 원딜끼리·서폿끼리 큰 티어 3단계 이상 차이가 나는 조합은 제외합니다. 예를 들어 골드↔다이아는 금지입니다.
>
> 고평가 선수는 양 팀에 나누고 가능한 경우 미드·정글로 분산합니다. 바텀과 탑·미드는 강점이 한 팀에 몰리지 않게 하며, 서폿이 약한 팀의 정글 보완과 강한 정글이 활용할 라인을 함께 봅니다. 이 과정에서도 두 팀 모두 게임을 풀어갈 라인이 남도록 합니다.
>
> 팀 합계가 같아도 크게 밀리는 라인이 두 곳 이상이면 좋은 밸런스로 보지 않습니다. 만족하는 조합이 없으면 조건부 편성과 남은 문제를 공개하고 조정하겠습니다. 자료가 부족한 경우에는 확인이 필요하다고 표시합니다.
